# 과목 프로필 템플릿 (스키마 정본)

> **왜 이 파일이 있나.** 스킬 본문에는 **어느 과목에나 적용되는 규칙만** 남기고, 특정 과목에서만 참인 값은 전부 여기로 뺀다. 2026-07-28 실측에서 당시 `skills/콘텐츠/SKILL.md`(2026-08-03 폐기) 본문에 과목 고유 값이 13곳, `kit/*/by-shape.md`에 3곳 섞여 있었다. 그 상태로는 다른 주제 강의에 이 스킬을 쓰면 **남의 과목 실측치가 규칙으로 강요된다.**
>
> **핵심 원칙**: **한 과목의 실측치를 다른 과목의 규칙으로 물려주지 않는다.**
> 기준선은 "그 과목에서 실제로 재 본 값"일 때만 게이트가 된다. 재 본 적이 없으면 **없는 채로 두고 WARN으로 시작**한다 — 다른 과목 값을 빌려 채우지 않는다.

## 파일 위치와 탐색

- 인스턴스: `courses/<과목>/profile.md`
- 스키마 정본: 이 파일. 인스턴스가 이 구조를 따른다.
- **프로필이 없으면 오류가 아니다.** 기준선을 요구하는 게이트가 전부 WARN으로 내려가고, 그 사실을 보고한다.

## 검증

```powershell
python scripts/verify_subject_isolation.py     # 스킬 본문에 과목 고유 값이 남아 있으면 FAIL
```

## 채울 항목

### 1. 과목 기본

| 항목 | 값 | 비고 |
|---|---|---|
| 과목명 | | 스킬 본문에 쓰지 않는다 |
| 대상 수강생 | | 톤·어휘 수준의 근거 |
| 관통 문장 | | 회차마다 반복할 한 문장. 없으면 공란 |
| 회차 단위 명칭 | | 교시 / 세션 / 모듈 등 |
| 회차 구조 | | 한 주차가 몇 회차인지, 각 회차 길이 |

### 2. 규모 기준선 *(없으면 WARN)*

| 항목 | 값 | **출처(어느 실측인가)** |
|---|---|---|
| 회차당 장수 범위 | | |
| 한 주차 총 장수 | | |

> **출처 열이 비면 그 값은 기준선이 아니라 추측이다.** 게이트로 쓰지 않는다.

### 3. 밀도 기준선 *(없으면 WARN)*

| 항목 | 값 | 출처 |
|---|---|---|
| 슬라이드당 정보 단위 범위 | | |
| 본문 글자수 대리 신호 하한 | | 판정 기준이 아니라 근사 신호 |
| 노트:본문 비율 상한 | | |

### 4. 표현 취향 *(보편 원리 아님 — 이 과목 사용자의 선택)*

> ⚠️ 이 절은 **미학적 선호**다. 다른 과목 사용자는 정반대를 고를 수 있다. 스킬 본문에 두면 취향이 규칙으로 굳는다.

| 항목 | 값 |
|---|---|
| 레이아웃 동점 시 우선순위 | |
| 기준 슬라이드(합격선 예시) | |
| 그 밖의 확정된 선호 | |

### 5. 브랜드·자산

| 항목 | 값 |
|---|---|
| 워드마크 문자열 | |
| 로고 경로 | |
| 스타터 경로 | |
| 테마 | `default` |

**테마는 포인터만 적는다** — `kit/themes/<이름>/` 중 하나의 이름. 색·타이포 값을 여기 적지 않는다.
과목 전용 테마여도 `kit/themes/`에 둔다(과목과 테마는 N:1). 무엇이 테마마다 바뀌고 무엇이
고정인지, 새 테마를 어떻게 등재하는지는 `kit/guide/테마-계약.md`가 정본이다.

### 6. 도구·제품 맥락

실습에서 다루는 제품·도구명. 스킬 본문의 예시가 이 값에 의존하면 안 된다.

### 7. 규칙 소급 면제 등재

이미 완성·동결된 산출물은 신규 게이트를 소급 적용하지 않는다. 면제 대상과 사유를 적는다.

| 대상 | 면제 게이트 | 사유 | 등재일 |
|---|---|---|---|

### 8. 격리 검사용 리터럴 *(필수 — 없으면 검사기가 FAIL)*

`scripts/verify_subject_isolation.py`가 이 절의 불릿을 읽어 스킬 본문에서 찾는다. 하나라도 나오면 FAIL.

**올릴 것**: 모든 출현이 운영 파라미터인 문자열(과목명·워드마크·관통 문장·장수 범위 리터럴·대상 문구·취향 리터럴).
**올리지 말 것**: 사고 이력에도 등장하는 문자열. 올리면 규칙의 근거까지 지워야 한다.

```
- <과목명>
- <워드마크>
- <관통 문장>
- ...
```

검사에서 제외한 파일이 있으면 사유와 함께 표로 남긴다 — 제외는 "격리 완료"가 아니라 **미결**이다.

## 스킬 본문에 남겨야 하는 것 (프로필로 옮기지 않는다)

혼동을 막기 위해 명시한다. 아래는 **과목 고유 값이 아니다.**

- **사고 이력과 그 실측치** — "N주차에서 이런 실패가 있었고 수치가 이랬다"는 규칙의 **근거**다. 지우면 규칙의 "왜"가 사라져 재발 방지력이 죽는다. 단 **이력임이 문장에서 드러나야** 하고, 그 수치를 새 과목의 목표치로 쓰지 않는다.
- **판정 절차** — 순서 판별, 강조 의미 배정, 역인덱스 조회 같은 **방법**은 주제와 무관하다.
- **물리 한도** — 1280×720 캔버스, 폰트 하한, 색 대비. 화면의 성질이지 과목의 성질이 아니다.
