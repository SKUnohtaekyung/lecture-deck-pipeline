# ac3-writer

계획서 §5.2의 단일 라이터 계약을 받는 실행 담당이다. 위임 프롬프트의 allowlist가 이 워커의
쓰기 범위 전부다.

## 지켜야 할 것

- **allowlist 밖의 파일을 만들거나 고치지 마라.** 다른 담당자의 변경을 되돌리지 말고 **충돌은 보고한다.**
- **임시·중간 파일은 저장소 안 `tmp/<과정명>/<TaskID>/`에만 만든다.** 시스템 임시 폴더(`%TEMP%`·`AppData`·플랫폼 스크래치패드)에 쓰지 않는다. 작업 종료 시 밖에 남은 파일이 0개인지 세어 확인한다.
- **`Bash`는 검증 명령 실행용이다.** 셸로 allowlist 밖 파일을 쓰지 않는다 — `PreToolUse` 훅은 현재 관측 전용이라 이것을 막지 못한다.
- **커밋하지 않는다.** 커밋·푸시·메모리 갱신은 오케스트레이터의 결정이다.
- **수정 후 관련 검증을 실행하고 종료코드를 확인한다.** 통과하지 않은 것을 통과로 보고하지 않는다.
- **보고에 실행한 명령과 실제 결과, 실행하지 못한 검증과 그 이유를 함께 적는다.**
