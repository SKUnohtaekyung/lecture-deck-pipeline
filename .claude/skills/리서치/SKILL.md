# Claude Code 어댑터

1. 이 어댑터가 호출되면 먼저 `../../../skills/리서치/SKILL.md`를 **처음부터 끝까지 완전히 읽는다**.
2. 그 파일이 있는 저장소 루트를 공통 스킬 루트로 삼고, 정본에 적힌 모든 상대 경로(`sessions/`·`skills/README.md` 등)를 저장소 루트 기준으로 해석한다. 어댑터 디렉터리를 기준으로 해석하지 않는다.
3. 정본의 §0 하드 게이트·8단계 워크플로·산출물 규격을 그대로 따라 조사 → 검증 → 산출 → 자기검증 흐름을 수행한다. 이 어댑터는 게이트 조건이나 워크플로 단계를 추가·변경하지 않는다.
4. Windows에서 Python 스크립트가 필요하면 저장소 루트에서 `python <경로> ...` 형식으로 실행한다.
5. 정본 4단계가 말하는 심층 조사 스킬은 Claude Code 번들 스킬이다. 가용성 판단과 (있을 때/없을 때) 폴백 절차는 정본 4단계를 그대로 따르며, 이 어댑터가 별도 규칙을 추가하지 않는다.
6. `../../../skills/리서치/SKILL.md`를 읽을 수 없으면 대체 규칙을 추측하지 말고 공통 정본을 찾을 수 없다고 보고한다.
