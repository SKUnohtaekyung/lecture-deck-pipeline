# Claude Code 어댑터

1. 이 어댑터가 호출되면 먼저 `../../../skills/검토/SKILL.md`를 **처음부터 끝까지 완전히 읽는다**.
2. 그 파일이 있는 저장소 루트를 공통 스킬 루트로 삼고, 정본에 적힌 모든 상대 경로를 저장소 루트 기준으로 해석한다. 어댑터 디렉터리를 기준으로 해석하지 않는다.
3. 정본의 인자 해석 → 인벤토리 → 7단계 검토 → 보고서 산출 흐름을 그대로 따른다. 이 어댑터는 검토 규칙이나 §0 불변 규칙을 추가·변경하지 않는다.
4. Windows에서 `scripts/verify_deck.py`는 저장소 루트에서 `python scripts/verify_deck.py <덱>.html --parts N` 형식으로 실행한다.
5. `../../../skills/검토/SKILL.md`를 읽을 수 없으면 대체 규칙을 추측하지 말고 공통 정본을 찾을 수 없다고 보고한다.
