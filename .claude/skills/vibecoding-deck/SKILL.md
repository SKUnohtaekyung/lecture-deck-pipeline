# Claude Code 어댑터

1. 이 어댑터가 호출되면 먼저 `../../../SKILL.md`를 **처음부터 끝까지 완전히 읽는다**.
2. 그 파일이 있는 저장소 루트를 공통 스킬 루트로 삼고, 공통 지침에 적힌 모든 상대 경로를 저장소 루트 기준으로 해석한다. 어댑터 디렉터리를 기준으로 해석하지 않는다.
3. 루트 `SKILL.md`와 그 문서가 요구하는 참조·스크립트·에셋을 그대로 따라 탐색 → 로드 → 제작 → 검증 흐름을 수행한다. 이 어댑터는 PPT 조건이나 디자인 규칙을 추가·변경하지 않는다.
4. Windows에서 Python 스크립트는 저장소 루트에서 `python <경로> ...` 형식으로 실행한다.
5. `../../../SKILL.md`를 읽을 수 없으면 대체 규칙을 추측하지 말고 공통 정본을 찾을 수 없다고 보고한다.
6. 루트가 `IMAGE_MODE=generate_now`로 확정하면 사용 가능한 이미지 생성 기능을 먼저 확인한다. 기능이 없으면 `prompt_only`로 조용히 바꾸지 말고 사용자에게 보고한 뒤 이미지 단계에서 중단한다.
