# Claude Code 어댑터

1. 이 어댑터가 호출되면 먼저 `../../../skills/콘텐츠/SKILL.md`를 **처음부터 끝까지 완전히 읽는다**.
2. 그 파일이 있는 저장소 루트의 `skills/콘텐츠/`를 공통 스킬 정본 위치로 삼고, 정본에 적힌 모든 상대 경로는 저장소 루트 기준으로 해석한다. 어댑터 디렉터리를 기준으로 해석하지 않는다.
3. 정본 `skills/콘텐츠/SKILL.md`와 그 문서가 요구하는 read-path(입력 템플릿·초안 입력형식·리서치 산출물)를 그대로 따라 탐색 → 게이트A/게이트B 확인 → 집필 → 자기검증 흐름을 수행한다. 이 어댑터는 집필 규칙이나 형식 조건을 추가·변경하지 않는다.
4. Windows에서 보조 스크립트나 파일 확인이 필요하면 저장소 루트에서 `python <경로> ...` 형식으로 실행한다.
5. `../../../skills/콘텐츠/SKILL.md`를 읽을 수 없으면 대체 규칙을 추측하지 말고 공통 정본을 찾을 수 없다고 보고한다.
