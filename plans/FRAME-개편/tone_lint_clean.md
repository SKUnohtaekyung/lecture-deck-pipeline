# 말투 린트 통과 예문 (clean)

이 파일은 tone_lint.py가 위반을 0건으로 판정해야 하는 담백한 설명문 예문이다.

## 중간 유실 — 긴 자료의 가운데를 놓치는 현상

긴 자료를 한 번에 넣으면 모델은 처음과 끝의 내용을 잘 반영하고 가운데 내용은 놓치기 쉽습니다.

가운데에 있는 조건은 요청문 끝에서 한 번 더 적어 줍니다.

## 에이전트 실습 고르기

실습은 세 가지 중에서 하나를 고릅니다. 각 실습은 입력 자료와 결과물의 모양이 다릅니다.

고른 실습의 입력 자료는 자료 폴더에 있습니다.

## 흩어진 메모 4개를 할 일 표 하나로 모읍니다

메모마다 기한이 다르게 적혀 있어서 표의 마감 열에 기한을 통일된 형식으로 옮깁니다.

표가 완성되면 담당자와 기한이 빈 칸으로 남은 줄이 있는지 확인합니다.

## 기한마다 근거 줄을 열어 원문과 대조합니다

표의 각 줄에는 근거가 된 메모의 위치가 함께 적혀 있습니다.

근거 줄을 열어 날짜와 숫자를 원문과 나란히 놓고 읽습니다. 다르면 표를 고칩니다.

## 질문하는 방식이 답에 미치는 영향

AI는 질문자의 의견에 동의하는 쪽으로 답하는 경향이 있습니다. 의견을 물을 때는 내 생각을 밝히지 않고 먼저 장단점을 요청합니다.

같은 질문을 두 번 보내 답이 달라지는지 비교해 봅니다.

| 항목 | 확인 방법 |
|---|---|
| 날짜 | 원문의 같은 문장을 찾아 대조합니다 |
| 담당자 | 메모의 이름과 표의 이름을 나란히 놓습니다 |

- 요청문에는 목적과 입력 자료, 결과물의 형식을 적습니다.
- 결과가 기대와 다르면 요청문에서 빠진 조건을 찾아 보탭니다.

```
코드 펜스 안의 줄은 검사 대상이 아닙니다.
```
