# 디자인 v2 요약 — 마크업 위주 (셸 정본: `강의덱.초안/shell.html` · 시험 덱 `tmp/frame/E1/t2/` · 예시 `tmp/frame/E1/src/part-v2.tpl.html`)

설명·무드·줄바꿈 기준은 `공통지침.md` 「디자인 v2」 절이 정본이다. 이 문서는 **클래스와 마크업만** 적는다. 새 클래스는 만들지 않는다(필요하면 보고).

## 1. 장의 기본 골격 — 자유 흐름
`.slide`에 padding 56/72가 있다. 눈썹 · 제목 · 보조 설명을 섹션 직속에 차례로 쓰면 위에서 아래로 흐른다. 머리(`s-head`)는 바닥 한 줄로 바뀌니 **마크업은 그대로** 둔다(`.s-team`의 `<br>`은 「 · 」로 바뀐다).
```html
<section class="slide" data-slide="ID">            <!-- 실습은 class="slide pr", 간지는 "slide part-divider f-divider dark" -->
  <header class="s-head">…표준 헤더…</header>
  <div class="bleed w50 t-mint"></div>              <!-- 선택: 오른쪽 면 -->
  <p class="kick">개념 · 에이전트</p>
  <h2 class="s-title"><b class="kw">에이전트</b> — 읽기 · 계획 ·<br>실행 · 확인</h2>
  <p class="lede">회색 보조 설명 한 줄.</p>
  …본문(왼쪽 칸)…
  <div class="on-bleed">…오른쪽 면 위 그림…</div>
</section>
```
- `.bleed`가 있으면 왼쪽 글 칸은 자동으로 면 앞(`.w40` 656px · `.w50` 520px · `.w60` 392px)까지만 쓴다. 더 넓히려면 인라인 `max-width`.
- 기존 v1 틀(`.cx-wrap` · `.pr-wrap` · `.hub-wrap` · `.slot-wrap`)도 그대로 동작한다(위 56px부터, 면 · 카드 스타일로 바뀜).

## 2. 클래스 표 — 최소 마크업
| 클래스 | 마크업 |
|---|---|
| `.kick` | `<p class="kick">실습 1 · 회의 메모 · ① 목표</p>` (24자 이내 · 실습 장은 자동 주홍) |
| `.kw` (`.mk` `.mk-solid`도 동일) | `<b class="kw">중간 유실</b>` — 색 글자 800 · 면 없음 · 줄바꿈 가능 |

| `.bleed` `.w40/.w50/.w60` `.t-mint/-sky/-apricot/-mist` | `<div class="bleed w50 t-sky"></div>` 섹션 직속. 색 생략 시 개념=민트 · 실습=살구 |
| `.on-bleed` | 면 위 그림 묶음. 면과 같은 폭(`.w40/.w60`은 면 뒤에서 따라감), 세로 가운데 정렬. 위 정렬은 `style="justify-content:flex-start"` |
| `.band` `.t-*` | `<div class="band t-mint">글 <span class="pill">기획</span><b>→</b>…</div>` 화면 폭 띠. 기본 바닥 위 74px · 높이 128. `style="--bb:auto;--bt:300px;--bh:140px"`로 자리 변경 |
| `.bignum` `.md` | `<div class="bignum">26<small>%</small></div>` 170px · `.md` 112px |

| `.cols-dot` | `<div class="cols-dot"><div><b><small>블록&nbsp;1</small>50분</b><ul><li>…</li><li class="a">강조 점</li></ul></div>…</div>` 기둥 수만큼 자동 분할 |

## 4. 실습 셸 골격(실습이 주인공 — `.pr-*`는 그대로 동작, 눈썹 · 면으로 바뀜)
```html
<section class="slide pr f-steps" data-slide="P1-2">
  <header class="s-head">…</header>
  <div class="pr-wrap">
    <div class="pr-bar"><span class="pr-no">실습 1</span><span class="pr-name">회의 메모</span><span class="pr-steps"><span>① 목표</span><span class="cur">② 진행</span><span>③ 확인</span><span>④ 고치기</span></span></div>
    <div class="pr-top"><h2 class="s-title">…</h2></div>               <!-- 타이머를 제목 줄에: class="pr-top has-timer" + <button class="timer sm" data-min="8">…</button> -->
    <div class="pr-main"><div class="pr-cols">
      <div class="pr-left"><ol class="flow" data-w="todo">…</ol><button class="timer" data-min="8">…</button></div>
      <div class="pr-right"><div class="term terminal-dark">…</div><p class="keep tail">이어가기 안내</p></div>
    </div></div>
  </div>
</section>
```
- ④ 아래 줄: `<div class="fx-back"><p class="keep">끝나면 <b>허브로</b> 돌아갑니다.</p><button class="back" data-go="HUB" data-vt-key="p1">허브로</button></div>`
- 펼침: `<details class="reveal"><summary><span>찾은 곳</span><span class="hint">강사가 눌러 공개</span></summary><div class="reveal-body">…</div></details>` — 닫히면 본문이 배치에서 빠진다. 위에 겹쳐 뜨는 패널은 `class="reveal pop" style="--rw:740px"`(흰 카드 + 그림자, 인라인 position 불필요). 안에 터미널을 넣어도 글자색 유지.
- 실습 그림은 실제 행동 모형: `.win`(`file`/`browser`/`app`) · `.term` · `.paper` · `.wcard`. 창은 박스 1, 터미널 1, `.back`/`.wg-btn` 1 — 면(`.bleed` `.pc` `.wcard` `.paper` `.ic` `.pill`)은 의사 요소라 박스로 세지 않는다.

## 5. 바뀐 기존 규칙 · 금지
- `.mk` `.mk-solid`: 형광펜 면 없음(= `.kw`). `.rule`/`.say`/`.reveal`/`.meta3`의 세로 선 없음. 표 · 창 테두리 없음(표는 머리 글자색 + 여백).
- 고정폭 글꼴은 **터미널 창 안만**. `.em-tag` `code` `.path` `.win.file` 제목 · `.code` · 타이머 · 번호는 본문 글꼴이다(파일 이름은 `.em-tag`로).
- 제목 48/700 · `.kick` 18/800 · 본문 22 이상 · 요소 하나의 글자가 24자를 넘으면 22px 이상(출처 · 캡션은 `<span>`으로 24자씩 나눈다). 본문 글꼴 기본 굵기 500, 강조 800.
- 애니메이션: 막대가 자라는 `.a-grow` `.a-fillx`만. `.rv` · `--i` · `--mkd`는 효과 없음(써도 무해, 새로 쓰지 않는다).
- `.pill`은 kit의 흰 면 알약을 끄고 덮었다. kit `.card` `.callout`으로 글 묶음을 박스화하지 않는다.
- 색은 토큰만: `var(--t-mint|sky|apricot|mist|card|dark)` · `--pr-*` · `--mint-deep` 등. raw hex 금지(정의 줄은 셸에만).
- **색 수 제한(2026-10-01 사용자)**: 보라 · 노랑은 쓰지 않는다. 면은 민트 · 하늘 · 살구(실습 전용) · 회청(mist) 넷, 글자 강조는 청록(`--blue`) · 민트 진한 색 · 주황(실습 · 주의) · 진홍(`--red`, 오류만) 안에서 고른다. `.t-lav` · `.t-sand`는 폐기 별칭이라 새로 쓰지 않는다. 한 장에 면 색은 2개까지.
