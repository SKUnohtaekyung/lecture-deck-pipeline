## 6. 참가자에게 주는 것(D26)

참가자는 **축과 유형은 그대로 두고 문항 8개와 결과 글 4개를 직접 쓴다.** 제공물:

1. **틀** — 참가자는 JSON을 직접 고치지 않는다(따옴표 · 쉼표 오류로 화면이 비는 위험). `문항.txt`(축 이름 아래 한 줄에 한 문항) · `결과글.txt`(유형마다 요약 · 이번 주 한 가지 · 요청문 카드)에 쓰고, M2-2에서 에이전트가 `content.js`으로 옮긴다.
2. **작성 안내**(`시작안내.md`)
   - 문항은 내 업무에서 실제로 하는 행동으로 씁니다. 「~한다」로 끝나는 한 문장.
   - 한 문항에는 행동 하나만 넣습니다.
   - 결과 글의 요약은 「~하는 편입니다」로 씁니다.
   - 최소 완성 기준(R14 · D39): 축마다 문항 2개(총 4개) + **본인이 예상하는 유형 포함 두 유형**의 요약과 이번 주 한 가지. 나머지 두 유형은 ④ 개선에서 채운다(비어 있는 유형은 화면에 「아직 쓰지 않은 결과입니다…」). 요청문 카드는 강사 예시에서 골라 붙여도 됩니다. 나머지 문항은 ④ 개선 단계에서 채웁니다. 먼저 끝난 사람은 문항을 8개까지 채웁니다.
3. **에이전트에게 질문을 시키는 요청문**(`요청문.txt` · 터미널 카드) — 에이전트가 문항을 대신 쓰지 않고, 참가자가 쓸 재료를 끌어낸다.
   ```
   > 나는 'AI 활용 습관 점검' 페이지를 만들고 있어. 축은 두 개야 — 시작(AI를 켜기 전에 내 생각을 먼저 두는가)과 마무리(받은 답을 쓰기 전에 확인하는가).
     내가 문항을 직접 쓸 수 있게, 축마다 내 업무에서 AI를 쓰는 장면을 묻는 질문을 두 개씩 해 줘.
     문항은 네가 쓰지 말고, 내 대답을 한 문장씩 정리만 해 줘.
   ```
4. **「진단처럼 쓰지 않기」 점검 3줄**
   - 「당신은 ~한 사람입니다」 대신 「~하는 편입니다」로 씁니다.
   - 좋고 나쁨을 적지 않고, 이번 주에 해 볼 행동 하나를 적습니다.
   - 결과 아래에 「연구에서 착안한 자기 점검입니다」 한 줄을 둡니다.
5. **강사 시연용 예시 파일** — 위 §3·§4를 채운 `강사용_예시결과/`(D1 · Phase D).
