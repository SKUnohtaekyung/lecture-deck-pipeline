## 1. 토큰 규칙 (가장 중요한 조건 — 이 방법으로 한다)

이 작업의 비용 대부분은 **메인 창의 재독**이다(실측 72% · 워커 몫은 작다). 그래서 메인은 **읽지 않고 시킨다.**

1. **메인이 여는 파일은 세 개뿐**: `새창_프롬프트.md`(이미 읽음) · 이 `PLAN.md` · `plans/FRAME-실습강화/재개_인계.md` **§3·§4만**(`sed -n '/^## 3/,/^## 5/p'`). 그 밖의 문서는 열지 않는다. 과목 지침은 PreToolUse `course` 훅이 주입하므로 `profile.md`도 열지 않는다.
2. **메인은 part-0N.html · shell.html · gen_*.py · templates를 절대 열지 않는다.** 위치가 필요하면 `rg -n` 한 줄만. 편집은 전부 워커가 한다. 생성물(`강의덱*.html` · `*_발표*.html` · `*_배포.html`)은 아무도 열지 않고 명령으로 다시 만든다.
3. **워커 브리프 = 이 문서의 해당 절을 그대로 붙여 넣기** + 공통 머리말(§1-1). 메인이 브리프를 새로 쓰지 않는다. 워커 보고는 **10줄 이내**, 검토자 보고는 **판정표 + 근거(파일:줄) 25줄 이내**.
4. **명령 출력은 판정 줄만**: `... 2>&1 | tail -n 12` · `| rg "RESULT|FAIL|ERROR|OK|Traceback"`. 콘솔 한글은 `PYTHONIOENCODING=utf-8`.
5. **브라우저 측정은 한 번에 묶는다**: 바뀐 장 ID 목록을 §1-2 스니펫 한 번에 넣어 JSON 한 줄로 받는다. 스크린샷은 **빨간 동그라미 위치 확인이 필요한 설치 장 4개와 MHUB · P5-1에만**, `scale 0.5`.
6. **Phase 1과 Phase 2는 병렬**(파일이 겹치지 않는다: builder는 `강의덱.초안/**`, writer는 `_생성스크립트/**`). 한 번의 메시지로 두 워커를 동시에 띄운다. 나머지는 순차.
7. **독립 검토는 Phase당 1회, 끝에서만.** 반영 뒤 재검토 없음 — `rg -c`로 잔존 0을 센다(U12).
8. **임시 파일은 `tmp/frame-수정-1025/<phase>/`에만.** 워커 브리프에도 적는다(built-in Explore·Plan은 CLAUDE.md를 읽지 않는다). 끝날 때 저장소 밖 파일 0개를 센다.
9. **`PROGRESS.md`는 40줄 이내**: Phase · 상태 · 검토 지적 수 · 반영 수 · 남은 것. 창이 250k를 넘거나 긴 중단 뒤에는 새 세션에서 `PROGRESS.md` → 이 문서 순으로 재개한다.
10. **결정을 다시 따지지 않는다.** §0에 없는 결정이 필요하면 **멈추고 사용자에게 한 줄로 묻는다**(임의 판단 금지). 멈춤 지점은 각 Phase의 「STOP」 항목뿐이다.

### 1-2. 브라우저 측정 스니펫 (메인이 `javascript_tool`로 1회 실행)

`preview_start {name:"deck-verify"}`(8799 · 루트 `.`) → `http://localhost:8799/courses/AI_에이전트_실습워크숍_4시간/sessions/1주차/강의덱.html?v=<시각>` 으로 연다(캐시 함정: `await fetch(location.pathname,{cache:'reload'})` 뒤 쿼리를 바꿔 다시 연다). 창은 1280×720 이상.

```js
(async()=>{await document.fonts.ready;
const ids=["O-01","DL-1","DL-2","DL-3","DL-ALL","MHUB","P5-1","P8-1","P8-2","P8-2B","P8-2C","P8-2D","P8-3","P8-3B"];
const out={};for(const id of ids){const s=document.querySelector(`[data-slide="${id}"]`);if(!s){out[id]="MISSING";continue;}
const r=s.getBoundingClientRect();let ovf=0,small=[],maxB=0;
s.querySelectorAll("*").forEach(e=>{const b=e.getBoundingClientRect();if(!b.width||!b.height)return;
if(b.right>r.right+1||b.bottom>r.bottom+1)ovf++;maxB=Math.max(maxB,b.bottom-r.top);
const cs=getComputedStyle(e);if(e.childNodes.length&&[...e.childNodes].some(n=>n.nodeType===3&&n.textContent.trim())){const fs=parseFloat(cs.fontSize);if(fs<22)small.push(e.className||e.tagName)}});
out[id]={ovf,maxBottom:Math.round(maxB),sw:s.scrollWidth,sh:s.scrollHeight,small:small.slice(0,5),smallN:small.length}}
return JSON.stringify(out)})()
```
판정: `ovf 0` · `maxBottom ≤ 666`(바닥선) · `sw ≤ 1280 · sh ≤ 720` · `smallN 0`(캡션 18~20px는 기존 장 P1-1과 같은 class면 허용 — 기존 장에서 쓰는 class 이름을 보고로 받아 비교). 측정은 장을 **현재 장으로 보이게 한 뒤**(방향키 · `html.no-anim` 켜기) 한다 — 숨은 장은 0으로 나온다(인계 §4 함정).
