# 디자인 v2 — 「노션 페이지를 그대로 띄운 강의덱」 (아트 디렉션 정본)

> 2026-10-22 · 메인 작성 · 사용자 지시: 기존 프로젝트 디자인 틀(kit CSS · FRAME 셸 · notepaper 테마 · 우주 허브)과 그 규칙을 이 덱에서는 쓰지 않는다. 원본 분위기 자료는 `courses/세컨브레인_특강/sessions/1주차/DESIGN-notion.md`(이하 DN).
> 이 문서는 빌더·영상 제작자·검토자가 공유하는 **유일한 디자인 기준**이다. 값은 여기서 가져오고, 애매하면 「노션 앱에서 실제로 이렇게 보이는가」로 판단한다.

---

## 0. 한 줄 콘셉트

**모든 슬라이드는 노션 페이지 한 장이다.** 브라우저에서 노션을 열면 보이는 것 — 상단 경로(breadcrumb), 페이지 아이콘, 큰 제목, 속성(properties) 줄, 그리고 블록(콜아웃 · 체크리스트 · 토글 · 데이터베이스 표 · 갤러리 · 코드 블록) — 만으로 덱 전체를 짓는다. 장식은 노션처럼 **흑백 + 파랑 하나 + 작은 스티커 색**으로 끝낸다.

시니어가 수업 뒤 노션을 열었을 때 「아까 화면이랑 똑같네」가 되게 하는 것이 디자인의 기능이다.

## 1. 하지 말 것

- 우주 · 행성 · 별 · 은하 · 3D 궤도 — 전부 삭제. 허브는 노션 **갤러리 보기**다.
- 그라디언트 배경, 네온, 글래스모피즘, 두꺼운 그림자, 굵은 테두리 박스 남발.
- 파랑 이외의 구조 강조색(버튼·링크·현재 위치 표시에 주황·초록 등을 쓰지 않는다). 스티커 색은 장식(아이콘 타일 · 표지 띠 · 태그 칩)에만.
- 노션 로고를 그대로 복제하지 않는다. 노션 제품을 가리킬 때만 실제 로고를 작게 쓴다(아래 §8).
- 본문 굵게 남발(본문 400 · 강조 600 · 제목 700/800).

## 3. 글꼴 — 「굵고 촘촘한 산세리프 + 로고에서 빌린 세리프 숫자」

| 역할 | 글꼴 | 규격(1280×720 기준) |
|---|---|---|
| 한글 전체 | Pretendard(Inter와 짝이 맞는 한글) | — |
| 라틴·숫자 | Inter(노션 NotionInter의 공개판) | 스택: `"Inter","Pretendard",-apple-system,system-ui,sans-serif` |
| 표시 세리프 | Noto Serif KR 900 (노션 「N」 로고의 세리프 획을 빌린다) | **워드마크 · PART 번호 · 실습 번호 · 큰 숫자(시간·휴식 타이머)에만** |
| 고정폭 | 쓰지 않는다(한글 고정폭은 시니어 가독이 나쁘다). 코드 블록도 Pretendard |

글자 크기(시니어 · 프로젝터 기준 — DN의 웹 크기를 그대로 쓰지 않는다):

| 토큰 | 크기 · 굵기 · 자간 | 용도 |
|---|---|---|
| `--t-display` | 88px · 800 · −3px · 1.02 | 표지 |
| `--t-h1` | 52px · 800 · −1.6px · 1.1 | 페이지 제목(모든 장) |
| `--t-h2` | 34px · 700 · −0.8px · 1.2 | 블록 제목 · 카드 제목 큰 것 |
| `--t-h3` | 28px · 700 · −0.4px · 1.25 | 카드 제목 |
| `--t-body` | **26px** · 400 · −0.2px · 1.5 | 본문 · 단계 |
| `--t-small` | 22px · 500 · 0 · 1.45 | 속성 줄 · 표 칸 · 요청문(최소) |
| `--t-meta` | 18px · 500 · 0 · 1.4 | 상단 경로 · 쪽 번호 · 캡션(이보다 작게 쓰지 않는다) |

- 본문 26px 이상 · 요청문 22px 이상 · 어떤 글자도 18px 아래 금지.
- 제목은 굵기 800과 음수 자간으로 「단단하게」. 본문은 400으로 「조용하게」. 이 대비가 노션의 목소리다(DN Typography Principles).
- 글꼴 파일은 오프라인 배포본에서도 보이도록 **로컬**에 둔다(§10).

## 4. 슬라이드 해부도(모든 장 공통)

```
┌ 1280×720 · 바탕 --paper ───────────────────────────────────────────────┐
│ s-head(높이 56): [■S] 세컨브레인 특강 / PART 2 모으기 / 받은함   [⏱ 4:00] 23 │  ← 18px · --ink-3 · 아래 1px --line
│                                                                          │
│   ┌ n-page(흰 종이 · 좌우 여백 72 · 위 28) ────────────────────────────┐ │
│   │  📥            ← 페이지 아이콘 64px(이모지 또는 스티커 타일)         │ │
│   │  받은함          ← n-title 52px/800                                  │ │
│   │  ⏱ 3분 · 블록 2 · 새 개념     ← n-props(속성 줄 · 태그 칩)          │ │
│   │  ───────────────────────────── (hairline)                          │ │
│   │  [블록들]                                                           │ │
│   └────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

- 페이지 면 표현은 두 가지 중 하나로 통일: **(A, 기본)** 바탕 전체를 흰색으로 두고 상단만 `--paper` 띠 — 실제 노션 페이지처럼. **(B, 카드형)** `--paper` 위에 흰 카드(반경 16 · `--sh-1`). 셸 빌더가 둘을 style tile로 만들어 메인이 고른다. 기본은 A.
- 왼쪽 정렬 · 넉넉한 여백 · 블록 간 간격으로 묶는다(선·상자는 최소).
- 한 장의 정보 단위 ≤4. 넘치면 토글로 접는다.

## 5. 블록 어휘(HTML 계약 — 클래스 이름 고정)

모든 파트 빌더는 이 마크업만 쓴다. 셸이 CSS·JS를 가진다.

```html
<!-- 슬라이드 -->
<section class="slide" data-slide="C1-1" data-kind="concept|practice|divider|hub|break|cover|summary|demo|closing|agenda" data-part="1">
  <header class="s-head">
    <span class="n-mark" aria-hidden="true"></span>
    <nav class="n-crumb"><span>세컨브레인 특강</span><span>PART 1 · 두 번째 뇌 만들기</span><b>세컨브레인</b></nav>
    <span class="s-tools"><!-- 실습 장만: <button class="n-timer" data-min="4">⏱ 4:00</button> --></span>
    <span class="s-pageno"></span>
  </header>
  <div class="n-page">
    <div class="n-icon">🧠</div>   <!-- 또는 <div class="n-icon n-tile st-purple">🧠</div> -->
    <h1 class="n-title">세컨브레인</h1>
    <div class="n-props"><span class="n-prop"><i>⏱</i>3분</span><span class="n-tag tg-blue">개념</span></div>
    <div class="n-body"> … 블록 … </div>
  </div>
</section>
```

| 블록 | 마크업 | 모양 |
|---|---|---|
| 콜아웃 | `<div class="n-callout cl-gray"><span class="n-callout-icon">💡</span><div>…</div></div>` (cl-blue/yellow/green/red/purple) | 노션 콜아웃 · 반경 6 · 안쪽 여백 18 24 |
| 정의 콜아웃 | `<div class="n-callout cl-blue n-def"><span class="n-callout-icon">📌</span><div><b class="n-label">정의</b>…</div></div>` | 정의는 항상 비유보다 위 |
| 체크리스트 | `<ul class="n-todo"><li><span class="n-check"></span>노션에서 「받은함」을 연다</li><li class="is-done">…</li></ul>` | 26px 체크 상자 · 클릭하면 체크(파랑 채움 + 글자 회색 취소선 없이 흐리게) |
| 번호 단계 | `<ol class="n-steps"><li><b>요청문을 보냅니다</b><span class="n-time">2분</span></li></ol>` | 번호는 원형이 아니라 노션 번호 목록(「1.」) + 굵은 동작 + 오른쪽 회색 분 |
| 토글 | `<details class="n-toggle"><summary>노션에 안 생겼어요</summary><div>…</div></details>` | ▸ 삼각형 · 열린 상태도 한 장에 들어가야 한다 |
| 인용 | `<blockquote class="n-quote">…</blockquote>` | 왼쪽 3px 검정 막대 |
| 구분선 | `<hr class="n-divider">` | 1px --line |
| 요청문(코드 블록) | `<figure class="n-code"><figcaption><span>요청문 · 2단계</span><button class="n-copy" type="button">복사</button></figcaption><pre>문장 원문</pre></figure>` | 노션 코드 블록(#f7f6f3 · 반경 6) · 글자 Pretendard 22~24px · 복사 버튼은 파랑 글자 |
| 지침 블록 | 같은 마크업 + `class="n-code is-guide"` · 캡션 「프로젝트 지침」 | |
| 페이지 멘션 | `<span class="n-mention">📄 받은함</span>` | 회색 밑줄 · 아이콘 |
| 태그 칩 | `<span class="n-tag tg-orange">코스</span>` | 반경 4 · 22px 높이 기준 상하 2px |
| 속성 | `<span class="n-prop"><i>⏱</i>18분</span>` | 아이콘 + 회색 글자 |
| 데이터베이스 | `<div class="n-db"><div class="n-db-bar"><b>📚 내 자료함</b><span class="n-view is-on">표</span><span class="n-view">갤러리</span></div><table class="n-table"><thead><tr><th><i>Aa</i>제목</th><th><i>◉</i>종류</th>…</tr></thead><tbody>…</tbody></table></div>` | 노션 표 보기 · 머리 칸 회색 아이콘 · 선은 --line-2 |
| 갤러리 | `<div class="n-gallery"><a class="n-card" data-go="P1-1"><div class="n-card-cover st-sky"></div><div class="n-card-icon">🗂</div><b class="n-card-title">첫 서랍</b><div class="n-card-props"><span class="n-tag tg-gray">15분</span></div></a>…</div>` | 노션 갤러리 · 표지 띠는 스티커 색 |
| 화면 틀(캡처·영상) | `<figure class="n-frame"><img src="자료/images/…" alt="…"><figcaption>…</figcaption></figure>` · 영상은 `<video class="n-video" src="자료/video/rag.mp4" poster="자료/video/rag.png" muted loop playsinline preload="auto"></video>` | 반경 12 · 1px --line · --sh-1 · 브라우저 창 머리(●●● 회색 점 세 개 + 주소)를 얹는 변형 `n-frame is-browser` |
| ChatGPT 대화 | `<div class="n-chat"><div class="n-chat-me">…</div><div class="n-chat-ai">…</div></div>` | ChatGPT를 그릴 때만: 내 말풍선 #f4f4f4 반경 18 오른쪽 · AI는 바탕 없이 왼쪽 |
| 승인 카드 | `<div class="n-approve"><b>Notion 사용 승인</b><p>…</p><div><span class="n-approve-no">거부</span><span class="n-approve-ok">승인</span></div></div>` | ChatGPT 대화상자처럼 흰 면 · 반경 16 · --sh-2 · 「승인」은 검정 알약 버튼(ChatGPT 화면이므로 노션 파랑이 아니다) |
| 버튼 | `<button class="n-btn" data-go="HUB">← 실습 목록으로</button>` · 주요 `n-btn is-primary` | 보조: 흰 면 1px 선 반경 8 / 주요: 파랑 알약 |
| 스티커 타일 | `<span class="n-tile st-orange">📥</span>` | 반경 12 정사각 · 스티커 색 면 + 이모지 |

## 6. 장 유형별 템플릿

| 유형 | 구성 |
|---|---|
| **표지 cover** | 바탕 흰색. 왼쪽 위 브랜드 마크(§8) 96px. 가운데-왼쪽에 워드마크 「세컨브레인」(Noto Serif KR 900 · 120px · 검정)과 그 아래 한 줄 「노션 + ChatGPT로 만드는 두 번째 뇌」(--t-h2 · --ink-3). 아래쪽에 스티커 타일 3개(📥 모으기 · 🗂 정리하기 · 🔎 다시 찾기)가 가로로. 오른쪽 아래 작은 회색 고지 「Notion·OpenAI와 무관한 교육 자료」. 검정·흰색이 주인공 |
| **아젠다 agenda** | 노션 표 보기: 행 = 블록 4개 + 마무리, 열 = 시간(태그) · 하는 일 · 실습(멘션). 맨 위에 관통 문장 콜아웃 |
| **허브 hub** | 페이지 제목 「실습 8개」 + 노션 **갤러리 보기 4×2**. 카드 = 표지 띠(스티커 색) · 아이콘 · 제목 · 태그(분 · 선택). 클릭 → 그 실습 ① 장. 우주·행성 없음 |
| **PART 전환 divider** | 노션 페이지의 **표지 이미지 + 겹친 아이콘** 구도: 위 260px를 검정(`--black`) 표지 띠로 덮고, 그 경계에 120px 페이지 아이콘(흰 바탕 타일)을 반쯤 걸친다. 띠 안 오른쪽 위에 세리프 대형 숫자 「01」(흰색 · 160px). 아래에 제목 「두 번째 뇌 만들기」(--t-h1), 속성 줄(50분 · 실습 1·2 · 새 개념 3), 이 블록에서 할 일 체크리스트 3줄 |
| **개념 concept** | 제목 → 정의 콜아웃(📌) → 비유 콜아웃(💡) → 시각 자료(오른쪽 또는 아래). 시각 자료는 노션 블록으로 만든 도식(표 · 갤러리 · 멘션 연결) 또는 **영상 틀**(§7) |
| **개념-영상 concept-video** | 제목 한 줄 + 큰 영상 틀(가로 880 안팎) + 아래 캡션 한 줄 + 오른쪽 좁은 열에 단계 3개(영상 장면과 같은 낱말) |
| **실습 ① 목표** | 제목 「실습 3 · 받은함 채우기」 + 실습 번호 세리프 타일(왼쪽 아이콘 자리: 흰 타일 안에 세리프 「3」) + 속성 줄(⏱ 18분 · 단계 칩 `①목표` 진하게 · ②③④ 흐리게) + 「만들 것」 전/후 두 장의 미니 노션 페이지 카드 |
| **실습 ② 진행** | 왼쪽 60%: `n-steps`(최대 8 · 한 줄 한 동작) / 오른쪽 40%: 요청문 `n-code`(복사 버튼) + 필요하면 승인 카드 축소판. 상단 경로 오른쪽에 타이머 |

### 6-1. 옵시디언 하위 테마 (`section.slide.theme-obsidian`)

옵시디언을 소개하는 장(들)만 옵시디언 앱의 분위기로 바꾼다 — 「다른 도구에 들어왔다」가 즉시 느껴져야 한다.

```css
.slide.theme-obsidian{
  --paper:#1c1c1c; --white:#212121; --line:#333333; --line-2:#2e2e2e;   /* 공식 --color-base-00/05/30/25 */
  --ink:#dadada; --ink-2:#bababa; --ink-3:#999999; --ink-4:#666666;     /* --color-base-100 = #dadada */
  --blue:#8a5cf5;  /* 옵시디언 기본 강조색 hsl(258,88%,66%) — docs.obsidian.md CSS variables 확인 · 이 장에서는 보라가 구조 강조색 */
  --blue-tint:rgba(138,92,245,.18);
  --obs-logo:#a079ff; /* 로고 SVG 내부 보라 */
}
```
- 구성: 왼쪽 파일 탐색기(📁 금고(vault) · .md 파일 목록), 가운데 편집기(마크다운 본문 · `[[링크]]`는 보라), 오른쪽 그래프 보기(점 · 선 · 보라로 강조된 현재 노트) — 앱 화면을 블록으로 재현하거나 실제 예시 이미지(§8)를 틀에 넣는다.
- 로고: 옵시디언 공식 로고(보라 결정 모양)를 제목 옆 64px.

## 20. 표현 — 그림이 먼저, 상자는 마지막

- **상자·표·콜아웃은 꼭 필요할 때만**: 표 = 실제 노션 표 보기를 보여 줄 때 · 코드 블록 = 요청문 · 콜아웃 = 장당 최대 1개(정의 한 줄). 비유는 콜아웃이 아니라 **그림 + 한 줄**.

## 21. 개념 장 구성 — FRAME 방식(정확한 개념 → 비유 → 움직임)

3. **비유 장**: 사물 비유 그림 한 장(AI를 사람처럼 그리지 않는다).
4. **영상 장**(있는 개념만): 「잠깐 영상 보고 갈게요」 — 영상이 화면 대부분(폭 1040px 이상) · 제목 한 줄 · 영상만 봐도 이해되게.

- **파트 안내 장**: 이번 파트에서 만드는 것 그림 하나 + 실습 이름 2개. 사이드바·체크리스트·다시 시작 단계는 뺀다(다시 시작 안내는 노트로).
- 파트 이름: 파트 1 「세컨드 브레인과 연결」 · 파트 2 「모으기」 · 파트 3 「정리하기」 · 파트 4 「꺼내 쓰기」(원고가 확정).

## 24. 실습 주제 — 「국내 여행 계획 · 예시 경주 1박 2일」(사용자가 메인 추천안으로 진행 지시)

- 「동네 걷기 모임」(잠긴 결정 L7)을 대체한다(사용자 요청 7-12). 「대인관계 심리학」 금지는 유지.
- 흐름: 노션 「경주 여행」 페이지 + ChatGPT 프로젝트 → 플러그인 연결 · 첫 쓰기 → ChatGPT로 명소 정보를 리서치해 「받은함」에 → 「경주 자료함」 데이터베이스로 정리(종류 · 위치 · 걷는 정도 · 추천 시간 · 출처) → 태그·@멘션 → ChatGPT가 자료함을 찾아 「1박 2일 일정표」 페이지를 쓴다(RAG) → 내 여행지로 바꿔 한 번 더 + 매주 정리.
- 결과물은 「정리를 이렇게 잘 해 주네」 수준으로 풍부하게: 요청문이 그런 결과를 내도록 구체적으로(섹션 · 개수 · 형식 지정).
- 이름: 사이드바 워크스페이스는 「태경님의 워크스페이스」. 실습 이름은 듣자마자 아는 말로(원고가 확정).
- 실습 산출물은 ChatGPT가 노션에 직접 쓴다(L3 유지).
