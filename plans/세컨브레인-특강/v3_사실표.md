## MCP (Model Context Protocol)
- 발표: Anthropic, 2024-11-25 「open-sourcing the Model Context Protocol」 [공식] https://www.anthropic.com/news/model-context-protocol
- 정의: "MCP (Model Context Protocol) is an open-source standard for connecting AI applications to external systems." [공식] https://modelcontextprotocol.io/docs/getting-started/intro
- 공식 비유: "Think of MCP like a USB-C port for AI applications." (같은 페이지) — 덱의 「표준 콘센트/플러그」 비유는 이 USB-C 비유의 변형.
- 구조 [공식] https://modelcontextprotocol.io/docs/learn/architecture : 호스트(연결을 조정하는 AI 앱 = ChatGPT) · 클라이언트(호스트 안에서 서버 하나와 연결을 유지하는 부품 · 서버마다 하나) · 서버(문맥과 기능을 내주는 프로그램 = 노션 MCP 서버). 서버가 내주는 것 3종: 도구 Tools(실행 기능) · 자료 Resources(문맥 자료) · 프롬프트 Prompts(재사용 틀). 전송: stdio(같은 컴퓨터) · Streamable HTTP(원격 · OAuth 권장).
- 노션 MCP: 노션이 운영하는 원격 MCP 서버 · OAuth 승인 뒤 사용 [공식] https://developers.notion.com/docs/mcp · 도구 예: 검색(search) · 읽기(fetch) · 페이지 만들기(create-pages) · 페이지 고치기(update-page) [공식] https://developers.notion.com/guides/mcp/mcp-supported-tools
- ChatGPT: MCP 공식 소개가 ChatGPT를 지원 클라이언트로 명시 [공식] · 쓰기 작업은 사람이 확인(승인)을 거친다 [공식] https://developers.openai.com/api/docs/mcp
- 플러그인과 MCP: 플러그인 = ChatGPT에 설치하는 묶음(스킬 + MCP 서버) · MCP = 그 안에서 노션과 주고받는 규격 [공식] https://developers.openai.com/plugins/concepts/plugins

## RAG (Retrieval-Augmented Generation · 검색 증강 생성)
- Lewis 외, "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks", arXiv:2005.11401, NeurIPS 2020 [공식] https://arxiv.org/abs/2005.11401 — 생성기(사전학습 언어 모델 · 매개변수 기억) + 검색기(신경망 검색기) + 문서 색인(위키백과 벡터 색인 · 비매개변수 기억). 동기: 모델 혼자서는 출처 제시·지식 갱신이 어렵다.
- 파이프라인 [공식] AWS https://aws.amazon.com/what-is/retrieval-augmented-generation/ · Azure https://learn.microsoft.com/en-us/azure/search/retrieval-augmented-generation-overview : ① 나누기(chunking — 큰 문서를 조각으로) ② 임베딩(조각을 숫자 벡터로) · 벡터 저장 ③ 찾기(질문을 벡터로 바꿔 가까운 조각 top-k) ④ 붙이기(찾은 조각을 프롬프트에 덧붙임) ⑤ 만들기(그 내용을 바탕으로 생성 · 출처 인용).
- 컨텍스트 창과의 관계: 모델이 한 번에 받는 글의 양(토큰)이 유한하므로 자료를 전부 넣지 않고 찾아서 필요한 조각만 넣는다(Azure).
- 장점: 재학습보다 저렴 · 최신·개인 자료 반영 · 출처 제시. 한계: 자료가 낡거나 찾기가 빗나가면 답도 빗나간다 → 원문 확인.
- 고전 RAG vs 에이전트형 검색: Azure가 「classic RAG(사전 색인 + 단일 질의)」와 「agentic retrieval(모델이 하위 질의를 계획해 도구로 검색)」을 구분. ChatGPT+노션 MCP는 모델이 질문할 때 노션 검색·읽기 도구를 부르는 에이전트형 쪽 · 같은 점은 찾기 → 붙이기 → 만들기(차이는 위 구분에서 추론).

## 시니어용 정의·비유 (리서처 제안 · 다듬어 쓸 것)
- MCP: ChatGPT가 노션 같은 앱과 주고받도록 정한 공개 규격 · 비유: 어느 기기든 꽂히는 USB-C 포트.
- 데이터베이스: 같은 칸을 가진 기록을 모아 골라 보고 정렬하는 표 · 노션에서는 행 하나가 페이지 하나 · 비유: 칸이 정해진 카드 상자.
- RAG: 답하기 전에 내 자료에서 관련 조각을 찾아 질문 곁에 붙이고 쓰는 방식 · 비유: 시험 때 펼쳐 보는 정리 노트.
- 에이전트: 목표를 받으면 필요한 도구를 골라 여러 단계를 진행하는 AI 프로그램 · 비유: 공구함에서 순서대로 도구를 꺼내 쓰는 작업대.
