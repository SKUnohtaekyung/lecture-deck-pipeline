## 4. 함정 (2026-10-20 실측)

- **인앱 브라우저가 숨겨져 있으면 `requestAnimationFrame`과 View Transition이 돌지 않는다.** 시간축 장은 `render(t)`을 직접 불러 재고(`window.FRAME_ORB.render/settle`), 이동은 `html.no-anim`을 켜서(전환 없이) 시험한다. 숨김 여부는 javascript_tool 시간 초과 메시지로 알 수 있다.
- **브라우저가 옛 덱을 캐시한다** — `await fetch(location.pathname,{cache:'reload'})` 뒤 주소 쿼리를 바꿔 다시 연다.
- **시간축 장에 CSS `transition`을 opacity · transform에 걸지 않는다** — 매 프레임 쓰는 값과 다퉈 반투명 · 14px 어긋남이 났다. 호버 떠오름은 `translate` 속성으로 따로.
- **시간축의 끝 시각은 마지막 효과(착지 빛 등)까지 덮게 계산한다** — 안 그러면 잔상이 남은 채 멈춘다.
- 스크립트로 장을 쓰면 슬라이드 사전 점검 훅(7항)이 주입되지 않는다. 마지막 확인은 Edit/Write로 연 상태에서 한다.
- 임시 파일은 저장소 안 `tmp/frame-실습강화/<단계>/`에만. 워커 프롬프트에도 적는다.
- 콘솔(cp949)에서 파이썬 한글 출력이 깨진다 — `PYTHONIOENCODING=utf-8`.
