## 0. 판단과 근거 (사용자 위임 범위 — 통보)

| # | 판단 | 근거 |
|---|---|---|
| J1 | **API 호출은 도구가, 결정과 일정은 에이전트가 한다.** `여행도구.html`이 세 창구를 부르고 요청 주소 · 상태 코드 · 응답 원문을 보여 준다. 에이전트는 `계획.js`(여행 · 화면 설정 · 일정)와 `확장.js`(내 기능 하나)만 쓴다 | Codex 무료 규칙 1 · 2(호출 주소를 에이전트가 짓지 않는다). 호출 코드를 약한 모델에 맡기면 키 노출 · 주소 오타 · CORS 오진이 수업을 멈춘다. 참가자는 요청과 응답을 **눈으로** 보는 쪽이 개념(A-1 · A-2) 학습에 맞다 |
| J2 | **도구 ↔ 에이전트 왕복은 「결과 복사」 한 길.** 도구는 파일을 쓸 수 없다(file://). 참가자가 도구의 「결과 복사」를 눌러 대화에 붙이면 에이전트가 `계획.js`를 고친다 | 규칙 5. 에이전트는 브라우저를 못 본다 — 이 왕복 자체가 「에이전트가 보는 것은 내가 건넨 것뿐」(C-10 컨텍스트)을 겪게 한다 |
| J3 | **관광지는 `locationBasedList2`(좌표 + 반경)**로 부른다. `areaBasedList2`(지역 코드)는 쓰지 않는다 | 2025년 개편 뒤 지역 코드 체계가 바뀌어(리서치 A-3) 코드표를 이름표에 넣으면 3KB를 넘는다. 좌표는 지명찾기(Nominatim)가 이미 준다 |
| J4 | **축제는 `searchFestival2`를 여행 시작일로 부르고, 도구가 거리(여행지에서 40km)와 종료일로 거른다.** 거른 개수를 화면에 보인다(「끝난 축제 n건 · 먼 축제 n건 뺌」) | A-5 「범위와 빈 값」을 화면에서 겪게 한다. 숨기지 않고 센다(눈먼 0 방지) |
| J5 | **일정에 들어가는 장소는 응답에 있던 것만.** 점검 패널이 일정 항목의 `contentid`를 담은 곳 · 응답과 대조해 없는 것은 「고칠 곳 — 지어낸 장소」로 센다 | 환각(C-04)을 앱 안에서 잡는 장치. 블록 3 「대조」 단계의 재료 |
| J6 | **날씨는 예보 범위 밖이면 「예보 없음」.** 평년값으로 채우지 않는다. 범위는 도구가 Open-Meteo의 400 응답 `reason`에서 읽어 보인다 | 2026-10-20 실측: `start_date` 범위 밖은 400 · `{"error":true,"reason":"Parameter 'start_date' is out of allowed range from 2026-07-18 to 2026-11-03"}` |
| J7 | **지도 타일이 안 오면 핀은 그대로, 바탕만 「지도 그림을 불러오지 못했습니다」.** file://에서 OSM 타일이 Referer 없음으로 막힐 수 있다(OSM 커뮤니티 2026-03 · 04 증언). 공개본(https)에서는 Referer가 간다 | 리서치 A-4. curl(브라우저 UA · Referer 없음)은 200이었다 — 브라우저 file:// 실측은 드라이런(사용자)에서 |
| J8 | **키는 화면 입력 칸 → localStorage(`frame.app.key`).** 소스 · `계획.js` · `확장.js`에 키 문자열이 들어가면 점검 패널이 「고칠 곳 — 키가 파일에 있음」 | D5. 공개본 키 0건을 기계로 센다. localStorage의 위험(같은 출처 스크립트가 읽음 · OWASP)은 A-3 · A-6 장에서 말한다 |
| J9 | **축제 메인 과제(D13)는 같은 도구를 `오프라인응답/`으로 돌린다.** 키 · 인터넷 없이 같은 화면. 장 6장 | 같은 재료를 두 벌 만들지 않는다 |
| J10 | 앱 트랙 전용 장은 **`variants/4h-app.html`**에 둔다. 메인 덱에서 다시 쓰는 `pr` 장(메인 과제 띠가 있는 장)은 같은 ID로 그 파일에 다시 적어 띠를 「여행 앱」으로 바꾼다 | `assemble_deck.py` 변형 조립: 그 파일의 장은 그 변형에만 들어가고 같은 ID는 대신한다 → 4h 덱 바이트 동일 유지 |

  화면: { 순서: ["날씨", "목록", "지도", "일정표"], 색조합: "바다", 첫화면문구: "" },
  일정: [ /* { 날: 1, 항목: [ { 시각: "10:00", 이름: "", contentid: "", 메모: "" } ] } */ ],
  하지않을것: []

## 3. `여행도구.html` 명세 (builder)

- 1280px 기준 · 375px에서 가로 넘침 0 · 외부 스크립트는 Leaflet 1.9.4(unpkg · CSS 포함) 1건 · 그 밖 설치 0.
- **위 띠**: 제목 · 여행지 · 날짜 · 모드 단추(실시간 / 오프라인 — 오프라인이면 「오프라인 응답 · 만든 시각」 표시, 예시 데이터면 「예시 데이터 — 실제 행사가 아닙니다」 띠).
- **키 칸**: TourAPI 키 입력 · 저장(localStorage `frame.app.key`) · 지우기 · 「키는 이 브라우저에만 저장됩니다」. 키가 없으면 축제 · 관광지 단추가 「키를 넣거나 오프라인으로」 안내.
- **창구 패널**(교육용 · 접기 가능): 창구마다 단추 · 마지막 요청 주소(키는 `●●●●`로 가림) · 상태 코드와 뜻(200 · 400 · 403 · 404 · 429 · CORS 실패 · 연결 실패) · 걸린 시간 · 응답 원문(JSON 들여쓰기 · 접기) · 「이 응답 복사」.
- **날씨 패널**: 여행 날짜마다 최고 · 최저 · 강수 확률 · 날씨 그림(WMO 코드 → 그림 6종). 범위 밖 날짜는 「예보 없음」과 400의 `reason`에서 읽은 허용 범위.
- **목록 패널**: 축제 · 관광지 탭 · 카드(사진이 없으면 그림 자리 · 이름 · 기간 · 주소 · 거리 · 좌표 없음 표) · 「담기」 · 거른 개수 줄.
- **담은 곳**: localStorage `frame.app.picked` · 빼기 · 「결과 복사」에 포함.
- **일정표**: `계획.일정`을 날짜별 열로. 항목의 날씨 아이콘은 그날 예보.
- **지도**: Leaflet · 여행지 중심 · 담은 곳(회색 핀) · 일정(날마다 색 · 번호 핀 · 선) · 타일 실패 시 J7 · 저작자 표시 「© OpenStreetMap contributors」 · 날씨 출처 「Weather data by Open-Meteo.com」 · 관광 정보 출처 「한국관광공사 TourAPI」.
- **확장 영역**: `window.여행앱확장(영역요소, 자료)`를 try로 부른다. 오류면 영역에 오류 문장 · 점검 패널 「고칠 곳」.
- **점검 패널**(고칠 곳 · 통과 · 미판정 개수 · 미판정은 통과에 넣지 않는다 · 「결과 복사」): ① `계획.js` 읽힘 ② 여행지 좌표 ③ 날짜 형식 · 순서 · 시작이 오늘 이후 ④ 창구 · 색조합 · 패널 이름이 이름표에 있음 ⑤ 키 상태(실시간에서 키 없음 = 미판정) ⑥ 날씨 수신 ⑦ 예보 없음 날짜 수(정보) ⑧ 축제 수신 · 거른 개수 ⑨ 관광지 수신 ⑩ 좌표 없는 항목 수(지도에서 뺌) ⑪ **일정 항목이 응답 · 담은 곳에 있는 contentid인가**(J5) ⑫ 일정 날짜가 여행 날짜 안 ⑬ 확장.js 오류 없음 ⑭ **파일에 키 문자열 없음**(J8 — `계획` · 확장 소스 문자열에 저장된 키가 들어 있으면 고칠 곳).
- **「결과 복사」 글**: 점검 결과 + 여행지 · 날짜 · 날씨 요약 · 담은 곳(이름 · contentid · 좌표 · 기간) — 에이전트가 일정을 짤 재료. 키는 넣지 않는다.
- 지명찾기 결과는 localStorage에 저장해 다시 부르지 않는다(Nominatim 캐시 의무 · 초당 1회).
- 감사 훅: `window.여행앱 = { 상태, 점검(), 호출(이름) }`.
