## 1. 실측 — API CORS (curl · 2026-10-20 · 이 PC)

브라우저가 다른 주소로 `fetch`할 때 상대 서버가 `Access-Control-Allow-Origin`으로 허락해야 한다. 더블클릭으로 연 HTML은 Origin이 `null`이다.

| 대상 | 요청 | 응답 | 판정 |
|---|---|---|---|
| Open-Meteo `api.open-meteo.com/v1/forecast` | Origin: null | 200 · `access-control-allow-origin: *` | 키 없이 · file:// · 공개본 모두 가능 |
| Nominatim `nominatim.openstreetmap.org/search` | Origin: null · UA 지정 | 200 · `*` | 가능(이용 규칙: 1초 1회 · 식별 가능한 UA 또는 Referer) |
| TourAPI 4.0 `apis.data.go.kr/B551011/KorService2/areaCode2` | Origin: null | 403(가짜 키) · `Access-Control-Allow-Origin: null` | **Origin 반사** → file:// 가능 |
| 같은 서버 | Origin: http://localhost:8080 | 403 · `…: http://localhost:8080` | 반사 확인 |
| 같은 서버 `searchFestival2` | Origin: https://example.netlify.app | 403 · `…: https://example.netlify.app` | **Netlify 공개본에서 가능** |
| 표준데이터 API `api.odcloud.kr/api/15013104/v1/…` | Origin: null | 404(uddi 가짜) · `*` | 가능 |
| OSM 타일 `tile.openstreetmap.org/10/876/402.png` | Origin: null | 200 · `*` | 지도 타일 가능 |
| Leaflet `unpkg.com/leaflet@1.9.4/dist/leaflet.js` | — | 200 | CDN 1건 |

403 · 404는 키·식별자가 가짜라서 난 것이고 CORS 헤더는 그와 무관하게 왔다. **키를 넣은 실제 응답은 미확인**(사용자 키 필요).

## 2. Codex(OpenAI) — 공식 문서

- **요금제**: OpenAI 도움말 「Using Codex with your ChatGPT plan」 — Codex는 Free · Go 포함 전 요금제에 포함. 클라우드 작업(Codex Cloud)은 Free · Go 미포함. 가격 페이지: Free는 **데스크톱 앱에서 GPT-6 Luna · Standard 속도**(롤아웃 조건). 한도는 요금제별로 다르며 Free의 수치는 비공개. 구조는 5시간 창 + 주간 상한(3자 블로그 종합 — 수치는 신뢰하지 않는다).

- **스킬**: https://learn.chatgpt.com/docs/build-skills — 저장소 `.agents/skills`(작업 폴더에서 루트까지 스캔) · 사용자 `$HOME/.agents/skills` · 시스템(`skill-creator` · `plan` 내장). 호출: 설명 매칭(암묵) · `$이름`(CLI · IDE) · `@이름`(ChatGPT). 「Codex detects skill changes automatically. - **MCP**: https://learn.chatgpt.com/docs/extend/mcp?surface=app — 데스크톱 앱 Settings → MCP servers → Add server(이름 · STDIO 또는 Streamable HTTP · 명령/URL) → Save → Restart. OAuth(CIMD · DCR) 지원 · 「Authenticate」 버튼. 설정은 `~/.codex/config.toml` 공유. 요금제 제한 언급 없음.
