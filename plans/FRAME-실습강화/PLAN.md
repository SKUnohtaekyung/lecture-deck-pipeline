## 4. 설계

### 4-0. 실습 허브 리디자인 — 「궤도에서 정렬로」 (R6 · 디자이너 판단 — 통보)

**현행(10-07 판)의 문제**: 순수 검정(`#000`)과 사실적인 행성 텍스처는 덱의 어느 장과도 다른 제품처럼 보인다. 공전하는 행성에 이름표가 따라붙어 **이름표가 행성 · 태양 · 서로와 겹친다**(2026-10-20 화면: 「01 프로젝트 실…」이 태양에 가려 잘림 · 06 · 08 이름표가 행성 위에 겹침). 이 장의 일은 **실습 10개를 비교해 하나를 고르는 것**인데, 돌고 있는 동안은 비교가 안 된다. 행성이 10개로 늘면 더 겹친다.

**판단: 우주와 3D 궤도는 남긴다 — 단 「보여 주는 첫 3초」에만. 그다음 행성들이 궤도를 떠나 고를 수 있는 판으로 정렬된다.** 10-07에 원한 우주 · 행성 · AI 비서 화면의 감각은 오프닝에서 살고, 고르는 시간에는 읽힌다. 색과 모양은 덱으로 돌아온다. **가운데 별은 FRAME 마크**다 — 표지에서 모서리 넷이 모이던 그 틀이 이 우주의 태양이 된다.

| 장면 | 무엇이 보이나 | 뜻 |
|---|---|---|
| **① 점화(0.8초)** | 깊은 페트롤 우주(`--t-dark` 위에 별 점 몇십 개 · `--t-dark-soft` 낮은 불투명도 · 그라디언트 없음). 가운데서 **FRAME 모서리 네 개가 안쪽으로 모이고**, 아쿠아 사각형 핵이 켜지며 빛 고리(`--t-glow`)가 한 번 퍼진다 | 표지의 연출이 이어진다 — 같은 덱 |
| **② 궤도(약 2초)** | 기울어진 타원 궤도 두 줄이 그려지고(선 · `--t-dark-2`), **행성 9개가 궤도를 따라 돈다.** 행성은 평면 원판(`--t-dark-2` · `--t-dark-3`) 위에 **결과물 선 아이콘**(아쿠아 선 — 칸반 · 노드 · 말풍선 · 막대 · 세로 프레임 · 종이 묶음 · 물음표 · 슬라이드 · 정사각 카드). 앞쪽은 크고 밝게, 뒤쪽은 작고 옅게(z 정렬 · 크기 · 흐림) — 사실적 텍스처 없이 3D | 우주의 감각. 이름표는 아직 없다(겹침이 생길 자리를 원천에서 없앤다) |
| **③ 정렬(0.9초)** | 행성들이 **궤도를 떠나 곡선으로 날아가** 5열 판(5 + 4)의 자리로 내려앉는다(번호 순 · 60ms 간격). 내려앉는 순간 행성 아래로 **이름 카드가 펼쳐진다**(번호 · 이름 22px · 한 줄 설명 18px). FRAME 별은 작아져 제목 왼쪽 로고 자리로 들어간다 | 「오늘 고를 열 가지」가 한눈에 선다 — 가장 큰 wow를 고르는 화면으로 넘어가는 순간에 둔다 |
| **④ 비교(호버 · Tab)** | 올린 카드가 떠오르며 아쿠아 테두리가 켜지고, 행성에 고리가 생기며 아이콘 선이 한 번 다시 그려진다. **나머지 카드는 흐리게 하지 않는다**(가독성 · 2026-10-20 사용자 지적). 방향키는 덱의 장 넘김이라 쓰지 않고 Tab · Enter로 고른다 | 비교 중인 하나를 또렷하게 |
| **⑤ 선택** | 고른 행성이 **화면을 채우며 다가오고**(View Transition · 현행 `data-vt-key`) 그 실습 첫 장으로 이어진다 | 「이 행성으로 간다」 |

**가르치는 흐름 — 리서치 → 디자인시스템 → 일관 생성 → 조립 → 공개.** 강사는 **AI 최신 뉴스**로 시연하고, 참가자는 **자기 주제**로 같은 흐름을 밟는다. 교안 스킬(§4-2)과 같은 흐름이다. AI 크레딧 0회(Canva 무료는 월 AI 20회 공유).

| 단계 | 강사 시연(AI 최신 뉴스) | 참가자(내 주제) |
|---|---|---|
| ① 리서치 | 에이전트 웹 검색 → 출처 원문 확인 → `사실카드.md`(사실 5 · 날짜 · 출처 URL · 인용 15자 이내) | 웹 검색이 되는 도구면 같은 절차, 아니면 「사용자가 말함」 사실 3~5개 |
| ② 디자인시스템 | `design.md` — 색 3 · 글꼴 2(Canva 무료 한글 글꼴 이름 · 실측 후) · 1080×1080 · 카드 틀 3종(표지 · 본문 · 마무리)의 자리 규칙 | 같은 양식 · 색 분위기는 인터뷰에서 |
| ③ 일관 생성 | `원고.md` — 장 4~6 전부 같은 규칙: 제목 ≤ 12자 · 본문 ≤ 40자 · 그림 키워드 2 · 틀 이름 · 출처. 에이전트가 글자 수 · 색 · 글꼴을 스스로 점검 | 같은 양식 |
| ④ 조립(Canva 무료) | Brand Kit에 색 3 등록 → 「Instagram 게시물」 → 표지 1장을 틀대로 만들고 **페이지 복제** → 본문 장은 글만 교체 → 무료 요소만 → PNG 내보내기 | 같은 절차 |
| ⑤ 공개 | 「이 PNG를 넘기며 보는 모바일 페이지」 → `카드틀.html` + `카드.js`(대체 글 = 원고) → 공개 | 같은 절차 |
| 선택 | Canva AI 1회로 Magic Write 비교 · ChatGPT Canva 앱 | 되는 사람만 |

- **인터뷰(세 개씩)**: 주제 · 보는 사람 · 장 수 / 꼭 들어갈 사실 · 색 분위기 · 마지막 장의 행동 하나.
- **준비물**: 품질기준 · 사실카드 · design · 원고 양식 3 · `카드틀.html` + `카드.js` · 캔바 단계 캡처(수업 직전 · 메뉴 이름 대신 「무엇을」) · **강사 시연은 산출물이 아니라 절차서**(뉴스는 낡는다 — 수업 전날 다시 리서치).
- **덱**: `P9-C` 「에이전트와 디자인 도구의 분업」 · `P9-C2` 「리서치 → 디자인시스템 → 일관 생성」(교안 스킬과 같은 흐름 그림) · `P9-1~3`.
- **합격**: 원고 글자 수 위반 0 · Canva 무료로 ④ 완료(사용자 실측) · PNG 페이지가 더블클릭 · 공개 동작 · AI 크레딧 0 · 시연 사실 5개 전부 출처 URL.
