# 3차시 업무 프롬프트 공유 자료 — 구현 기록

## 목적

3차시 마무리에서 학습자가 오늘의 결과물 제작 방식을 실제 업무에도 적용할 수 있음을 보여 주기 위한, 공개 배포 가능한 단일 HTML 자료를 만든다. GPT Sites에는 이 파일을 사용자가 별도로 게시한다.

## 구현 결정

- 산출물: \`courses/AI_코딩_에이전트_입문_3차시/sessions/3주차/자료/AI_업무_프롬프트_10개.html\`
- 디자인: 기존 덱의 blue / mint / coral / ink 토큰과 VIBECODING 워드마크를 사용하되, 1280×720 발표 화면이 아닌 읽기 중심 문서 레이아웃을 사용한다.
- 탐색: 데스크톱은 고정 좌측 목차, 모바일은 가로 스크롤 목차로 10개 섹션 앵커에 직접 이동한다.
- 복사: 각 버튼은 대응하는 프롬프트 본문 \`textContent\`만 복사한다. Secure Context의 Clipboard API가 실패하거나 \`file://\`처럼 사용할 수 없으면 textarea + \`execCommand('copy')\`를 시도한다. 두 경로 모두 실패하면 해당 본문을 선택하고 수동 복사 안내를 표시한다.
- 공개 배포: 외부 폰트·스크립트·이미지·API·분석 도구를 불러오지 않는다. 공식 OpenAI 정보는 문서 링크만 제공한다.

## 포함 범위

- 사용자가 제공한 10개 프롬프트 전문과 대괄호 입력 자리표시자
- 각 프롬프트의 개별 복사 버튼·키보드 포커스·상태 메시지
- OpenAI Help Center 근거의 보완 원칙 3개

## 검증 기록

실행 결과는 작업 완료 시 아래에 추가한다.

| 확인 | 방법 | 결과 |
|---|---|---|
| 프롬프트/복사 제어 수 | Node 정적 검사 | PASS — 프롬프트 10개, 복사 제어 10개 |
| 앵커/상대 의존성 | Node·PowerShell 정적 검사 | PASS — 앵커 10개, 외부 asset 의존성 0개 |
| JavaScript 구문 | Node \`new Function()\` | PASS |
| 데스크톱/모바일 화면 | 브라우저 검사 | 보류 — 서브에이전트 스레드에서 인앱 브라우저 가시 미리보기가 지원되지 않음 |

## 게시 전 수동 확인

1. GPT Sites에 HTML을 올린 뒤 공개 URL에서 10개 복사 버튼을 각각 한 번씩 누른다.
2. 일반 창과 시크릿 창에서 링크가 열리는지 확인한다.
3. 좁은 모바일 화면에서 목차와 코드 블록이 가로 넘침 없이 읽히는지 확인한다.
4. 회사 자료를 실제로 붙일 때 사내 AI 사용 기준을 다시 확인한다.
