# 3차시 업무 프롬프트 공유 — 실행 계획

## 목적과 범위

3주차의 마지막 결과 확인 뒤, 실습을 추가하지 않고 “오늘 배운 입력·기준·결과물 설계는 내 업무에도 옮길 수 있다”는 전이를 만든다. 수강생이 복사해 쓸 수 있는 단일 HTML 자료를 제공한다. Sites 공개 배포는 사용자가 수행하므로 이 작업에는 포함하지 않는다.

## 산출물

1. `3주차/강의덱.초안/`에 마무리 슬라이드 2장 추가 후 조립한다.
   - 장 1: 오늘 만든 흐름(자료 → 기준 → 결과물 → 확인)을 회의록·조사·자동화 설계·메일·기획·보고서·계획·비교·성과평가·인수인계로 확장해 보인다. 10개를 읽거나 실습시키지 않는다.
   - 장 2: “내일 할 일 하나를 골라 쓰기”로 끝낸다. 대괄호를 채우고 관련 자료를 첨부하며 결과를 원자료/기준과 대조한다는 3단계를 제시하고, 별도 HTML 자료 경로를 안내한다.
2. `3주차/자료/AI_업무_프롬프트_10개.html` 한 파일을 만든다.
   - 사용자 제공 10개 프롬프트 전문을 빠짐없이 담고, 각 항목에 독립 복사 버튼과 성공/실패 상태를 제공한다.
   - 노션처럼 읽히는 문서형 화면을 기존 3주차 덱의 색·서체·라운드·강조 체계에 맞추되, 데크 UI를 그대로 이식하지 않는다.
   - 공식 OpenAI 추가 팁은 사용자가 제공한 원문과 구획을 분리해 “공식 OpenAI 문서에서 확인한 활용 원칙”으로만 넣는다. 모델 성능·가격·제공 여부 주장은 넣지 않는다.
3. 정적/상호작용 QA를 수행한다.
   - 10개 제목·전문·복사 버튼 수, 공식 링크 3개와 출처 표기, 금지된 내부 경로·개인정보·미확인 모델 주장 유무를 점검한다.
   - HTTPS/Sites에서 동작하는 Clipboard API 경로와 접근 거부/미지원 시 `execCommand` 폴백, 그리고 최종 수동 선택·복사 안내 경로를 검사한다.
   - 브라우저에서 데스크톱과 좁은 화면의 읽기·키보드·복사 상태를 확인한다.

## 수용 기준

- 덱은 기존 실습 및 시간표를 바꾸지 않고 마무리에서 약 2~3분만 사용한다.
- 자료는 외부 스크립트·폰트·분석 도구 없이 한 HTML 파일로 열리고, 공개 Sites에 올려도 내부 경로·비밀값이 없다.
- 모든 프롬프트는 선택 없이 복사되며, 실패해도 사용자가 직접 복사할 수 있게 텍스트가 노출된다.
- 2026-09-11에 실제로 연 일반 사용자용 공식 OpenAI Help Center 페이지 3개가 제목·정확한 URL·해석 가능한 주장과 함께 표시된다.
