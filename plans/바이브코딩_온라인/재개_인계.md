## 0. 새 PC에서 처음 한 번 (환경 준비)

```bash
git pull
python scripts/install_hooks.py
```

```bash
PYTHONUTF8=1 python -m pip install -r requirements-dev.txt
```

- `install_hooks.py`는 클론마다 한 번 필요하다(`core.hooksPath=.githooks`). 확인: `python scripts/verify_skill_setup.py` → `RESULT | PASS`.
- `requirements-dev.txt`에 한글 주석이 있어 Windows cp949 환경에서는 `PYTHONUTF8=1` 없이 pip가 실패한다.
- 과목이 3개라 검사 스크립트는 **반드시** `CREATE_SLIDES_COURSE=바이브코딩_온라인`을 붙이고, 주차 인자는 숫자(`1`·`2`)로 넘긴다.
- 렌더 감사용 로컬 서버: 저장소 루트에서 `python -m http.server 8799` (Claude 데스크톱 앱이면 `.claude/launch.json`의 `deck-verify`).
