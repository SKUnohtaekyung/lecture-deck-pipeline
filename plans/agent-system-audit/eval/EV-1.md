# EV-1 — 열린 일 조회

개편 전후에 같은 프롬프트·같은 모델(Sonnet, `general-purpose` 서브에이전트)·3회씩 돌린다. 서브에이전트는 이 저장소의 `CLAUDE.md`→`AGENTS.md`를 자동으로 읽는다. 프롬프트는 어느 파일을 보라고 알려 주지 않는다.

한계: 메인 세션(Opus)이 아니라 서브에이전트로 잰다. 개편 전후의 상대 비교에만 쓴다.

## 프롬프트 (글자 그대로)

```
이 저장소에서 지금 열려 있는 일을 정리해 줘. 파일은 읽기만 하고 아무것도 수정하지 마.

1. 사용자가 결정하거나 자료를 줘야 진행되는 일 — 전부
2. 에이전트가 사용자 입력 없이 바로 할 수 있는 열린 일 — 전부
3. 이미 끝났는데 문서에는 아직 열린 일처럼 적혀 있는 것을 발견했다면 따로

각 항목에 근거(파일 경로와 줄 번호)를 붙여. 3000자 이내의 목록으로 답해.
`plans/agent-system-audit/` 폴더와 `tmp/` 폴더는 이 질문을 채점하려고 만든 자료이니 열지도 인용하지도 마.
```

프롬프트 v1(마지막 줄 없음)은 폐기했다. v1 1회차 답이 `plans/agent-system-audit/`의 감사 문서를 근거로 인용했고, 그 폴더에 이 채점 키가 있어 개편 후 측정이 오염되기 때문이다. v1 답은 전문을 보관하지 않고 채점만 `pre_v1_notes.md`에 남겼다. 비교에 쓰지 않는다.
