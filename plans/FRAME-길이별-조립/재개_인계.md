- 품질기준에 숫자: 한 장면 한 메시지 · 2 ~ 3초마다 화면 변화 · 색 3 · 글꼴 2 · 글자 수에 맞는 읽기 시간.
- 가르칠 영상 문법: 훅(첫 1 ~ 3초) → 맥락 → 본문 → 결말 → CTA(마지막 3 ~ 5초, 행동 하나). AI에게 넘길 정보: 목적 · 시청자 · 길이와 비율 · 장면표 · 화면 글자 · 분위기 · 근거 수치.
- 참고: OpenAI 「Designing delightful frontends with GPT-5.4」(디자인 시스템을 먼저 주고 색 · 움직임을 지어내지 않게) · Remotion/HyperFrames 계열 가이드(구간을 정확히 적기).

**API와 MCP 장(P5 · 약 10분 · 5장)** — ① API 정의(프로그램이 다른 프로그램에 정해진 형식으로 요청하고 답을 받는 창구 · 비유 가게의 주문 창구) ② API 실물(공공데이터 주소를 넣으면 답이 오는 화면 · 강사 시연) ③ MCP 정의(AI 에이전트가 외부 도구와 데이터에 연결하는 공통 규격 · 비유 규격이 통일된 콘센트) ④ 차이표(누가 쓰나 · 사용법 · 정해 두는 것 · 연결 방법 · 무엇을 쓸지 정하는 쪽)와 「API 위에 MCP」 층 그림 — **둘은 경쟁 관계가 아니다** ⑤ 오늘 만든 앱에 대입(파일을 실시간으로 바꾸려면 API · 에이전트가 내 캘린더에 일정을 넣게 하려면 MCP). 세 도구의 MCP 연결 화면은 공식 문서로 확인 전이다.

## 8. 함정

- **`CREATE_SLIDES_COURSE`를 켠 채 회귀 테스트를 돌리면 4건이 ERROR다.** 회귀는 변수 없이 돌린다(346건 OK).
- **장을 추가 · 삭제 · 개명하면 함께 고칠 것**: `variants/4h.txt` · `2h.txt` · `minutes.tsv` · `deck.contract.json`(두 덱의 장수와 순서) · `1주차_초안.md` 행 → 재조립 → 노트 재생성 → 재측정.
- **`deck.contract.json`은 줄바꿈이 섞여 있다.** `json.dump`로 다시 쓰면 파일 전체가 바뀐다. 문자열 치환으로 필요한 줄만 고친다(선례 `tmp/review-fix/merge.py`).
- **결정 이력을 열기 전에 「오개념」으로 고치지 않는다.** 하네스 그림을 그렇게 바꿨다가 이전 결정과 부딪혔다(§3-2). `plans/FRAME-개편/PLAN.md`와 `자료/개념노트.md`를 먼저 본다.
- **워커 운영**: part 파일마다 작업자 하나(단일 라이터). `shell.html`을 고칠 수 있는 작업자는 한 번에 하나. 초안은 작업자가 직접 고치지 않고 `tmp/<폴더>/*_초안행.md`에 행을 적게 한 뒤 메인이 병합한다. 「임시 파일은 저장소 안 tmp/에만」을 프롬프트에 적는다.
- **스크립트로 장을 쓰면 슬라이드 사전 점검 훅(7항)이 주입되지 않는다.** Edit/Write로 고칠 때만 뜬다.
- **인앱 브라우저 스크린샷이 불안정하다**(창 크기 에뮬레이션 중에는 덱이 작게 그려지고, 자주 시간 초과). 판정은 `audit_all.js` 수치로 하고, 화면은 사용자 육안 확인을 요청한다.
- `강의덱.html` 쓰기가 「액세스 거부」로 실패하면 브라우저 창이 파일을 잡고 있는 것이다. 다시 실행하면 된다.
- `verify_report_freshness.py`는 주석 안의 예시까지 장으로 세어 1장 많게 나온다(러너의 같은 결함은 고쳤다).
- `tmp/`는 gitignore다. `tmp/공공데이터시험/` · `tmp/review-fix*/` · `tmp/frame/rev/gen_docs.py`(옛 초안 생성기 · 84장 기준)는 이 PC에만 있다.
