## ③ 「가능한데 없음」 갭 상위 목록

1. **레이아웃·배치 렌더 판정 부재** — `verify_deck.py`/`verify_deck_quality.py` 어디에도 좌표·여백·정렬·겹침을 계산하는 함수가 없다(DEC-03로 헤드리스 브라우저 자체 미도입). `run_deck_checks.py`는 사람이 만든 `deck-audit.json`의 **존재 여부**만 강제하고 그 안 수치를 게이트에 안 쓴다(스크립트: `run_deck_checks.py` 주석 41-47). → `audit_all.js`가 이미 뽑는 좌표값에 여백/정렬 임계치를 걸어 `run_deck_checks.py`가 판정에 반영하면 125건 중 상당수(여백 확보·정렬·위치이동류)가 잡힌다.
2. **초안 대비 콘텐츠 삭제/보존 게이트가 꺼져 있음** — `check_title_survival.py`는 로직은 있으나 기본 WARN이고 pre-commit·run_deck_checks 어디서도 `--strict` 호출을 안 함. `report_draft_sync.py`는 애초 `sys.exit(1)`이 없어 "있는데 상시 통과"다. → 두 스크립트를 `run_deck_checks.py`에 `--strict`로 편입하면 236건 중 "유지/삭제 확정" 계열 일부가 잡힌다.
3. **구조 패턴 버그(예: 헤더 훅 누락) 전용 검사 없음** — B-734류(특정 CSS 클래스가 붙어야 할 자리에 없음)는 `find_sections`(verify_deck.py:567)가 이미 절 구조를 파싱하므로 같은 방식으로 "필수 클래스 존재율" 검사를 추가하면 즉시 자동화 가능.
4. **타이포 토큰 이탈 전용 리포트 없음** — `verify_declared_vs_enforced.py`는 kit 선언 vs CSS 집행의 **불일치**만 보고, 어떤 슬라이드가 임의 폰트 크기/굵기를 썼는지 슬라이드 단위로 안 짚는다. 슬라이드별 리포트로 세분화하면 B-300류(폰트·볼드 다운) 일부가 걸린다.

## 확인 불가

- `.githooks/_gate.py` 전체 로직(258줄 이상) 중 kit/skill/notes 3개 경로 외 조건부 분기는 상세 미확인(시간 예산상 상위 훅 배선만 확인).
- `scripts/verify_required_statements.py`·`verify_subject_isolation.py`·`verify_skill_setup.py`·`verify_research_chunks.py`·`verify_session_docs.py`·`verify_draft_quality.py`는 함수 목록만 확인했고 세부 로직(정규식·임계값)은 3000자 예산상 미상세화 — 덱 콘텐츠 자체보다 스킬/리서치 산출물 구조 검사로 판단되어 매트릭스 판정에는 영향 없음.
