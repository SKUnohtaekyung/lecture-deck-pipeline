## ① kit 색 토큰 하드결합도 → **97%는 토큰 스왑으로 해결 · 전면 복제 불필요, 차단 4요인**

- `var(--*)` 참조 441건(deck.css 286 · patterns.css 155) vs raw hex는 **100% `:root` 격리**(27건).
  유출은 `rgba()` 36건뿐(전부 box-shadow/border — 블루 계열 11 · ink 15 · 흰색 12). 카탈로그
  71종(레이아웃 50·차트 21)의 raw hex는 실질 0.
- **토큰 이름이 의미역이 아니라 색상명**(`--blue`·`--mint`·`--coral`…)이고 역할 토큰 층
  (`--accent`/`--action`/`--warn`류)이 없다. 카탈로그·차트 문서에 한국어 색 단어 서술 **254회** —
  보라 테마에서 `--blue:#7C3AED`가 되면 문서가 거짓말이 된다.
- **차단 4요인**: ⑴ `verify_deck.py:1786` `need_tokens`가 **hex 값을 하드코딩**(토큰 값 변경 즉시
  FAIL — 검사 전환 필수) ⑵ rgba 36건 중 브랜드색 11건 ⑶ `kit/starter/logo.svg` 3 hex +
  스타터 favicon data-URI 3 hex(원리적으로 `var()` 불가 — 테마당 복제) ⑷ 색 단어 문서 254회.
- 권고(워커): `:root`에 역할 토큰 층을 한 겹 올리고 기존 색상명 토큰은 별칭으로 유지 → 과목
  테마 파일은 역할 토큰 ~12개만 재선언. `rgba()`는 `color-mix()`/글래스 토큰으로 흡수,
  verify는 «값 고정» → «토큰 존재 + 대비비» 검사로 전환.

## ③ 배포본 재생성 비용 → **신규 과목 시나리오 = 0 · 위험은 kit 전역 `:root` 수정**

- 산출물 12파일 ≈214MB — 배포본+발표본이 99.5%(base64 팽창이 조각 1.1MB의 약 200배).
- 정본 덱 3건은 kit CSS를 `<link>` 참조하고 **인라인 로고 SVG조차 `var()` 참조**라, 색 테마는
  재조립 0으로 자동 반영된다. **그래서 위험**: kit 전역 `:root`를 고치면 동결 1~3주차 정본
  덱의 렌더가 파일 무수정인 채 바뀌고(동결 위반), CSS가 굳은 배포본과 213MB 드리프트가 난다
  → **테마는 반드시 과목 스코프**(P7 권고 (B)와 독립 실측으로 재확인됨).
- 로고: 조각에 인라인 `svg.s-logo` **241개** + `VIBECODING` 문자열 247건 하드코딩. 기존 주차는
  안 고쳐도 되지만, **신규 과목 조각은 `<use href="#logo">`(단일 정의) 구조**로 시작할 것.

## ④ 표지·챕터 소재와 다과목 지뢰 → **테마 축은 조각이 아니라 deck.css+shell JS · 지뢰 3곳**

- 표지(`.cover`)는 shell 내장, PART divider는 part 조각 머리 + **shell JS `hydratePartDivider()`가
  도형·도트를 런타임 생성**(shell마다 복제됨). 스타일 정본은 patterns가 아니라 `deck.css`.
- 열린 축 부채: `kit/starter/presenter-notes-template.html`이 `:root` 팔레트를 **hex로 미러**
  (테마 시 첫 동기화 부채) · 터미널 계약이 2곳으로 분리(`.cover-terminal` 라이트 vs
  `.terminal-dark`) · 차트 팔레트 규칙은 문서 한 줄 · **profile §5 브랜드 필드 3개뿐**(색·폰트·
  표지 구도·divider 톤 필드 없음 — 스키마 확장 필요).
- **다과목 지뢰 3곳**(두 번째 과목 추가 즉시 발화): ⑴ `_course_paths.py` — `guide_path()`/
  `profile_path()`는 후보 >1이면 `None`(훅 침묵 — MEMORY 기등재), `session_dir()`류는
  `_first_existing`으로 **첫 과목을 조용히 집음** ⑵ `course` 훅이 파일 경로를 게이트로만 쓰고

  ⑶ `verify_subject_isolation.py`는 md만 스캔(CSS·starter·logo.svg 사각지대)이고 프로필이
  1개일 때만 동작 — 다과목이면 **전체 SKIP으로 조용히 통과**.
