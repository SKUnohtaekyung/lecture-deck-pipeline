# 주석 스크린샷 element (Annotated Screenshot)

> 정보 모양 `screen-operation`(실습 화면 조작 안내)용 element. **캡처는 사람이, 번호·테두리 overlay는 킷이 코드로.**
> whole-slide가 아니라 host 레이아웃(`L-dc-annotated`·`L-vf-numbered-stack`·`L-dc-hero`)에 얹는 fragment.

## 무엇인가
실제 화면 캡처 이미지 위에 **번호 배지(①②③)** 와 **강조 테두리 박스**를 얹어 "이 버튼 → 저 메뉴 → 클릭"을 짚는다. "여기" 대신 실제 버튼명·위치.

## data_shape · capacity
- 한 화면에 짚을 지점 **3~5개**(6개↑면 리더선/배지 혼잡 → 화면을 나눔).
- 배지·캡션 텍스트 ≥22px(가독성 하한). 배지는 대상이므로 `--blue`(색 문법: 강조/대상).
- 여러 화면 단계면 host를 `L-vf-numbered-stack`으로 세로 나열, 각 단계에 미니 캡처 + 캡션.

## element_vs_slide
- **fragment** = `.shot-annot`(프레임 + 캡처 `<img>` + 절대배치 `.shot-badge`/`.shot-hl` overlay + 캡션). whole-slide 아님.
- **host(별도)** = `L-dc-annotated`(한 화면 여러 지점)·`L-vf-numbered-stack`(여러 화면)·`L-dc-hero`(단일 화면 크게). host가 eyebrow·제목을 얹는다.

## 핸드오프
1. 계획서 `화면 캡처` 항목의 화면·단계·강조 위치(번호)를 읽는다.
2. **캡처는 사용자가** 실제 화면을 찍어 `img/`에 둔다(이 스킬은 캡처하지 않음).
3. 킷이 그 위에 배지·테두리 overlay를 코드로 얹는다. 배지 `top/left`, 테두리 박스 `top/left/width/height`는 캡처의 강조 지점에 맞춰 인라인.
4. `<figcaption>`에는 “1. 버튼명 → 2. 메뉴명 → 3. 결과”처럼 **의미가 있는 단계 문장**을 쓴다. “여기 클릭”만 쓰지 않는다.

## 공용 CSS와 표준 마크업
CSS 정본은 [`../styles/deck.css`](../styles/deck.css)의 `.shot-*` 블록이다. 배지와 캡션은 모두 **22px 이상**이며 개별 덱에 복제하지 않는다.

```html
<figure class="shot-annot" aria-label="화면 조작 3단계">
  <div class="shot-frame">
    <img src="자료/screenshots/folder-menu.png"
      alt="바탕화면 메뉴에서 새로 만들기를 거쳐 폴더를 선택하는 세 단계">
    <span class="shot-badge" style="left:12%;top:24%" aria-hidden="true">1</span>
    <span class="shot-hl" style="left:20%;top:20%;width:34%;height:12%" aria-hidden="true"></span>
  </div>
  <figcaption class="shot-caption"><strong>1.</strong> 바탕화면 우클릭 → <strong>2.</strong> 새로 만들기 → <strong>3.</strong> 폴더 선택</figcaption>
</figure>
```

## 캡처가 아직 없을 때 (목업 폴백)
실제 캡처 전이라면 데모(`데모_제작규칙.html`)의 **목업 창** 변형으로 자리를 잡는다 — `.shot-win`(타이틀바 + 메뉴 행) + `.shot-row.on`(강조 행) + `.shot-badge.b1/.b2/.b3`(행에 정렬된 번호). 실제 캡처가 오면 목업을 `<img>`로 교체하고, 목업 상태는 최종 배포하지 않는다.

## a11y
`<figure>`의 `aria-label`, 관계를 설명하는 이미지 `alt`, 실제 `<figcaption>`을 함께 쓴다. 번호 배지·강조 박스는 캡션과 중복되므로 `aria-hidden="true"`로 숨긴다.
