# 주석 스크린샷 element (Annotated Screenshot)

> 정보 모양 `screen-operation`(실습 화면 조작 안내)용 element. **캡처는 사람이, 번호·테두리 overlay는 킷이 코드로.**
> whole-slide가 아니라 host 레이아웃(`L-dc-annotated`·`L-dc-hero`)에 얹는 fragment.

## 무엇인가
실제 화면 캡처 이미지 위에 **번호 배지(①②③)** 와 **강조 테두리 박스**를 얹어 "이 버튼 → 저 메뉴 → 클릭"을 짚는다. "여기" 대신 실제 버튼명·위치.

## data_shape · capacity
- **한 슬라이드 = 조작 단계 1개**(커리큘럼 기준안 §6 원칙 9 "한 화면에는 한 단계만 보여준다"). 단계가 3개면 슬라이드도 3장이다. 밀도 하한(정보 단위 3~6개)은 이 정보 모양에 적용하지 않는다.
- **단계 ≠ 지점.** 한 단계 안에서 시선이 가야 할 지점은 **1~3개**까지 짚을 수 있다(예: 권한 창에서 폴더 이름을 확인하고 허용 버튼을 누른다 = 1단계·2지점). 4개↑면 그건 대개 단계가 섞인 것이니 슬라이드를 나눈다.
- 배지·캡션 텍스트 ≥22px(가독성 하한). 배지는 대상이므로 `--blue`(색 문법: 강조/대상).
- **여러 단계를 한 슬라이드에 세로로 나열하지 않는다.** `L-vf-numbered-stack`을 조작 안내의 host로 쓰지 않는다 — 단계마다 슬라이드를 만들고 host는 `L-dc-hero`(단일 화면 크게) 또는 `L-dc-annotated`(한 단계·여러 지점)를 쓴다. 전체 흐름 요약이 필요하면 조작 슬라이드들 **앞에** 개요 슬라이드 1장을 따로 둔다.

## element_vs_slide
- **fragment** = `.shot-annot`(프레임 + 캡처 `<img>` + 절대배치 `.shot-badge`/`.shot-hl` overlay + 캡션). whole-slide 아님.
- **host(별도)** = `L-dc-annotated`(한 단계·여러 지점)·`L-dc-hero`(단일 화면 크게). host가 eyebrow·제목을 얹는다. 여러 단계를 담는 host(`L-vf-numbered-stack` 등)는 쓰지 않는다.

## 핸드오프
1. 계획서 `화면 캡처` 항목의 화면·단계·강조 위치(번호)를 읽고, **단계 수만큼 슬라이드를 나눈다**.
2. **캡처는 사용자가** 실제 화면을 찍어 `img/`에 둔다(이 스킬은 캡처하지 않음).
3. 킷이 그 위에 배지·테두리 overlay를 코드로 얹는다. 배지 `top/left`, 테두리 박스 `top/left/width/height`는 캡처의 강조 지점에 맞춰 인라인.
4. `<figcaption>`에는 그 **한 단계가 무엇인지** 실제 버튼명·메뉴명으로 쓴다 — “바탕화면을 우클릭해 새로 만들기를 연다”처럼. “여기 클릭”만 쓰지 않는다. 여러 단계를 화살표로 잇는 문장(“1. → 2. → 3.”)은 한 슬라이드에 단계가 섞였다는 신호이므로 쓰지 않는다.

## 공용 CSS와 표준 마크업
CSS 정본은 [`../styles/deck.css`](../styles/deck.css)의 `.shot-*` 블록이다. 배지와 캡션은 모두 **22px 이상**이며 개별 덱에 복제하지 않는다.

```html
<figure class="shot-annot" aria-label="폴더 만들기 1단계 — 바탕화면 우클릭">
  <div class="shot-frame">
    <img src="자료/screenshots/folder-menu.png"
      alt="바탕화면 빈 곳을 우클릭해 열린 메뉴에서 새로 만들기 항목이 강조된 화면">
    <span class="shot-badge" style="left:12%;top:24%" aria-hidden="true">1</span>
    <span class="shot-hl" style="left:20%;top:20%;width:34%;height:12%" aria-hidden="true"></span>
  </div>
  <figcaption class="shot-caption">바탕화면 빈 곳을 우클릭해 <strong>새로 만들기</strong>를 엽니다.</figcaption>
</figure>
```

## 캡처가 아직 없을 때 (목업 폴백)
실제 캡처 전이라면 데모(`데모_제작규칙.html`)의 **목업 창** 변형으로 자리를 잡는다 — `.shot-win`(타이틀바 + 메뉴 행) + `.shot-row.on`(강조 행) + `.shot-badge.b1/.b2/.b3`(행에 정렬된 번호). 실제 캡처가 오면 목업을 `<img>`로 교체하고, 목업 상태는 최종 배포하지 않는다.

## a11y
`<figure>`의 `aria-label`, 관계를 설명하는 이미지 `alt`, 실제 `<figcaption>`을 함께 쓴다. 번호 배지·강조 박스는 캡션과 중복되므로 `aria-hidden="true"`로 숨긴다.
