## 캔버스·본문 골격 (1280×720)
- `.slide` = 1280×720, overflow hidden. 화면모드는 한 장씩(`.is-active`).
- `.s-head` — 상단 헤더(top:34, left/right:56). 구조: [로고][브랜드]`.s-line`[팀명].
  - **헤더 파트진행**: 본문 슬라이드는 우측에 `PART n/N` + 진행 도트(현재 파트=민트)를 JS가 `.s-part`로 주입(divider 기준 자동). 고정 슬라이드는 파트진행 미주입 — 표지·도입·마무리는 팀명 유지, **아젠다는 팀명 제거**(로고+브랜드+라인만), **파트전환은 헤더 전체 제거**(풀캔버스 히어로).
  - **하단 페이지네이션**: `n/전체` 페이지 번호를 JS가 `.s-pageno`로 주입(표지·마무리 제외, 자동).
- **본문 컨테이너 3종(구도가 여기서 갈림):**
  - `.s-body-wrap` — **좌측 컬럼**(left:64 top:132 **width:560**). ← 이게 좌우분할(split)의 근원.
  - `.s-full` — **풀폭**(left:64 right:64 top:118). top-down·grid·diagram-centric용.
  - `.center-msg` — **중앙**(left:64 right:64 top:196 max-width:900). centered용.
- `.canvas-fill` + `.s-full` → 남은 세로를 flex로 꽉 채움(표·그리드).

## 세로 예산·행높이·글자폭 계산 (오버플로 방지 — 필수)
- **밀도**: 저밀도 최소주의 폐기 → 정보 단위 3~6개(물리 한도 내). 정본은 `skills/콘텐츠/SKILL.md` §0-6.
- **세로 균형(하단 여백 금지)**: 콘텐츠를 위로 몰아 아래를 텅 비우면 미완성처럼 보인다. 정보가 적으면 세로 중앙정렬(`.center-msg`는 자동) 또는 `.s-full.fill`(격자·표 확장)·`.s-full.solo`(콜아웃 하나를 아래 공간 중앙에 크게)로 남는 세로를 채운다. 오버플로 0과 **동시에** 세로를 균형 있게 쓴다.
- **박스 크기 = 정보량 비례**: 한 줄짜리 박스를 억지로 키우거나 서너 줄짜리를 억지로 줄이지 않는다 — **내용이 많아지면 박스도 그만큼 커진다(크기를 내용에 맞추는 것이지 내용을 줄이라는 뜻이 아니다)**. 격자 안 항목별 정보량 편차가 크면 균일 그리드 대신 bento(대표 크게+보조 작게)·행높이 가변으로.
  - **패딩 절대 기준**: 세로 패딩 합이 콘텐츠 높이의 1/3을 넘으면 과하다. 1~2줄 배너·콜아웃 = 세로 패딩 12~14px, 3줄↑ = 16~20px.
  - **폭 절대 기준(대칭 규칙)**: 짧은 문장 하나 담은 단독 박스는 `.hug-center`(width:fit-content+가운데 정렬)로 폭을 텍스트만큼만. 시퀀스 칩·대비/체크리스트 격자 콜아웃은 예외(폭 전체가 의미). `flex-column` 부모 안에선 `align-self`도 같이 바꿔야 줄어든다.

카탈로그 `capacity`/`density_note`는 반드시 이 산식으로 검산한다:
- **R-TYPE-03 세로 예산** — 규칙과 사실 기록을 구분한다. 헤더는 이 위에 있고, 모든 콘텐츠가 예산 안에 스크롤 없이 들어가야 한다.

  |---|---|---|
  | **바닥선** | **666px** (720 − 54) | **규칙 · 불변.** 어떤 콘텐츠도 이 아래로 내려가지 않는다 |
  | **신규 슬라이드 예산** | top 112 / bottom 54 → 가용 **554px** | **규칙.** 새로 만드는 장은 이 값으로 잡는다 |
  | 기존 다수 레이아웃 | top 118 → 가용 548px (`.s-full`·`.canvas-fill`) | **사실 기록**(규칙 아님) |

- **줄 높이**: 본문 22px × line-height 1.78 ≈ **줄당 39px**. 2줄 ≈ **78px**, 3줄 ≈ 117px. (❗흔한 오산: 2줄을 50px로 잡지 말 것.)
- **카드/스텝 행 높이** ≈ 헤드라인(~28px) + 본문(줄수×39) + 세로 패딩·gap(~28px). 예: 헤드라인+2줄 ≈ 28+78+28 ≈ **134px/행** → 가용 세로에 **4행**이 현실적(5행은 본문 1줄).
- **글자 가로폭**: 한글은 **전각(≈1.0em advance)** → 큰 디스플레이 텍스트 가로폭 ≈ 글자수 × 폰트px. 숫자·영문은 ≈0.55em. 가용 폭 **1152px**(1280−64−64). → 큰 단어는 폰트를 글자수에 맞춰 스케일(전각 240px면 ≤4자, 320px면 ≤3자; 숫자 320px면 ≤5자).

두 요소를 이을 땐 파란 화살표/기호로 관계 명시: 흐름 `→` · 포함 `⊃` · 대비 `≠` · 검증/아래 `↓`.

## 고정 구조 슬라이드(별도 — 새 카탈로그 대상 아님)
