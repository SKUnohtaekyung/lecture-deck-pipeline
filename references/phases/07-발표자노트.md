# 7단계 — 발표자 노트 HTML
> 이 문서는 7단계에서만 로드한다. 정본 규칙은 규칙 ID로 참조한다.

참조: `kit/starter/presenter-notes-template.html` — 7단계, 발표자 노트 HTML 복제 원본.

## 발표자 노트 HTML 산출 (R-NOTE-01b)

초안에 `💬`/`👀`/`🗣`가 하나라도 있으면 `kit/starter/presenter-notes-template.html`을 복제해 **`<덱이름>_발표자노트.html`**을 만든다 — 슬라이드 순서대로 번호·제목 + 그 슬라이드의 멘트를 종류별로 나열. **`🗣`는 펼쳐진 상태**로(강사는 안전망 예시를 미리 다 봐야 하므로 — 수강생 화면과 반대). 메인 덱과 별개 파일(같은 폴더에 둔다 — 세션 폴더면 `courses/<과목>/sessions/N주차/`). (R-NOTE-01b)

## pn-no 재번호·기계 대조 (R-NOTE-01c)

- **발표자 노트(`강의덱_발표자노트.html`)는 멘트가 있는 장만 담고, `pn-no`는 보이는 페이지 번호와 일치해야 한다.** 구성 변경 시 삽입 지점 이후를 다시 매기고, 노트에는 이모지·힌트가 허용되며 `🗣`는 펼친 상태로 둔다(학생 덱과 반대). (R-NOTE-01c)
- **재번호는 손으로 하지 말고 스크립트로 일괄 처리한다** — 삽입 지점 이후 전부 시프트라 손으로 고치면 중간에 충돌한다. `re.sub(r'<span class="pn-no">(\d+)</span>', lambda m: ... n+시프트 if n>=기준 else n, s)` 한 번으로 끝내고, 끝나면 **덱의 N번째 `data-slide`와 노트 `pn-no`를 기계적으로 대조**해 검증한다(순서 단조·범위 확인 포함). (R-NOTE-01c)
