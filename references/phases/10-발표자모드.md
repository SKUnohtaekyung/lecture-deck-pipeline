# 10단계 — 발표본(발표자 모드) 산출

> **선택 단계다. 사용자가 명시적으로 요청했을 때만 실행한다.**
> 일반 조립·배포 경로에는 발표자 코드 경로가 존재하지 않는다. 자동 삽입은 플래그 기본값이 아니라
> **구조로** 차단돼 있으므로, 이 문서를 읽지 않으면 발표본은 만들어지지 않는다.

설계 정본은 `plans/presenter-system-final-plan.md`다. 이 문서는 **실행 절차와 게이트**만 담는다.

---

## 1. 무엇을 만드는가

| 산출물 | 경로 | 성격 |
|---|---|---|
| 강사 전달물 | `courses/<과목>/sessions/N주차/강의덱_발표.html` | 외부 의존성 0의 단일 HTML. `file://` 더블클릭 실행 |
| 사이드카 | `sessions/_verify/N주차/강의덱_발표.meta.json` | 내부 검증용 감사 기록(전달물 아님) |

동결 폴더에 추가되는 파일은 **전달물 1개뿐**이다. 사이드카를 `sessions/_verify/`로 분리한 이유가 이것이다.

기존 산출물(`강의덱.초안/` · `강의덱.html` · `강의덱_배포.html` · `강의덱_발표자노트.html`)은
**한 글자도 바뀌지 않는다.** 주입기는 입력을 읽기만 한다.

---

## 2. 입력 계약

- 입력은 **이미 완성된 단일 HTML**(`강의덱_배포.html`)이다.
- **`build_release.py`를 쓰지 않는다.** 그것은 조각 폴더에서 전부 재생성하므로 동결된 주차에 쓰면
  동결을 깬다. 발표본은 반드시 완성본을 입력으로 받는다.
- 노트는 같은 주차의 `강의덱_발표자노트.html`을 쓴다(생략하면 기본 멘트 없이 주입된다).

---

## 3. 명령

```bash
python scripts/inject_presenter.py courses/<과목>/sessions/N주차/강의덱_배포.html \
  --notes courses/<과목>/sessions/N주차/강의덱_발표자노트.html \
  --deck-id <영구 deckId> \
  --output courses/<과목>/sessions/N주차/강의덱_발표.html \
  --meta sessions/_verify/N주차/강의덱_발표.meta.json

python scripts/verify_presenter_deck.py \
  --source courses/<과목>/sessions/N주차/강의덱_배포.html \
  --presenter courses/<과목>/sessions/N주차/강의덱_발표.html \
  --meta sessions/_verify/N주차/강의덱_발표.meta.json

python scripts/verify_deck.py courses/<과목>/sessions/N주차/강의덱_발표.html --parts <divider 수>
git status --short
```

`deckId`는 **사람이 정하는 영구 문자열**이다(1주차는 `vibecoding-week-1`). 메모가 이 값으로
`localStorage`에 저장되므로, 한 번 정하면 바꾸지 않는다 — 바꾸면 강사가 적어 둔 메모를 잃는다.

---

## 4. 게이트 (하나라도 실패하면 파일을 쓰지 않는다)

| # | 게이트 | 실패 시 |
|---|---|---|
| 1 | 입력에 이미 `<html data-presenter-runtime>`이 있음 | 중단(멱등) |
| 2 | `--output`에 파일이 있는데 `--force` 없음 | 중단 |
| 3 | `--output`이 입력과 같은 경로 | 중단(원본 덮어쓰기 금지) |
| 4 | `.slide`의 `data-slide` 누락·중복 | 중단. **자동 부여 금지** — 조각을 고쳐 다시 빌드한다 |
| 5 | 노트 하드 실패(`pn-no` 비정수·범위 밖·제목 전방일치 실패·중복 매핑) | 중단. **자동 추정 매핑 금지** |
| 6 | 노트 소진 어서션(파일의 `pn-slide` 블록 수 ≠ 매핑 성공 수) | 중단 |
| 7 | 주입 전후 지문 불일치(슬라이드 수·순서·slideId·innerHTML 해시·시작 태그 원문·`<img>`) | 중단 |
| 8 | 주입 노드가 `.deck` 안에 있거나 2개 이상 | 중단 |

노트가 없는 슬라이드는 **정상**이다(빈 메모). 개수만 로그로 보고한다.

`.deck` 안에 `<iframe|video|audio|canvas>`가 있으면 **WARN**이다(중단 아님). 미리보기 복제본에서
그 요소가 어떻게 동작하는지 손으로 확인한다.

## 5. 수동 체크리스트 (자동 검증이 덮지 못하는 구간)

공식 실행 경로가 `file://` 더블클릭이라 저장소 자동 검증으로는 덮이지 않는다.
릴리스마다 **Windows Chrome · Windows Edge · macOS Chrome** 3열로 수행한다.
전체 28항목 표는 설계 정본 §28에 있다. 최소 필수 8항목만 옮기면:

1. 덱 열기 — 표지 표시, 콘솔 에러 0
2. 하단 네비의 발표자 모드 버튼(또는 `P`) — 별도 **창**으로 열리고 덱을 재로드하지 않음
3. 팝업 차단 상태 — 진입 취소 + 안내 + 다시 시도. **청중 화면에 메모·다음 슬라이드·타이머 노출 0**
4. 좌우 이동 — 두 창의 번호가 항상 동일
5. 번호 입력 중 `b`·`g`·`?` — 아무 단축키도 발동하지 않음
6. 청중 창 새로고침 — 옛 발표자 창이 스스로 닫히고 **[발표자 창 다시 열기]** 안내가 뜸
7. 메모 편집 — `저장됨` 표시, 시크릿 창에서는 `저장 안 됨` 경고
8. PDF 저장 — 슬라이드 수 = 페이지 수, 발표 UI 0, 색 보존

> **`file://` 재연결 한계(측정 확정)**: 청중 창을 새로고침하면 브라우저가 그 문서에 새 opaque
> origin을 주기 때문에, 새 부모는 살아 있는 팝업의 DOM에 **영구히 접근할 수 없다**(Chrome·Edge 동일).
> 그래서 자동 재연결이 아니라 **1클릭 재열기**로 설계했다. 이것은 결함이 아니라 플랫폼 제약이다.

---

## 6. 하지 않는 것

- 슬라이드 본문·색·인쇄 색 보존 선언을 건드리지 않는다.
- 발표 UI 테마(`--pv-*`)를 슬라이드에 적용하지 않는다. 슬라이드 디자인은 테마와 무관하게 불변이다.
- 메모 내보내기·가져오기, 모바일 리모컨, 단일창 발표자 패널은 이 단계 범위가 아니다.
