# case_filename — 참조 이름과 실제 파일명 불일치

## 폴더 상태 (재현용)
```
broken/
├─ index.html   (링크: ./style.css)
├─ styles.css    (실제 파일명 — s 가 붙어 있음)
└─ script.js
```

## 증상 (file:// 로 index.html 을 열면)
- 화면 내용(제목·설명·입력창·버튼·목록)은 다 나오지만 스타일이 하나도 안 붙어 밋밋하다(카드·색·버튼 모양 없음).
- "기록 추가" 버튼과 목록 기능은 정상 동작한다(스크립트는 이름이 맞음). → CSS 이름 문제라는 것을 알 수 있다.
- 콘솔에 style.css 를 찾지 못했다는 오류(ERR_FILE_NOT_FOUND)가 뜬다.

## 원인 (쉬운 말로)
- `index.html` 은 `./style.css` 를 불러오라고 적혀 있는데, 실제 파일 이름은 `styles.css`(s 하나 더) 라서 이름이 서로 다르다.
- 브라우저는 이름이 정확히 같아야 파일을 찾는다. 글자 하나만 달라도 "그런 파일 없음"이 되어 스타일이 빠진다.

## 최소 복구 (broken/ 을 fixed/ 로)
- 둘 중 하나로 이름을 맞춘다(하나만 하면 됨):
  1. 파일 이름을 `styles.css` → `style.css` 로 바꾼다. (권장: 흔한 표준 이름과 링크를 맞춤)
  2. 또는 `index.html` 의 링크를 `./styles.css` 로 바꾼다.
- fixed/ 에서는 1번(파일명을 `style.css` 로 통일)을 적용했다.

### Codex 에게 할 요청문 예시
> CSS 가 안 붙어요. index.html 은 ./style.css 를 참조하는데 실제 파일 이름이 styles.css 예요. 파일 이름을 style.css 로 바꿔서 참조와 실제 파일명을 맞춰 주세요. 다른 건 그대로 두고 이 이름 불일치만 고쳐 주세요.
