# 가상 예산 연습 도구

## 1. 누구에게 어떤 도움·결과·경험을 제공하는가
용돈이나 생활비를 계획해 보고 싶은 사람이, 연습용 예산과 지출을 넣어 보며 합계와 남은 금액을 눈으로 확인하도록 돕는다. (실제 금융 자료가 아닌 가상 연습용)

## 2. 핵심 기능 하나
지출 금액을 하나씩 더하면 지출 합계와 남은 예산(잔액)을 자동으로 계산해 보여 준다.

## 3. 대표 사용 흐름
예산 입력 → 지출 금액 입력 → 지출 추가 버튼 → 지출 목록·합계·잔액 표시

## 4. 이번에 만들 것과 만들지 않을 것
- 만들 것: 예산 입력, 지출 항목·금액 입력, 지출 추가, 지출 목록·합계·잔액 표시, 잘못된 금액 안내 문구
- 만들지 않을 것: 저장(새로고침하면 사라짐), 지출 수정·삭제, 분류·통계, 실제 계좌·카드 연동

## 5. 구현 완료 기준
- 예산을 넣고 지출 금액을 더하면 합계와 잔액이 바로 바뀐다.
- 지출을 여러 개 더하면 목록에 쌓이고 합계가 늘어난다.
- 잔액이 예산을 넘으면(음수) 초과 안내 문구가 보인다.
- 금액을 비우거나 숫자가 아닌 값으로 추가하면 안내 문구가 보이고 목록에 추가되지 않는다.
