# 걸음 수 거리 환산기

## 1. 누구에게 어떤 도움·결과·경험을 제공하는가
걷기 운동을 하는 사람이, 오늘 걸은 걸음 수가 대략 얼마만큼의 거리인지 쉽게 가늠할 수 있게 돕는다.

## 2. 핵심 기능 하나
걸음 수를 입력하면 평균 보폭(0.7m)으로 계산해 미터와 킬로미터 거리로 바꿔 준다.

## 3. 대표 사용 흐름
걸음 수 입력 → 거리로 변환하기 버튼 → 변환 결과(미터·킬로미터) 표시

## 4. 이번에 만들 것과 만들지 않을 것
- 만들 것: 걸음 수 입력, 변환 버튼, 미터·킬로미터 결과 표시
- 만들지 않을 것: 저장, 걸음 기록 누적, 보폭 사용자 설정, 칼로리·시간 계산, 실제 만보기 연동

## 5. 구현 완료 기준
- 걸음 수를 입력하고 변환하기를 누르면 미터와 킬로미터가 함께 보인다.
- 걸음 수를 다른 값으로 바꿔 변환하면 결과 숫자가 바뀐다.
