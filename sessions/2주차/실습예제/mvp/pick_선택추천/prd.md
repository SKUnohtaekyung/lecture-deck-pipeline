# 오늘 점심 메뉴 추천

## 1. 누구에게 어떤 도움·결과·경험을 제공하는가
점심 메뉴를 정하기 어려운 사람이, 먹고 싶은 종류만 고르면 그 종류의 메뉴 중 하나를 대신 골라 주도록 돕는다.

## 2. 핵심 기능 하나
고른 종류에 맞는 메뉴 목록에서 하나를 무작위로 골라 오늘의 추천으로 보여 준다.

## 3. 대표 사용 흐름
메뉴 종류 선택 → 추천받기 버튼 → 오늘의 추천 메뉴와 해당 종류 목록 표시

## 4. 이번에 만들 것과 만들지 않을 것
- 만들 것: 종류 선택(드롭다운), 추천받기 버튼, 오늘의 추천과 목록 표시(메뉴 데이터는 script.js 안에 고정)
- 만들지 않을 것: 저장, 즐겨찾기, 메뉴 추가·편집, 외부 데이터 파일·인터넷 연동, 가격·위치 정보

## 5. 구현 완료 기준
- 종류를 고르고 추천받기를 누르면 그 종류의 메뉴 중 하나가 오늘의 추천으로 보인다.
- 같은 종류로 다시 눌러도 그 종류 안에서 결과가 바뀔 수 있다(무작위).
- 다른 종류를 고르면 다른 종류의 메뉴가 나온다.
