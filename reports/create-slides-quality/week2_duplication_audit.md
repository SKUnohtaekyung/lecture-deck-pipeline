## B. 정당/부당 반복 분류

측정된 중복 후보(노이즈·템플릿 제외 실질 13건) 중 **정당 10건**(회상 2 · 전이 3 · 실습적용 3 · 오해교정→적용→통합 연쇄 1묶음(3-slide) · 최종통합 1), **부당 2건**(3-F3↔6-7 근거의 재진술, 1-8↔2-F2 이미 죽은 채 방치된 행), **별도 결함류 1건**(C-PlanFirst 참조-정의 괴리 — 반복이 아니라 반대로 정의 자체가 없음). 부당 2건 중 1건(1-8↔2-F2)은 저자가 이미 주석으로 자가 발견해 "삭제 예정"이라 표기해 둔 상태 — 실행만 안 됐다.

**관통 문장** ("AI가 작성하고, 사람이 검토하고, 사람이 결정합니다"): 초안 전체에서 `AI가 작성하고` 14회 검색됨. 이 중 6회는 각 교시 상단 블록쿼트("목표: … 관통 문장 —")로 **완전 동일 문구가 6교시 전부에 반복**되나 이는 슬라이드가 아니라 편집 지시문(화면 비노출)이다. 슬라이드 콘텐츠(본문/노트) 내 실제 등장은 6회(1-간지·2-간지·3-5·5-F1·6-6·6-10)이며 **매번 문구가 변주**된다 — 예: 1-간지 "…결정한다"(구어체 절단), 2-간지 "…무엇을 뺄지도 사람이 결정합니다"(확장절 추가), 3-5 "…(CP1: 대상·범위 가정 하나를 실제로 바꿉니다)"(체크포인트 결부), 5-F1 "AI가 작성하고 사람이 검토하는 흐름은 그대로입니다"(결정 절 생략된 축약형), 6-6 "…(CP3: 표현만 바꾸는 건 반려)"(체크포인트 결부), 6-10 완전형(마무리 배너, 화면 표시). 조립된 덱(HTML)에서 화면에 실제 렌더링되는 곳은 2곳뿐(S02 표지/아젠다, END 마무리) — 결함이 아니라 의도된 여는말/닫는말 북엔드.

**callout 텍스트**: 덱 전체 24개 `callout` 클래스 인스턴스 전수 추출 결과 **24개 전부 텍스트가 서로 다름**(jaccard≥0.3 근접중복 0건). 형태(24/107≈22.4%, 기존 감사의 "~24%"와 부합)는 반복되지만 **문구는 반복되지 않는다** — callout은 결론 배너 패턴이 재사용될 뿐 내용 재탕은 없다.

## D. CORE↔EXTENSION 중복 방지 계약 (제안)

**데이터 근거 임계값**: §A 분포 측정 결과 — 서로 다른 개념(refs 무공유)인 두 슬라이드는 잡음만으로 jaccard 0.19를 거의 넘지 않는다(p95=0.059, 관측 최대 0.188은 상용구 우연 일치 2건뿐). 같은 개념을 다루는 슬라이드끼리도 정상 스캐폴딩(정의→적용)은 0.15~0.18 대역에 머문다(3-2↔3-5=0.182, 4-1↔4-2=0.179). **진짜 재진술로 확인된 유일한 사례(3-F3↔6-7)는 0.231**. 따라서:

- **FAIL 기준**: EXTENSION 행의 본문(마크다운 제거·토큰화)과 그 행이 선언한 `연결 CORE` 행 본문 간 jaccard **≥ 0.20**.
- **WARN 기준**: 0.15~0.20 — 정상 스캐폴딩 대역과 겹치므로 자동 FAIL은 과도하나, `연결 CORE`가 선언돼 있다면 사람이 "새 학습 가치"가 실제로 있는지 1줄로 확인.
- 0.15 미만은 조치 불요(잡음 대역).

**요구 스키마**(초안 표 자체에서 조립 전에 체크 가능하도록): 각 EXTENSION 행에 3개 열/주석을 강제한다 — `연결 CORE`(슬라이드 id 1개 이상) · `새로 추가되는 학습 가치`(한 문장, 기존 CORE에 없는 요소를 지목) · `CORE와 중복되지 않는 이유`(위 자동측정 jaccard가 FAIL 기준을 넘지 않았다는 확인, 또는 넘었다면 왜 의도적 재진술(최종통합 등)인지). `scripts/verify_draft_quality.py` 또는 신규 스크립트가 draft 표를 파싱해 이 3필드 존재와 jaccard를 조립 전에 검사할 수 있다.

**EXTENSION으로 인정하지 않는 것** (명시적 배제):
같은 정의의 재진술 · CORE 사례의 이름만 변경(예: "퇴근길 직장인"을 "출근길 학생"으로 바꾸기만 함) · 이미 본 화면 재설명(새 정보 없이 같은 스크린샷 다시 보여주기) · 발표자 노트(🗣/💬)를 슬라이드 표면으로 승격만 하는 것 · 내용 없는 질문(예: "여러분 생각은요?"로 끝나고 답이 없는 슬라이드) · 대기 시간(실습 타이머만 있는 빈 슬라이드) · 의미 없는 추가 실습(완료 기준·산출물이 CORE 실습과 동일한 반복) · 같은 결과물 재제작(이미 만든 파일을 다른 이름으로 다시 만들게 하는 실습).
