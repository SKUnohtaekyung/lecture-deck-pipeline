| 파일 | 내용 | 올리는 실습 |

| 지난 안내문.txt | 날짜 · 시간 · 모이는 곳 · 준비물 · 연락처가 있는 짧은 안내문 | 실습 6에서 올립니다. 실습 7에서 말투와 순서의 본보기가 됩니다 |
