# N주차 이미지 프롬프트

상태 정본은 같은 폴더의 `이미지-에셋.json`이다. 이 문서는 사람이 검토하고 생성 도구에 전달하기 위한 대응 문서다.

## 작성 규칙

- manifest와 동일한 슬라이드 ID·`prompt_id`·예상 파일명을 쓴다.
- `의미 브리프 → paper-cut-v1 공통 스타일 → 출력 경로 블록` 순서로 조립한다.
- built-in 크로마 블록과 native-alpha 블록을 한 프롬프트에 섞지 않는다.
- `prompt_only` HTML에는 실제 `<img>`를 만들지 않는다.
