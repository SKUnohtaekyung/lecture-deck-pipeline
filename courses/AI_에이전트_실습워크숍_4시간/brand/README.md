# FRAME 브랜드 자산 (2026-09-30)

| 파일 | 용도 |
|---|---|
| `frame-mark.svg` | 마크 — 모서리 네 개(틀) + 가운데 아쿠아 사각형. 파비콘·작은 자리 |
| `frame-wordmark.svg` | 워드마크 — 각진 연결형(F·R 윗줄 공유 · R 다리→A · A·M 바닥선 · M·E 기둥 공유 · 윗선/바닥선에서 잘라냄) |
| `frame-lockup.svg` | 마크 + 워드마크 가로 조합 |

- 파일 안 색은 hex 고정(`#0E4A5A` 페트롤 · `#7DE0EC` 아쿠아)이다 — 덱 **밖**(파비콘·문서)용.
- 덱 **안**에 넣을 때는 인라인 SVG로 옮기고 `var(--blue)`·`var(--mint)`로 바꾼다(테마 계약 §6 — 인라인 로고는 토큰을 따른다).
- 어두운 면(페트롤) 위에서는 선을 `var(--white)`로, 아쿠아 사각형은 그대로 둔다.
- 워드마크 획 굵기 5(높이 40 기준). 7은 글자가 뭉쳐 폐기했다(2026-09-30 렌더 확인).
