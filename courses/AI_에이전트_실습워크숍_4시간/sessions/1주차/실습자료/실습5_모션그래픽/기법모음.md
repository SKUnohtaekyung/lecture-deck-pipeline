# 기법모음

에이전트가 읽는 문서입니다. 참가자에게 고르라고 내미는 메뉴로 쓰지 않습니다. 참가자가 말한 장면을 화면으로 옮길 때 필요한 절만 찾아 읽습니다. 조각은 모두 `영상_틀.html` 맨 위 칸의 장면 `그리기: function (t, 무대) { … }` 안에 넣습니다. 조각 속 글과 숫자는 자리 표시이며, 참가자가 말한 것으로 바꿉니다.

## 색인

| 찾는 것 | 절 |
|---|---|
| 틀의 도구: 무대.글 · 무대.그림 · 진행 · 놓기 · 색섞기 | 도구 |
| 등장: 떠오름 · 스며듦 · 튀어나옴 · 밀려듦 · 한 글자씩 · 그려짐 | 등장 |
| 전환: 겹쳐넘기기 · 밀어내기 · 닦아내기 · 원형 닦아내기 · 확대하기 | 전환 |
| 강조: 밑줄긋기 · 두근거림 · 물들임 · 숫자세기 | 강조 |
| 숫자 연출: 원형 게이지 · 점 그리드 | 숫자 |
| 카드 · 말풍선 | 카드 |
| 그림: 그리는 순서 · 예(도마 · 컵) · 사물 뼈대 | 그림 |
| 구도: 배치 5가지(좌표) · 그림 크기 · 깊이(그림자 · 기울임) | 구도 |
| 바탕 한 겹 · 마무리(이름 조립 · 단추 · 광택) | 마무리 |
| 연출 하한 · 사실 | 하한 |

## 도구

- 장면 칸: `{ 시작: 초, 끝: 초, 그리기: function (t, 무대) {} }`. 고를 수 있는 칸: `전환`(초) · `들어오기(p, 새, 옛)` · `멈춤시각`(점검과 움직임 줄이기에서 보일 시각) · `준비(무대)`(한 번만 실행).
- 그리기는 `t`만 보고 모습을 정합니다. 앞 화면을 기억하는 변수를 두지 않아야 `?t=` · 점검 · 녹화가 같은 화면을 얻습니다.
- `무대.글(이름, 문장, 옵션)`: 처음 부를 때 글 상자를 만들고 다음부터 같은 상자를 돌려줍니다. 옵션은 `x` · `y`(상자 위쪽) · `폭` · `크기`(px, 기본 56) · `굵게` · `색` · `정렬`('가운데' · '왼쪽' · '오른쪽') · `줄`(최대 줄 수, 기본 2) · `나누기`('글자' · '단어') · `가리개` · `안에`(다른 요소 안에 넣기) · `맞춤글`. 문장 속 `**…**`는 강조색, `\n`은 줄바꿈입니다. 낱말 중간에서 줄이 바뀌지 않고, 상자에 안 들어가면 44px까지 줄입니다. 나눈 조각은 `.조각들`에 있습니다.
- `무대.그림(이름, 'SVG나 HTML 글', { x, y, 폭, 높이, 안에 })`: 그림 상자. 안쪽 요소는 `querySelector`로 찾습니다.
- `진행(t, 시작, 길이, 곡선)` → 0~1. 곡선은 '부드럽게'(기본) · '양쪽' · '튕김' · '빨라짐' · '고르게'.
- `놓기(요소, { x, y, 크기, 회전, 보임 })`: 제자리에서 옮긴 거리 · 배율 · 각도 · 보임(0~1).
- `사이(a, b, p)` · `색섞기(색1, 색2, p)` · `색.바탕` · `색.글자` · `색.강조`. CSS와 SVG의 style에서는 `var(--강조)`.
- `무대.폭` · `무대.높이` · `무대.안전`(왼 · 오른 · 위 · 아래) · `무대.지금`(영상 처음부터 지난 초) · `무대.층`.
- 주의: SVG 속성 `fill="var(--강조)"`는 칠해지지 않습니다. `style="fill:var(--강조)"`로 씁니다.

## 등장

**떠오름** · 문장 하나를 차분히 꺼낼 때.

```js
var 글 = 무대.글('한줄', '참가자의 문장', { y: 900, 크기: 72, 굵게: true });
var p = 진행(t, 0.3, 0.5);
놓기(글, { y: 60 * (1 - p), 보임: p });
```

주의: 다 나타난 뒤 1.5초 이상 머물게 장면 길이를 잡습니다.

**스며듦** · 인용 · 후기처럼 부드럽게 들어올 글.

```js
var p = 진행(t, 0.3, 0.6);
글.style.opacity = p;
글.style.filter = p < 1 ? 'blur(' + (1 - p) * 12 + 'px)' : 'none';
```

주의: 흐림을 큰 상자 여러 개에 동시에 걸면 재생이 끊길 수 있습니다.

**튀어나옴** · 단추 · 가격표 · 그림 주인공을 세울 때.

```js
var p = 진행(t, 0.2, 0.5, '튕김');
놓기(그림, { 크기: 0.72 + 0.28 * p, 보임: p * 3 });
```

주의: 기준점은 요소 가운데입니다. 바닥에서 솟게 하려면 `그림.style.transformOrigin = '50% 100%'`.

**밀려듦** · 옆에서 들어오는 물건이나 카드.

```js
var p = 진행(t, 0.3, 0.6);
놓기(카드, { x: -700 * (1 - p), 보임: p });
```

주의: 다 들어온 자리의 글자가 안전 여백 안이면 됩니다.

**한 글자씩** · 첫 장면의 훅 문장.

```js
var 글 = 무대.글('훅', '참가자의 훅 문장', { y: 860, 크기: 88, 굵게: true, 나누기: '글자', 가리개: true });
글.조각들.forEach(function (c, i) {
  c.style.transform = 'translateY(' + (1 - 진행(t, 0.1 + i * 0.04, 0.35)) * 110 + '%)';
});
```

주의: 마지막 글자가 나온 시각(0.1 + 글자 수 × 0.04 + 0.35)에 1.5초를 더해 장면 길이와 비교합니다. 단어 단위는 `나누기: '단어'`, 간격 0.12초.

**그려짐** · 선 · 테두리 · 화살표가 그어지듯 나타날 때.

```js
var 선 = 무대.그림('선', '<svg width="864" height="60" viewBox="0 0 864 60"><path pathLength="1" d="M10 40C300 5 560 5 854 40" fill="none" style="stroke:var(--강조)" stroke-width="8" stroke-linecap="round" stroke-dasharray="1"/></svg>', { x: 108, y: 1000 });
선.querySelector('path').setAttribute('stroke-dashoffset', 1 - 진행(t, 0.5, 0.8, '양쪽'));
```

주의: `pathLength="1"`을 붙여야 길이와 상관없이 0~1로 그립니다.

## 전환

전환은 들어오는 장면에 적습니다. `전환`은 앞 장면 끝에 겹치는 초라서 장면 길이에 더하지 않습니다. 첫 장면에는 쓰지 않습니다. `p`는 0~1이고 `새` · `옛`은 두 장면의 층입니다.

**겹쳐넘기기**

```js
전환: 0.6,
들어오기: function (p, 새, 옛) { var e = 곡선.양쪽(p); 새.style.opacity = e; if (옛) 옛.style.opacity = 1 - e; },
```

**밀어내기**

```js
들어오기: function (p, 새, 옛) {
  var e = 곡선.양쪽(p), w = 새.offsetWidth;
  새.style.transform = 'translateX(' + (1 - e) * w + 'px)';
  if (옛) 옛.style.transform = 'translateX(' + (-e * w) + 'px)';
},
```

**닦아내기** · 아래에서 위로 쓸어 올림.

```js
들어오기: function (p, 새, 옛) {
  var e = 곡선.양쪽(p) * 100;
  새.style.clipPath = 'inset(' + (100 - e) + '% 0 0 0)';
  if (옛) 옛.style.clipPath = 'inset(0 0 ' + e + '% 0)';
},
```

**원형 닦아내기** · 한 점에서 원이 퍼짐.

```js
들어오기: function (p, 새, 옛) {
  var r = Math.max(0.5, 곡선.양쪽(p) * 2300), x = 540, y = 1350;
  새.style.clipPath = 'circle(' + r + 'px at ' + x + 'px ' + y + 'px)';
  if (옛) 옛.style.clipPath = 'path(evenodd,"M0 0H1080V1920H0Z M' + (x - r) + ' ' + y + 'a' + r + ' ' + r + ' 0 1 0 ' + 2 * r + ' 0a' + r + ' ' + r + ' 0 1 0 ' + (-2 * r) + ' 0Z")';
},
```

**확대하기**

```js
들어오기: function (p, 새, 옛) {
  var e = 곡선.양쪽(p); 새.style.opacity = e;
  if (옛) { 옛.style.transform = 'scale(' + (1 + 0.4 * e) + ')'; 옛.style.opacity = 1 - e; }
},
```

주의: 장면 층이 투명해서 옛 장면을 지우지 않으면 두 장면의 글이 겹쳐 보입니다. 넓은 면을 밝게 번쩍이는 전환은 1초에 3번을 넘기지 않습니다.

## 강조

**밑줄긋기** · `**…**`로 감싼 말 아래에 선이 그어짐. 맨 위 `<style>`에 아래 CSS를 넣습니다.

```css
.ft-em{position:relative}
.밑줄{position:absolute;left:0;right:0;bottom:-0.08em;height:0.14em;border-radius:0.07em;background:var(--강조);transform-origin:left center}
```

```js
글.querySelectorAll('.ft-em').forEach(function (em) {
  var u = em.querySelector('.밑줄');
  if (!u) { u = document.createElement('span'); u.className = '밑줄'; em.appendChild(u); }
  u.style.transform = 'scaleX(' + 진행(t, 1.2, 0.5) + ')';
});
```

**두근거림** · 다 나온 글이나 단추를 한 번 눈에 띄게.

```js
놓기(단추, { 크기: 1 + 0.07 * Math.sin(Math.PI * 진행(t, 2.0, 0.6, '고르게')) });
```

**물들임** · 글자 색이 강조색으로 바뀜.

```js
글.style.color = 색섞기(색.글자, 색.강조, 진행(t, 1.0, 0.4));
```

**숫자세기** · 참가자가 말한 숫자가 0에서 올라가 멈춤.

```js
var 값 = 120; /* 참가자가 말한 숫자 */
var 끝글 = 값.toLocaleString('ko-KR') + '명';
var 지금값 = Math.round(값 * 진행(t, 0.4, 1.2, '양쪽'));
var 글 = 무대.글('숫자', 지금값.toLocaleString('ko-KR') + '명', { y: 700, 크기: 140, 굵게: true, 맞춤글: 끝글 });
글.style.fontVariantNumeric = 'tabular-nums';
```

주의: `맞춤글`에 다 센 글을 주어야 숫자가 커질 때 상자를 넘지 않습니다.

## 숫자

**원형 게이지** · 비율. 숫자세기와 같은 `진행`을 씁니다.

```js
var 비율 = 0.5; /* 참가자가 말한 비율 */
var C = 2 * Math.PI * 206;
var g = 무대.그림('게이지', '<svg width="520" height="520" viewBox="0 0 520 520"><circle cx="260" cy="260" r="206" fill="none" style="stroke:var(--글자);opacity:.12" stroke-width="36"/><circle class="호" cx="260" cy="260" r="206" fill="none" style="stroke:var(--강조)" stroke-width="36" stroke-linecap="round" transform="rotate(-90 260 260)" stroke-dasharray="' + C + '"/></svg>', { x: 280, y: 300 });
g.querySelector('.호').setAttribute('stroke-dashoffset', C * (1 - 비율 * 진행(t, 0.4, 1.2, '양쪽')));
```

**점 그리드** · 「N명 중 M명」. 점이 튀어나온 뒤 M개가 강조색으로 물듦.

```js
var 전체 = 20, 표시 = 7; /* 참가자가 말한 수 */
var 칸 = 무대.그림('점들', '', { x: 140, y: 1000, 폭: 800 });
if (!칸.children.length) for (var i = 0; i < 전체; i++) 칸.appendChild(document.createElement('i'));
칸.style.cssText += ';display:grid;grid-template-columns:repeat(10,80px)';
Array.prototype.forEach.call(칸.children, function (d, i) {
  d.style.cssText = 'width:56px;height:56px;margin:12px;border-radius:50%;background:' + (i < 표시 && t > 1.2 + i * 0.05 ? 색.강조 : 색섞기(색.바탕, 색.글자, 0.2));
  d.style.transform = 'scale(' + 진행(t, 0.4 + i * 0.03, 0.3, '튕김') + ')';
});
```

주의: 점 하나가 사람 하나를 뜻하면 사람 뼈대(그림 절)를 작게 줄여 써도 됩니다.

## 카드

**카드** · 묶음 · 가격 · 목록을 올려놓는 판. 뒤로 기운 채 올라와 섬.

```js
var 카드 = 무대.그림('카드', '', { x: 130, y: 420, 폭: 820, 높이: 700 });
카드.style.cssText += ';border-radius:56px;background:var(--카드,#FFFFFF);box-shadow:0 50px 90px rgba(0,0,0,.18);transform-origin:50% 100%';
var p = 진행(t, 0.1, 1.0);
카드.style.transform = 'perspective(1400px) translateY(' + (1 - p) * 90 + 'px) rotateX(' + (1 - p) * 26 + 'deg)';
카드.style.opacity = Math.min(1, t / 0.3);
var 제목 = 무대.글('카드글', '참가자의 문장', { 안에: 카드, x: 40, y: 60, 폭: 740, 크기: 64, 굵게: true });
```

주의: 카드 위 글은 `안에: 카드`로 넣어야 함께 움직이고 점검이 카드 색으로 대비를 잽니다. 카드 색은 설정의 색에 `카드`를 더해 정합니다.

**말풍선** · 후기 · 대사. 카드에 꼬리를 붙입니다.

```js
var 풍선 = 무대.그림('풍선', '<i style="position:absolute;left:96px;bottom:-22px;width:48px;height:48px;background:var(--카드,#FFFFFF);transform:rotate(45deg)"></i>', { x: 120, y: 1250, 폭: 840, 높이: 200 });
풍선.style.cssText += ';border-radius:48px;background:var(--카드,#FFFFFF);box-shadow:0 36px 70px rgba(0,0,0,.18);transform-origin:20% 100%';
무대.글('풍선글', '「참가자가 준 후기」', { 안에: 풍선, x: 40, y: 60, 폭: 760, 크기: 56 });
var b = 진행(t, 0.2, 0.8);
풍선.style.transform = 'perspective(1200px) translateY(' + (1 - b) * 130 + 'px) rotateX(' + (3 + (1 - b) * 30) + 'deg)';
```

## 그림

장면마다 코드로 그린 그림 주인공이 하나 있어야 합니다. SVG로 그리고 쌓는 순서는 아래와 같습니다(뒤에 쓴 것이 위에 그려짐).

1. 바닥 그림자: 납작한 타원, `rgba(0,0,0,.12)`
2. 바깥 모양: 사물의 윤곽 하나(둥근 사각형 · 경로)
3. 면: 그라데이션으로 밝은 쪽과 어두운 쪽을 나눔
4. 두께 · 그늘: 바깥 모양을 몇 px 옮겨 진한 색으로 한 번 더(뒤에 깔기)
5. 하이라이트: 흰색 투명도 .3 안팎의 사선 띠나 짧은 곡선
6. 질감 선: 나뭇결 · 눈금 · 바느질 같은 가는 선(굵기 2~4)

색은 참가자의 색에서 `색섞기(색.강조, '#FFFFFF', 0.5)`처럼 밝기 단계를 만들어 씁니다.

**예: 도마** · 두께 → 면 → 손잡이 구멍 → 나뭇결 → 사선 반사.

```js

  '<ellipse cx="150" cy="418" rx="120" ry="10" style="fill:rgba(0,0,0,.12)"/>' +
  '<rect x="21" y="60" width="272" height="350" rx="30" style="fill:' + 어 + '"/>' +
  '<rect x="14" y="50" width="272" height="350" rx="30" style="fill:' + 밝 + '"/>' +
  '<rect x="110" y="8" width="80" height="62" rx="26" style="fill:' + 밝 + '"/>' +
  '<circle cx="150" cy="34" r="10" style="fill:' + 어 + '"/>' +
  '<g fill="none" style="stroke:' + 어 + '" stroke-width="2.5"><path d="M56 128C110 116 170 140 244 122"/><path d="M52 196C120 206 182 180 248 200"/><path d="M58 268C122 258 196 286 244 266"/></g>' +
  '<path d="M40 392L196 58h44L84 392z" style="fill:#FFFFFF" opacity=".28"/></svg>', { x: 390, y: 700 });
```

**예: 컵** · 손잡이(뒤) → 몸통(가로 그라데이션) → 눈금 → 세로 반사 → 입구 타원.

## 구도

장면마다 아래 다섯 배치 중 하나를 고르고, 장면표의 장면마다 배치 번호(①~⑤)를 적습니다. 같은 배치는 두 장면까지만 이어 씁니다. 좌표는 1080×1920 세로, 안전 여백(가로 108~972 · 세로 240~1600) 안입니다. 그림 주인공은 높이 640px(무대 높이의 3분의 1) 이상입니다. `주인공`은 그림 절의 SVG 글에서 `width` · `height` 속성을 빼고 `style="width:100%;height:100%"`를 붙인 것이라, 상자 크기가 그림 크기입니다.

**① 위 글 · 아래 큰 그림** · 글 하나와 그림 하나가 또렷해야 하는 장면(훅 · 소개 · 마무리).

```js
var 글 = 무대.글('제목', '참가자의 문장', { y: 250, 크기: 72, 굵게: true });
var 그림 = 무대.그림('주인공', 주인공, { x: 190, y: 560, 폭: 700, 높이: 1000 });
```

**② 큰 그림 가운데 · 아래쪽 띠에 글** · 사물 하나를 크게 보이고 문장을 얹을 때(가격 · 후기).

```js
var 그림 = 무대.그림('주인공', 주인공, { x: 190, y: 270, 폭: 700, 높이: 1000 });
var 띠 = 무대.그림('띠', '', { x: 108, y: 1160, 폭: 864, 높이: 420 });
띠.style.cssText += ';border-radius:48px;background:var(--카드,#FFFFFF);box-shadow:0 36px 70px rgba(0,0,0,.18)';
무대.글('제목', '참가자의 문장', { 안에: 띠, x: 48, y: 70, 폭: 768, 크기: 72, 굵게: true });
```

주의: 띠가 그림 아래 110px을 덮습니다. 글은 `안에: 띠`로 넣어야 점검이 띠 색으로 대비를 잽니다.

**③ 그림 왼쪽 위에 비스듬히 크게 · 글 오른쪽 아래** · 움직임이 느껴지는 사물, 한마디 대사.

```js

놓기(그림, { 회전: -9 });

```

주의: 기울인 그림 상자가 화면 왼쪽 끝을 넘지 않게 x를 28 이상으로 둡니다.

**④ 글 크게 가운데 · 작은 그림이 둘레를 둘러쌈** · 숫자 하나나 이름 하나를 크게 보이고 관련 물건을 흩어 놓을 때.


주의: `조각들`은 서로 다른 그림 SVG 글의 배열입니다. 묶음의 위끝(260)부터 아래끝(1600)까지가 주인공 높이이고 조각 하나는 높이 320 이상입니다.

**⑤ 위아래로 나눠 전후 비교** · 쓰기 전과 쓴 뒤, 두 가지 비교.


맨 위 `<style>`에 `.라벨{display:inline-block;padding:20px 44px;border-radius:999px;background:var(--강조);color:var(--강조위)}`를 넣습니다. 「전」 라벨은 `안에: 위`로 같게 만듭니다. 두 칸 높이 650이 곧 주인공 높이이며, 전은 글자색을 바탕에 섞은 회색 계열로, 후는 강조색 계열로 그려 차이가 첫눈에 읽히게 합니다.

**깊이** · 그림 상자가 큰 만큼 입체감을 줍니다.

- 바닥 그림자 · 면 그라데이션 · 하이라이트 띠는 그림 절의 순서와 예(도마 · 컵)를 따릅니다. 그림자 타원에 `filter:blur(6px)`를 더하면 가장자리가 흐려집니다: `style="fill:rgba(0,0,0,.12);filter:blur(6px)"`.
- 판 위에 놓는 그림자는 카드 절의 `box-shadow`를 씁니다.
- 살짝 기울임은 안쪽 SVG에 겁니다. `놓기`가 그림 상자의 `transform`을 쓰므로 상자에는 걸지 않습니다.

```js

```

## 하한

장면을 만들 때마다 세 가지를 셉니다.

- 장면마다 코드로 그린 그림 주인공이 하나 이상 있습니다(배경 도형과 글 상자는 세지 않음).
- 글자만 있는 장면이 없습니다.
- 장면마다 움직임이 두 종류 이상입니다. 예: 그림 튀어나옴과 글 떠오름, 카드 밀려듦과 숫자세기.

이 문서의 기법은 참가자가 말한 내용을 보여 줄 때만 씁니다. 참가자가 말하지 않은 숫자 · 사실 · 후기를 만들지 않습니다. 조각 속 자리 표시 값은 참가자의 값으로 바꾸고, 값이 없으면 그 조각을 쓰지 않습니다.

만든 뒤에는 `영상.html?check=1`로 열어 「점검: 문제 없음」을 확인하고, 「못 잰 곳」은 참가자에게 화면을 보고 알려 달라고 청합니다.
