# 점검

3단계의 1장(장 수 · 장 모양 제외)과 5단계의 전체 덱에서 확인합니다. 파일을 읽어 확인하고 사용자에게도 브라우저에서 보게 합니다. 맞지 않은 항목은 고친 뒤 다시 확인합니다(5단계는 승인받은 뒤).

| 항목 | 기준 (확인 방법) |
|---|---|
| 장 수 | 개요의 장 표와 같은 수 |
| 넘침 | 요소가 무대 안, 스크롤 없음, 글이 상자 밖으로 안 나감 (창을 줄였다 늘려 봅니다) |
| 글자 하한 | 화면의 모든 글자가 24px 이상 (font-size 값, 변수는 풀어서 24 미만인 곳을 찾습니다) |
| 색 수 | design.md의 색과 흰색만 쓰고 한 장의 면 색(02에 정의)은 2개 이하 |
| 대비 | 글자와 바탕의 모든 쌍이 4.5 : 1 이상 (WCAG 공식으로 계산합니다) |
| 정보 수 | 장마다 3~6개(첫 장 · 마지막 장 · 인용 장은 한 문장) |
| 장 모양 | 연달아 같은 모양 없음, 종류 수는 01의 기준 |
| 사실 대조 | 숫자 · 이름 · 날짜 · 인용의 근거가 개요에 있음. 근거 칸이 빈 것은 지우고, 「사용자 확인 필요」는 몇 장인지 알립니다 |
| 조작 | 방향키 · 진행 막대 · 장 번호 · 인쇄 미리보기(장마다 한 쪽) (사용자가 해 봅니다) |

결과표는 항목 · 결과(맞음, 고침, 미확인) · 고친 곳으로 보이고, 미확인 항목은 확인 방법을 알립니다.
