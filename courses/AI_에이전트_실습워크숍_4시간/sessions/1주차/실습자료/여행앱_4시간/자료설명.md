# 자료 설명

## 관광지.js

준비된 관광지 자료입니다. 모양은 다음과 같습니다.

```
window.관광지 = { 만든날, 출처, 지역: [ { 이름, 위도, 경도, 장소: [ { id, 이름, 분류, 실내, 주소, 위도, 경도, 사진, 설명 } ] } ] };
```

- 만든날 · 출처: 만든 날과 가져온 곳
- 지역: 이름 · 위도 · 경도. 지역마다 장소가 12곳입니다.
- 장소 id · 이름 · 주소 · 분류: 구분 번호, 이름, 주소, 종류
- 장소 실내: `true`면 비 오는 날 갈 수 있는 실내 장소
- 장소 위도 · 경도: 지도 핀 위치
- 장소 사진 · 설명: 사진 주소와 짧은 소개

빈 칸(`""`)이 있습니다. 사진 · 설명은 거의 다, 주소는 열에 일곱이 비어 있습니다. 빈 칸은 화면에 표시하지 않는 것이 기본값입니다.

지역 다섯 곳(순서대로): 강릉 · 경주 · 전주 · 부산 · 제주

## 날씨 주소

다섯 지역을 한 번에, 키 없이 부르는 주소입니다. 오늘부터 16일 예보가 옵니다.

```
https://api.open-meteo.com/v1/forecast?latitude=37.7519,35.8562,35.8242,35.1796,33.4996&longitude=128.8761,129.2247,127.148,129.0756,126.5312&daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max,weather_code&timezone=Asia/Seoul&forecast_days=16
```

응답은 다섯 지역의 목록(위 순서)입니다. 한 지역의 모양(이틀치 예):

```
{"latitude":37.75,"longitude":128.875,"daily":{"time":["2026-10-21","2026-10-22"],"temperature_2m_max":[18.4,13.3],"temperature_2m_min":[7.9,5.7],"precipitation_probability_max":[8,0],"weather_code":[51,0]}}
```

- `daily`의 `time`과 나머지 목록은 같은 순서입니다. 첫 칸끼리 같은 날의 값입니다.
- `temperature_2m_max` 하루 최고기온 · `temperature_2m_min` 최저기온 · `precipitation_probability_max` 강수 확률의 하루 최댓값(%)
- 예보 없는 날: 응답의 `time`에 없는 날짜입니다(16일보다 뒤의 날, 지난 날).
- 저장 형식: `window.날씨 = [ …받은 응답 전체… ];`

## weather_code

WMO 코드(Open-Meteo 문서 기준): 맑음 0 · 구름 1~3 · 안개 45, 48 · 이슬비 51~57 · 비 61~67 · 소나기 80~82 · 눈 71~77, 85, 86 · 뇌우 95~99

비 오는 날(기본값): 61~67, 80~82, 95~99. 이슬비와 눈은 넣지 않습니다.

## 지도 그림 주소

Leaflet 지도 그림(타일) 주소입니다.

```
https://{s}.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png
```

출처 문구: `© OpenStreetMap contributors · Tiles style by Humanitarian OpenStreetMap Team hosted by OpenStreetMap France`

더블클릭으로 연 파일에서는 브라우저에 따라 그림이 안 올 수 있고, 안 오면 핀만 보입니다. `tile.openstreetmap.org`는 이때 막힌 그림이 나와 쓰지 않습니다.
