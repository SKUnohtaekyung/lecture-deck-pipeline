# 만들기 안내 (Canva)

메뉴 이름은 수업 직전 Canva 화면으로 확인합니다.

값과 문구는 `design.md` · `카드문구.md` 그대로입니다. 유료 표시가 붙은 글꼴과 요소는 워터마크가 들어가므로 무료 표시가 있는 것만 고릅니다. 이름이 표에 없는 메뉴는 「화면에서 직접 찾습니다」로 적었습니다. 브랜드 키트는 무료에서 색 3개까지이므로 아래 색 세 가지로 끝입니다.

## 새 디자인 · 페이지

1. Canva 홈의 「사용자 지정 크기」에서 1080 × 1080 px를 입력합니다.
2. 「페이지 추가」를 눌러 모두 6장이 되게 합니다.

## 색

3. 색 선택기의 「+」(새 색 추가)에서 코드 #FFF6D6(바탕)을 입력합니다.
4. 색 선택기의 「+」(새 색 추가)에서 코드 #2B2B2B(글자)를 입력합니다.
5. 색 선택기의 「+」(새 색 추가)에서 코드 #1B7F3B(강조)를 입력합니다.
6. 6장 모두 바탕 색을 #FFF6D6으로 바꿉니다. 바탕 색을 바꾸는 메뉴는 화면에서 직접 찾습니다.

## 글꼴

7. 왼쪽 「텍스트」에서 글 상자를 더합니다.
8. 위쪽 글꼴 칸에서 무료 표시가 있는 한글 글꼴 가운데 굵은 것 하나를 제목 글꼴로 고릅니다.
9. 고른 글꼴 이름을 `design.md`의 제목 글꼴 이름 칸에 적습니다.
10. 위쪽 글꼴 칸에서 무료 표시가 있는 한글 글꼴 가운데 읽기 쉬운 것 하나를 본문 글꼴로 고릅니다.
11. 고른 글꼴 이름을 `design.md`의 본문 글꼴 이름 칸에 적습니다.

## 문구 붙이기

12. 1장에 글 상자를 더하고 제목 「토요일 아침, 그림책 같이 읽어요」를 붙입니다.
13. 1장에 글 상자를 더하고 본문 「우리 동네 도서관이 12월 매주 토요일에 그림책 읽기 모임을 열어요」를 붙입니다.
14. 2장에 글 상자를 더하고 제목 「12월 토요일, 오전 10시」를 붙입니다.
15. 2장에 글 상자를 더하고 본문 「12월 6일 · 13일 · 20일 · 27일 토요일 오전 10시에 모여요」를 붙입니다.
16. 3장에 글 상자를 더하고 제목 「2층 어린이실에서 열려요」를 붙입니다.
17. 3장에 글 상자를 더하고 본문 「토요일 아침 그림책 읽기 모임은 2층 어린이실에서 열려요」를 붙입니다.
18. 4장에 글 상자를 더하고 제목 「5~8세가 함께 읽어요」를 붙입니다.
19. 4장에 글 상자를 더하고 본문 「5~8세 친구들이 토요일 아침에 모여 그림책을 함께 읽어요」를 붙입니다.
20. 5장에 글 상자를 더하고 제목 「선착순 15명이에요」를 붙입니다.
21. 5장에 글 상자를 더하고 본문 「그림책 읽기 모임에는 선착순으로 15명이 함께 참여해요」를 붙입니다.
22. 6장에 글 상자를 더하고 제목 「안내 데스크에서 신청해요」를 붙입니다.
23. 6장에 글 상자를 더하고 본문 「신청은 도서관 안내 데스크에서 해요. 토요일 아침에 만나요」를 붙입니다.
24. 제목 글 상자 6개의 글꼴을 제목 글꼴로 맞춥니다.
25. 제목 글 상자 6개의 크기를 72픽셀로 맞춥니다. 글꼴 크기를 바꾸는 메뉴는 화면에서 직접 찾습니다.
26. 본문 글 상자 6개의 글꼴을 본문 글꼴로 맞춥니다.
27. 본문 글 상자 6개의 크기를 40픽셀로 맞춥니다.
28. 모든 글 상자의 글자 색을 #2B2B2B로 맞춥니다. 글자 색을 바꾸는 메뉴는 화면에서 직접 찾습니다.
29. 각 장 본문에서 눈에 띄게 할 핵심 낱말을 골라 글자 색을 #1B7F3B으로 바꿉니다. 어느 낱말인지는 직접 정합니다.
30. 1장 오른쪽 아래에 글 상자를 더하고 쪽 번호 「1/6」을 붙입니다.
31. 2~6장에도 같은 자리에 쪽 번호 「2/6」 「3/6」 「4/6」 「5/6」 「6/6」을 하나씩 붙입니다. 자리를 맞추는 메뉴는 화면에서 직접 찾습니다.
32. 쪽 번호 글 상자 6개의 끝을 오른쪽과 아래 가장자리에서 120픽셀 안쪽에 맞춥니다.
33. 1장 왼쪽 아래에 글 상자를 더하고 이름 「우리 동네 도서관」을 붙입니다.
34. 2~6장에도 같은 자리에 이름 「우리 동네 도서관」을 붙입니다.
35. 이름 글 상자 6개를 왼쪽 가장자리에서 120픽셀 안쪽에 맞춥니다.
36. 쪽 번호와 이름 글 상자 12개의 크기를 28픽셀로 맞춥니다.
37. 1장에 책 모양 도형 하나를 넣습니다. 도형을 찾는 메뉴는 화면에서 직접 찾습니다.
38. 2~6장에도 책 모양 도형을 한 장에 하나씩 넣습니다. 자리는 `카드문구.md`의 그림 설명을 따릅니다.
39. 책 모양 도형 6개를 #1B7F3B으로 칠합니다.
40. 모든 글과 도형이 네 가장자리에서 120픽셀 안쪽에 들어왔는지 눈으로 확인합니다. 안내선을 켜는 메뉴는 화면에서 직접 찾습니다.

## 마지막 장 아래 출처 줄

41. 6장 쪽 번호 줄 바로 위에 글 상자를 더하고 「우리 동네 도서관 공지」를 붙입니다.
42. 출처 줄의 크기를 28픽셀로 맞춥니다.
43. 출처 줄의 글자 색을 #2B2B2B로 맞춥니다.
44. 출처 줄을 왼쪽에 맞춥니다.

## PNG 내려받기

45. 오른쪽 위 「공유 → 다운로드 → PNG」를 고릅니다.
46. 모든 페이지를 선택합니다.
47. 내려받습니다.
