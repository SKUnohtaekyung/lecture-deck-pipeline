# design.md — AI 활용 습관 점검 앱의 모양

에이전트는 화면을 만들 때 이 문서의 색과 모양을 따릅니다.

## 1. 색 (배경 60 · 메인 30 · 포인트 10)

| 역할 | 색 코드 | 쓰는 곳 |
|---|---|---|
| 배경 (60) | #F7F4EA | 화면 전체 바탕, 보기 버튼 바탕 |
| 메인 (30) | #1F4E5F | 제목 강조, 진행 막대, 유형 이름 |
| 포인트 (10) | #F2A65A | 시작 버튼, 내 위치 점, 복사 버튼 — 한 화면에 한두 곳만 |
| 글자 | #1B1B1B | 본문 |
| 카드 | #FFFFFF | 내용이 올라가는 흰 면 |

- 고른 곳: Color Hunt (https://colorhunt.co)
- 고른 이유: 짙은 청록은 차분하고 믿음이 가는 인상, 주황은 「해 볼 것」으로 눈을 끄는 용도

## 2. 분위기

담백하고 차분하게. 장식 그림은 넣지 않고 여백을 넉넉히 둡니다.

## 3. 글자

- 글꼴: Pretendard (없으면 맑은 고딕)
- 문항 24px 굵게 · 본문 17px · 보조 13px

## 4. 모양

- 카드 모서리 20px, 버튼 모서리 14px
- 그림자는 옅게 한 겹
- 버튼에 마우스를 올리면 살짝 떠오름

## 5. 확인할 것

- 글자와 배경의 대비가 충분한가 (포인트 색 위에는 검은 글자)
- 휴대폰 폭에서 버튼이 손가락으로 누르기 충분히 큰가
