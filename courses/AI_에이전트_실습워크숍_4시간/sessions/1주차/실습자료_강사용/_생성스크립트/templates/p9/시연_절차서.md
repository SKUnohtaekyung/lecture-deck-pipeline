# 시연 절차서 (강사용)

강사가 학생과 같은 흐름을 「이번 주 AI 소식」 카드뉴스로 한 번 보입니다. 소식은 금방 낡으므로 이 문서에 소식 내용을 적지 않고, 수업 전날 조사합니다. 이 문서는 학생 폴더에 넣지 않습니다.

## 수업 전날

1. 웹 검색이 되는 도구로 이번 주 AI 소식을 찾습니다. 공식 발표(회사 · 기관의 자체 블로그 · 보도자료 · 논문 페이지)를 1차 출처로 씁니다. 기사만 있는 소식은 공식 발표를 찾은 뒤에 쓰고, 못 찾으면 뺍니다.
2. 소식 3건을 고르고 건마다 사실 한 줄 · 발표일 · 출처 주소 · 확인한 날(전날 날짜)을 표로 적습니다. 숫자는 출처 원문 그대로 옮깁니다. 출처가 건마다 다르므로 카드의 출처 줄도 본문 장마다 그 건의 출처를 씁니다.
3. 출처 주소를 직접 열어 숫자와 날짜를 한 번 더 대조합니다. 열리지 않거나 날짜가 없는 것은 뺍니다.
4. 시연 폴더를 새로 만들어 `품질기준.md`와 `카드규격.md`를 복사합니다. 학생 폴더와 같은 파일입니다.
5. 두 파일의 「확인:」 칸을 채웁니다. `카드규격.md`에는 인스타그램 올리기 화면이 받는 카드 비율 · 장 수와 확인한 날을, `품질기준.md`에는 Canva 화면 이름 표와 무료 표시 · 워터마크 규칙을 Canva 화면과 하나씩 맞춘 날을 적습니다. 로그인과 「사용자 지정 크기」로 새 디자인 열기도 확인합니다. 채운 뒤 「확인:」 줄에 빈 칸(____)이 남지 않았는지 찾고, 채운 두 파일을 학생 폴더에도 다시 나눕니다. 비워 두면 에이전트가 올리기 화면의 값을 학생에게 묻고 Canva 표는 참고로만 씁니다.
6. 에이전트 도구에서 웹 검색이 되는지 확인합니다. 안 되면 2의 표를 텍스트 파일로 만들어 사용자가 준 자료로 씁니다.
7. 시연 흐름을 전날 한 번 끝까지 해 봅니다. 카드 5장 PNG와 `카드문구.md`를 예비로 저장합니다.
8. 학생 폴더에는 `예시/`를 만들지 않습니다. 시연 소식은 날짜가 지나면 낡기 때문입니다.

## 시연 흐름과 보일 곳

시연 카드는 표지 1 · 본문 3(소식 3건) · 마무리 1, 모두 5장입니다. 강사가 사용자 역할로 답하고, 답은 전날 정해 둡니다. 장 수 · 모양 · 색 · 글꼴은 이날 강사가 정한 값이고 학생은 각자 정한다고 말합니다. 질문 하나는 「예를 들어 줘」로 답해 보기가 나오는 것을 보이고, 묻지 않은 값에 「기본값」 줄이 붙는 것은 승인 요청에서 보입니다.

| 단계 | 하는 일 | 학생에게 보일 곳 |
|---|---|---|
| 내용 인터뷰 | 질문 세 개씩 받고 답합니다. 글의 양은 「예를 들어 줘」로 보기를 받아 고르고, 말투는 한 줄로 직접 답합니다 | 질문마다 비유가 붙는 것 · 에이전트가 대신 정하지 않는 것 · 승인 때 「기본값 · 바꿀 수 있음」 줄 · 보기 |
| 자료 정리 | 검색어 승인 후 검색, 사실표 확인 | 검색 전에 검색어를 보여 주고 승인을 기다리는 것 · 사실표의 출처 주소와 날짜 |
| 카드 문구 | 두 장씩 받고 「좋아」로 승인 | 두 장씩 받는 것 · 글자 수가 정한 값 안인 것 · 본문 장마다 출처 줄이 붙는 것 |
| 디자이너 인터뷰 | 질문 10개, 색은 강사가 말하기 | 세 개씩 묻는 것 · 말한 색의 대비 계산식과 값 · 승인 때 분량 점검 줄 |
| Canva 조립 | `만들기안내.md`를 한 줄씩 따라 손으로 만들기 | 에이전트가 만든 것은 문구와 안내이고 카드는 사람이 만드는 것 |
| 대조 | 카드의 숫자 · 날짜와 출처를 표로 비교 | 같음 · 다름 · 출처 없음 표 |

시간이 모자라면 Canva 조립은 표지와 본문 한 장까지만 손으로 보이고, 나머지 장은 전날 저장한 파일을 열어 보입니다.

## 막혔을 때

- 웹 검색이 안 됨: 전날의 표를 사용자가 준 자료로 붙입니다.
- 검색이 느림: 전날의 표를 열어 다음 단계로 갑니다.
- Canva 로그인이나 메뉴 이름이 다름: 예비 PNG를 보입니다. 달라진 이름은 수업 뒤 `품질기준.md`의 표에 반영합니다.
- 대조에서 다름이 나옴: 그대로 보이고 한 장만 고칩니다.

## 수업 뒤

시연한 소식은 다음 수업에서 낡습니다. 시연 폴더의 소식 내용을 `실습9_카드뉴스` 폴더로 옮기지 않습니다.
