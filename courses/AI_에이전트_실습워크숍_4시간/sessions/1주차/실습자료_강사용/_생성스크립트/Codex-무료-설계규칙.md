# Codex 무료 요금제 설계 규칙 (실습 준비물 공통)

> 2026-10-20 신설 · 정본 계획 `plans/FRAME-실습강화/PLAN.md` §3 · 근거 `plans/FRAME-실습강화/조사결과.md` §2.
> 새 실습을 만들거나 기존 실습의 준비물을 고칠 때 이 표를 먼저 본다. 기준선(턴 수 · 시간)은 `../드라이런_기록.md`의 사용자 실측으로만 바꾼다.

## 왜 필요한가

Codex 무료는 ChatGPT 데스크톱 앱에서만 쓸 수 있고, 한도 수치가 공개되지 않았다(5시간 창 + 주간 상한 구조만 공개). 참가자 모델은 Claude보다 덜 강하다. 그래서 두 가지를 함께 줄인다.

- **결정** — 디자인 · 타이밍 · 호출 주소처럼 모델이 스스로 정하면 무너지는 것을 준비물에 이름으로 고정한다.
- **토큰** — 모델이 읽는 양과 대화 턴 수를 설계로 줄인다. 영상도구 113KB를 통째로 읽으면 그것만으로 약 3만 토큰이다.

## 규칙 7가지

| # | 규칙 | 준비물에서 지키는 방법 | 점검 |
|---|---|---|---|
| 1 | 에이전트가 읽는 파일 합계 15KB 이하 | 도구 본체 HTML은 「열지 않는다」를 본체 첫 줄 주석과 품질기준 첫 줄에 적는다. 에이전트가 쓰는 데이터는 작은 파일(`장면.js` · `slides.js` · `계획.js` · `카드.js`)로 떼어 본체가 `<script src>`로 읽게 한다 | 품질기준 + 이름표 + 데이터 파일 크기 합 |
| 2 | 결정은 이름으로 고른다 | 부품마다 이름표 문서 3KB 이하(이름과 한 줄 뜻). 좌표 · 색 코드 · 호출 주소를 에이전트가 짓지 않는다 | 이름표에 없는 이름을 쓰면 점검 패널이 「고칠 곳」으로 센다 |
| 3 | 인터뷰는 한 번에 질문 세 개 · 최대 10번(2026-10-07 사용자 결정 · `gen_rules.py` 공통부) · 참가자 메시지 합계 25 이하 | 질문표를 세 개씩 「묶음」으로 짠다 | 대리 시험과 드라이런에서 주고받은 횟수와 메시지 수를 센다 |
| 4 | 첫 단계만 만들고 승인받은 뒤 나머지 | 장면 1 · 슬라이드 1 · 화면 1부터 | 품질기준 「일하는 순서」 |
| 5 | 점검 패널과 「결과 복사」 | 에이전트는 브라우저를 보지 못한다. 패널이 고칠 곳 · 통과 · 미판정 개수를 세고, 참가자가 복사한 글을 대화에 붙인다 | 미판정은 통과에 넣지 않는다 |
| 6 | 설치 0 · 더블클릭으로 열림 · 한 파일로 되면 한 파일(profile §9 · 2026-10-06 완화) | 데이터는 `.js`로 둔다 — 더블클릭(file://)으로 연 페이지는 옆의 `.json` · `.csv`를 못 읽는다(덱 `M2-V`). 서버는 에이전트가 켜 주는 미리보기까지만(profile §6). 외부 스크립트는 지도 라이브러리(Leaflet) 1건까지 | 생성 스크립트가 외부 `<script>` 수를 센다 |
| 7 | 한도가 다 되면 다른 도구로 이어 간다 | 상태는 전부 폴더 안 파일에 있다. 품질기준 끝에 「이어가기」 절을 둔다(같은 폴더를 Antigravity로 열고 「품질기준.md를 읽고 지금 파일 상태에서 이어서 해 줘」) | 드라이런 기록의 한도 경고 열 |

## 품질기준 첫머리에 넣을 문장(공통)

```
이 폴더에서 에이전트가 읽는 파일은 품질기준.md · 이름표 문서 · 데이터 파일(.js)뿐입니다.
도구 본체(.html)는 열지 않습니다. 화면은 사용자가 브라우저로 보고, 점검 패널의 결과를 복사해 대화에 붙여 줍니다.
```

## 대리 시험 프로토콜(메인 실행 · 연기 시험)

참가자 도구로 돌린 결과가 아니다. 동작 · 읽기량 · 턴 수가 설계대로인지만 본다.

1. Sonnet 저추론 서브에이전트에게 실습 폴더 사본(`tmp/frame-실습강화/dry/<실습>/`)과 품질기준만 준다. 참가자 역할 답은 미리 적은 답안지로 준다.
2. 센다: 턴 수 · 읽은 파일 이름과 KB · 도구 본체를 열었는지 · 고칠 곳 0 도달 여부.
3. 기준을 넘으면 준비물을 고친다. 모델 탓으로 넘기지 않는다.
4. 통과해도 「검증 완료」로 적지 않는다. 사용자 드라이런(Codex 무료 · Antigravity)이 검증이다.
