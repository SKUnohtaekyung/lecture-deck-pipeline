| 슬라이드 | 채택 | 왜 |
|---|---|---|
| 1 정보 구조 | **B** | 빙산 도해가 「보이는 것 ⊂ 결정한 것」을 즉시 전달 |
| 2 화면 순서 | **B** | 두 장 비교 + 시선 경로로 «왜»를 눈으로 증명 |
| 3 화면 문구 | **A** | 정보 모양이 mapping — **1:1 대응 표가 카드 병렬보다 낫다** |
| 4 가독성·접근성 | **B** | 색각 시뮬레이션이 수치보다 설득력 있다 |
| 5 DESIGN.md | **B** | 전/후 비교 + 메모지가 구체적 |
| 6 디자인 토큰 | **B** | 값→이름→재사용 3단이 방사보다 과정을 보여준다 |

**5구간 CSS는 병합본이다** — B 전체 + A의 `w5-map` 블록. 수정할 때 `w5b-*`와 `w5-map` 두 계열이 함께 있다는 점을 유의한다. 판정 근거 전문: `reports/create-slides-quality/P7_ab_criteria.md`.
