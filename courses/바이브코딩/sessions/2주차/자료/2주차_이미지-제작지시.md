## 2. 안전영역 (IMAGE_PLAN.md §2 요약)

```
캔버스: 1280 × 720
이미지 안전영역: x ∈ [64, 1216]  y ∈ [118, 666]
```

이미지 렌더 bbox가 이 사각형을 1px이라도 벗어나면 FAIL이다. `y < 118`은 헤더 침범, `y > 666`은 페이지 번호 침범이다.

## 3. 슬롯 계약 (IMAGE_PLAN.md §3 요약)

새 좌표를 발명하지 말고 아래 4종 중 하나를 고른다. 안 맞으면 §9(중단 조건)에 따라 보고한다.

| 슬롯 | 용도 | 이미지 기하 | 본문 인셋 |
|---|---|---|---|
| **SLOT-R** | 좌 글 / 우 이미지 | `right:64 top:150 width:404 height:460` → x[812,1216] y[150,610] | `.s-full{right:500}` |
| **SLOT-L** | 좌 이미지 / 우 글 | `left:64 top:150 width:404 height:460` → x[64,468] y[150,610] | `.s-full{left:500}` |
| **SLOT-B** | 상 글 / 하 이미지 | `left:64 right:64 top:392 height:268` → x[64,1216] y[392,660] | `.s-full{bottom:360}` |
| **SLOT-C** | 이미지가 주인공 | `left:190 right:190 top:196 height:424` → x[190,1090] y[196,620] | 제목만 위 |
| **SLOT-B2**(한 슬라이드 2장 전용) | 좌: `left:64 top:392 width:560 height:268` / 우: `right:64 top:392 width:560 height:268` | | `.s-full{bottom:360}` |

**최소 크기**: `explanatory`·`mnemonic` 이미지는 면적 ≥ 67,200px²이고 짧은 변 ≥ 240px. 위 슬롯은 전부 이 하한을 넉넉히 만족한다.

**TEXT_SAFE_SIDE는 슬롯이 정한다** — 프롬프트 작성 시 아래 대응표를 그대로 쓴다.

| 슬롯 | TEXT_SAFE_SIDE | 이유 |
|---|---|---|
| SLOT-R | `left` | 글이 왼쪽에 있으니 이미지 왼쪽에 여백 |
| SLOT-L | `right` | 반대 |
| SLOT-B | `top` | 글이 위 |
| SLOT-C | `none` | 이미지가 주인공 |

## 4. 이미지 19장의 완성된 프롬프트

각 프롬프트는 **[1층] 의미 브리프 → [2층] 공통 스타일 → [3층] 출력 경로** 순서로 조립된 완성본이다. **2층과 3층을 섞지 마라** — 크로마(3층) 프롬프트에 `transparent`·`alpha`·`no backdrop` 문자열을 넣지 않는다.

파일명 규약: `sNN_<슬러그>-paper-cut-v1-transparent.png`
저장 경로: `courses/바이브코딩/sessions/2주차/자료/images/`
