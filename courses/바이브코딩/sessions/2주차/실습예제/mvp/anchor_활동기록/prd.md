# 오늘의 활동 기록 도구

## 1. 누구에게 어떤 도움·결과·경험을 제공하는가
하루를 정리하고 싶은 사람이 오늘 한 활동을 한 줄씩 적어, 지금까지 한 일을 한눈에 볼 수 있게 돕는다.

## 2. 핵심 기능 하나
활동 한 줄을 입력하고 기록하기를 누르면 오늘 기록 목록에 그 활동이 추가된다.

## 3. 대표 사용 흐름
활동 한 줄 입력 → 기록하기 버튼 → 오늘 기록 영역에 목록으로 표시

## 4. 이번에 만들 것과 만들지 않을 것
- 만들 것: 활동 한 줄 입력, 기록하기 버튼, 오늘 기록 목록 표시, 빈 입력 안내 문구
- 만들지 않을 것: 저장(새로고침하면 기록이 사라짐), 날짜 구분, 수정·삭제, 검색, 분류, 여러 사용자

## 5. 구현 완료 기준
- 활동을 입력하고 기록하기를 누르면 아래 목록에 그 활동이 보인다.
- 여러 번 입력하면 목록에 순서대로 쌓인다.
- 빈 칸으로 기록하기를 누르면 안내 문구가 보이고 빈 항목은 추가되지 않는다.
- 새로고침하면 목록이 비워진다(저장 기능이 없으므로 정상).
