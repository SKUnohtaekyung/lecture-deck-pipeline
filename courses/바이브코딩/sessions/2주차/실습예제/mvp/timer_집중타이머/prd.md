# 집중 타이머

## 1. 누구에게 어떤 도움·결과·경험을 제공하는가
공부나 일에 집중하고 싶은 사람이, 정한 시간 동안 남은 시간을 눈으로 보며 집중하고 끝나면 알 수 있게 돕는다.

## 2. 핵심 기능 하나
입력한 분만큼 시간을 세어 남은 시간을 분:초로 보여 주고, 0이 되면 종료 안내를 표시한다.

## 3. 대표 사용 흐름
집중 시간(분) 입력 → 시작 버튼 → 남은 시간 표시(줄어듦) → 0이 되면 종료 안내

## 4. 이번에 만들 것과 만들지 않을 것
- 만들 것: 분 입력, 시작 버튼, 남은 시간 표시(분:초), 종료 안내 문구
- 만들지 않을 것: 저장, 일시정지·재개, 알림 소리, 여러 타이머, 기록 통계

## 5. 구현 완료 기준
- 분을 입력하고 시작을 누르면 남은 시간이 1초마다 줄어든다.
- 남은 시간이 0이 되면 카운트다운이 멈추고 종료 안내가 보인다.
- 다른 분으로 다시 시작하면 새 시간으로 다시 센다.
