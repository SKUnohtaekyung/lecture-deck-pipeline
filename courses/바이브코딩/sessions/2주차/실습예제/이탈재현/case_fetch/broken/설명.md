# case_fetch — 로컬 파일 fetch() 범위 이탈

## 증상 (file:// 로 index.html 을 열면)
- 화면(제목·설명·입력창·버튼)은 정상으로 보이고 스타일도 적용된다.
- 그러나 시작 기록 두 개("아침 스트레칭", "책 20쪽 읽기")가 목록에 나오지 않고 "아직 기록이 없어요."만 보인다.
- 콘솔에 "데이터를 불러오지 못했습니다. TypeError: Failed to fetch" 같은 오류가 뜬다.
- (입력창에 직접 쳐서 "기록 추가"를 누르면 그 항목은 추가되지만, 파일에 있던 시작 데이터는 끝내 안 나온다.)

## 원인 (쉬운 말로)
- `script.js` 가 시작 데이터를 옆에 있는 `data.json` 파일에서 `fetch()` 로 읽어 오려 한다.
- `fetch()` 로 로컬 파일을 읽는 것은 웹 주소(http)로 열 때만 허용되고, 파일을 직접 여는 `file://` 방식에서는 브라우저가 막는다.
- 그래서 시작 데이터 불러오기가 실패하고 목록이 비어 보인다.

## 최소 복구 (broken/ 을 fixed/ 로)
1. `script.js` 의 `fetch("./data.json") ... ` 블록 전체를 지운다.
2. 맨 위 `var activities = [];` 를 시작 데이터가 담긴 배열로 바꾼다: `var activities = ["아침 스트레칭", "책 20쪽 읽기"];`
3. 더 이상 읽지 않는 `data.json` 은 지운다(원한다면 기획 참고용으로 남겨도 되지만 웹페이지가 실행 중 읽지는 않는다).

### Codex 에게 할 요청문 예시
> 이 프로젝트는 file:// 로 직접 열어요. 그런데 script.js 가 data.json 을 fetch() 로 불러와서 시작 데이터가 안 보여요. fetch 를 없애고, data.json 안의 값을 script.js 안에 일반 배열로 직접 넣어 주세요. 나머지 화면과 기능은 그대로 두고 이 부분만 최소로 고쳐 주세요.
