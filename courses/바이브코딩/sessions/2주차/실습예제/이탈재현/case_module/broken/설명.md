# case_module — type=module / import·export 범위 이탈

## 증상 (file:// 로 index.html 을 열면)
- 제목·설명·입력창·버튼은 보이지만, 시작 기록 두 개("아침 스트레칭", "책 20쪽 읽기")가 목록에 나오지 않는다.
- "기록 추가" 버튼을 눌러도 아무 일도 일어나지 않는다.
- 개발자 도구(F12) 콘솔에 CORS/모듈 로드 오류가 뜬다. 예: "Access to script at 'file:///.../script.js' from origin 'null' has been blocked by CORS policy".

## 원인 (쉬운 말로)
- `index.html` 이 `<script type="module">` 로 스크립트를 불러오고, `script.js` 가 `import` 로 `data.js` 를 가져오도록 되어 있다.
- 이런 "모듈" 방식은 웹 주소(http)로 열 때만 허용되고, 파일을 브라우저에 직접 끌어다 여는 `file://` 방식에서는 브라우저가 보안상 막는다.
- 그래서 `script.js` 전체가 아예 실행되지 않아 화면 뼈대만 남고 기능이 죽는다.

## 최소 복구 (broken/ 을 fixed/ 로)
1. `index.html` 의 `<script type="module" src="./script.js">` 에서 `type="module"` 을 지워 일반 스크립트로 바꾼다.
2. `script.js` 의 `import { initialActivities } from "./data.js";` 줄을 지우고, 데이터를 `script.js` 안에 직접 배열로 적는다: `var activities = ["아침 스트레칭", "책 20쪽 읽기"];`
3. 더 이상 쓰지 않는 `data.js` 는 지운다. `export` 도 함께 사라진다.

### Codex 에게 할 요청문 예시
> 지금 프로젝트를 file:// 로 직접 열 건데 모듈 방식 때문에 안 돼요. index.html 에서 script 태그의 type="module" 을 없애고, script.js 의 import/export 를 제거해서 데이터를 script.js 안에 일반 배열로 넣어 주세요. 화면과 기능은 그대로 두고, 이 문제 하나만 최소로 고쳐 주세요.
