# case_abspath — 프로젝트 밖 C:\ 절대경로 참조

## 폴더 상태 (재현용)
```
broken/
├─ index.html   (CSS·이미지를 file:///C:/Users/lecture/... 절대경로로 참조)
└─ script.js    (상대경로 ./script.js — 기능은 동작)
```
- 프로젝트 안에 `style.css` 도 `assets/` 도 없다. CSS·이미지가 전부 프로젝트 밖 특정 PC 경로를 가리킨다.

## 증상 (file:// 로 index.html 을 열면)
- 스타일이 적용되지 않아 밋밋한 기본 화면으로 나온다(카드·색·버튼 모양 없음).
- 제목 옆 로고 자리에 깨진 이미지 아이콘이 뜬다.
- 반면 "기록 추가" 버튼은 동작한다(스크립트만 상대경로라서). → 스타일·이미지 경로 문제라는 것을 알 수 있다.
- 콘솔에 style.css, 앵커로고.png 를 찾지 못했다는 오류(ERR_FILE_NOT_FOUND)가 뜬다.
- 이 구조는 다른 수강생 PC 로 폴더를 복사해도 똑같이 깨진다. `C:/Users/lecture/...` 경로가 그 PC 에는 없기 때문이다.

## 원인 (쉬운 말로)
- CSS 와 이미지를 `file:///C:/Users/lecture/Desktop/...` 같은 "그 컴퓨터에만 있는 정확한 위치(절대경로)"로 적었다.
- 절대경로는 그 PC 에서만 맞고, 파일을 프로젝트 밖에 두면 폴더를 통째로 옮기거나 다른 사람에게 주는 순간 전부 깨진다.

## 최소 복구 (broken/ 을 fixed/ 로)
1. CSS 파일을 프로젝트 안으로 가져와 `style.css` 로 두고, 링크를 `./style.css` 로 고친다.
2. 이미지를 프로젝트 안 `assets/` 폴더에 넣고(`assets/logo.svg`), `<img src="assets/logo.svg">` 처럼 상대경로로 고친다.
3. `C:\`, `file:///C:/...` 같은 절대경로가 코드에 남아 있지 않은지 확인한다.

### Codex 에게 할 요청문 예시
> 지금 index.html 이 CSS 와 이미지를 C:\Users\lecture\... 절대경로로 참조해서 다른 PC 에서 다 깨져요. CSS 는 프로젝트 안 style.css 로, 이미지는 assets/ 폴더 안으로 옮기고, 참조를 ./style.css 와 assets/ 상대경로로 바꿔 주세요. 프로젝트 밖 경로나 C:\ 절대경로는 남기지 말아 주세요.
