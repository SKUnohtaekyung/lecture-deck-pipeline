# case_subfolder — index.html 이 하위 폴더에 있고 경로가 꼬임

## 폴더 상태 (재현용)
```
broken/
└─ pages/
   ├─ index.html   (../style.css, ../script.js 로 부모를 가리킴)
   ├─ style.css     (실제로는 index.html 과 같은 pages/ 안에 있음)
   └─ script.js
```
- 프로젝트 루트에 `index.html` 이 없다. 세 파일이 모두 `pages/` 안에 몰려 있다.

## 증상 (file:// 로 pages/index.html 을 열면)
- 스타일이 하나도 적용되지 않아 흰 배경에 기본 글꼴로 밋밋하게 나온다(카드·색·버튼 모양 없음).
- "기록 추가" 버튼을 눌러도 반응이 없다(스크립트가 안 붙음).
- 콘솔에 style.css, script.js 를 찾지 못했다는 오류(ERR_FILE_NOT_FOUND)가 뜬다.

## 원인 (쉬운 말로)
- AI 가 `index.html` 을 프로젝트 루트가 아니라 `pages/` 하위 폴더에 만들었다.
- 게다가 링크를 `../style.css`, `../script.js` 로 "한 단계 위 폴더"를 가리키게 적었는데, 실제 CSS·JS 파일은 `index.html` 과 같은 폴더에 있다. 그래서 브라우저가 파일을 엉뚱한 곳에서 찾다 못 찾는다.

## 최소 복구 (broken/ 을 fixed/ 로)
1. `pages/index.html`, `pages/style.css`, `pages/script.js` 세 파일을 프로젝트 루트로 옮긴다.
2. 빈 `pages/` 폴더는 지운다.
3. `index.html` 의 링크를 같은 폴더를 뜻하는 `./style.css`, `./script.js` 로 고친다.
4. 프로젝트 루트의 `index.html` 을 직접 열어 스타일·기능이 나오는지 확인한다.

### Codex 에게 할 요청문 예시
> index.html 이 pages 하위 폴더에 생겨서 스타일과 스크립트가 안 붙어요. index.html, style.css, script.js 를 프로젝트 루트로 옮기고, index.html 의 경로를 ./style.css, ./script.js 로 정리해 주세요. 빈 pages 폴더는 지워 주세요. 내용은 그대로 두고 위치와 경로만 최소로 고쳐 주세요.
