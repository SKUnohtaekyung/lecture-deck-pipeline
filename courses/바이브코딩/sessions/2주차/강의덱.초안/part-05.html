브라우저 직접 실행 vs 서버 방식

직접 열기(file://)

  • 우리는 index.html을 직접 엽니다(file://).
  • 주소창이 file:///C:/...로 시작합니다.
  • 인터넷 연결 없이도 화면이 뜹니다.
≠

서버 방식

  • module·로컬 fetch는 서버가 필요 → 이번 범위 밖
  • 주소창이 http://localhost:...처럼 시작합니다.
  • 이번 수업은 서버 없이 진행합니다.
