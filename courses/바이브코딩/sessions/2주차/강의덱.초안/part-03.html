PRD와 prd.md 핵심 구분

PRD

  • 무엇을 왜 만들지 적는 기획 문서(조직마다 다름·회사는 30쪽도)
  • 제품 매니저가 팀에 방향을 알리는 문서입니다
≠

prd.md

  • 우리 최소 5줄 — 대상·핵심·흐름·제외·완료
  • AI는 코드를 만들기 전에 이 문서를 먼저 읽습니다
  • 다 만든 뒤에는 결과를 이 기준과 맞춰 봅니다

PRD(개념) ≠ prd.md(구현)

AGENTS.md는 무엇·왜 (최소 소개)

Codex가 작업 시작 전 자동으로 읽는 규칙 파일입니다.

AGENTS.md

  • 언제 읽히나 작업 시작마다 항상 자동으로
  • 무엇을 담나 프로젝트에서 계속 지킬 공통 규칙
  • 없으면 매번 같은 이탈을 반복합니다
호출 조건 ⇄ 항상 자동
↔ 필요할 때만

Skill

  • 언제 호출되나 요청이 맞을 때만 골라서
  • 무엇을 담나 특정 절차 하나를 담은 지침·자료 묶음
  • 없으면 매번 같은 절차를 처음부터 다시 설명해야 합니다

AI의 기억이 아니라, 사람이 적어 둔 만큼만 지키는 고정된 규칙입니다. 하위 폴더에 규칙 파일을 또 두면 위쪽 규칙을 덮어쓰는 것이 아니라 누적됩니다 — 덮어쓰기로 이해하면 오개념입니다.

실습 ⑤ prd.md 만들기 (ChatGPT 초안 → 사람 수정 → Codex 저장)

1ChatGPT로 5항목(대상·핵심·흐름·제외·완료) 초안을 만듭니다.
2사람이 읽고 최소 1개를 수정합니다(단어만 바꾸는 건 수정 아님).
3Codex로 프로젝트에 prd.md로 저장합니다.
완성

다시 읽을 기준 문서 + 내가 바꾼 결정 1개

완료 확인 5항목이 모두 채워진 prd.md 파일이 프로젝트 폴더 안에 있습니다.

자주 막히는 지점 빈 칸을 하나 남긴 채 저장합니다 — 다섯 칸을 다 채워야 완성입니다.
