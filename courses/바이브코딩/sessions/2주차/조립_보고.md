## 2. 실행 중 발견해 고친 결함 (수정요청서에 없던 것)

1. **`assemble_deck`이 CSS 주석 안 마크업 예시를 슬라이드로 셌다.**
   shell의 P0 주석에 쓴 `<section … data-slide="MN">` 예시가 유령 슬라이드 1장으로 잡혔다.
   → 주석 안 태그를 전부 비태그 표기로 바꿨다. 재발 방지 주석을 같은 자리에 남겼다.
2. **`.w2-ed-code > li`의 익명 격자 아이템 사고**(MEMORY의 R-QC-19 유형).
   마크다운 에디터에서 `<span>` 뒤의 맨 텍스트가 별도 격자 아이템이 되어 4줄이 133~207px로
   부풀고 슬라이드를 **1118px까지** 넘겼다. → 각 줄을 `<span class="ln">`으로 감쌌다.
3. **`.sub` 클래스명 충돌.** kit이 이미 `.cmp .sub{font-size:13px}`를 쓰고 있어
   §0-1 대체 줄을 `.sub`로 만들면 그 컴포넌트가 조용히 깨진다 → `.subline`으로 명명.
4. **R-QC-08 검출기가 새 시각자료를 못 봤다.**
   `viz-*` 클래스·`<canvas>`·`<img>`만 세는데, 이번에 만든 앱 UI·에디터·화면 흐름은
   HTML/CSS라 0으로 집계됐다. **경보를 해석으로 끄지 않고** 실제 시각자료 14곳에
   `viz-*` 클래스를 붙여 지표가 실제를 반영하게 했다(30.8% → 42.3%).
