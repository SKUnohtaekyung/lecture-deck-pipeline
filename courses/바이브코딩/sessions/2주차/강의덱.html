User Flow란?

User Flow(사용자 흐름)는 사용자가 하나의 목표를 완료하기 위해 제품 안에서 밟는 화면과 행동의 순서를 나타낸 지도입니다.

우리 수업에서는 무엇을 입력·선택하고 → 어떤 버튼을 누르고 → 무엇을 보는지의 순서로 이 지도를 표현합니다.

1무엇을 입력·선택하고

PRD

PRD (Product Requirements Document, 제품 요구사항 문서)는 무엇을 왜 만드는지를 적어 팀에 방향을 알리는 기획 문서입니다.

1제품 매니저가 씁니다. — 개발자와 디자이너가 같은 목표를 보도록, 무엇을 왜 만드는지 팀 전체에 미리 알립니다. 방향이 다르면 서로 다른 것을 만들게 됩니다. 그래서 코드를 짜기 전에 먼저 씁니다.
2조직마다 형식이 다릅니다. — 정해진 표준 양식이 없어 회사마다, 팀마다 담는 항목과 순서가 제각각입니다. 그래서 "이게 PRD의 정답"이라는 틀은 없습니다. 우리 수업도 우리만의 형식을 씁니다.
3실제 회사에서는 수십 쪽이 되기도 합니다. — 배경 조사·성공 지표·예외 상황까지 담다 보면 문서가 길어지기 때문입니다. 팀이 클수록 문서도 두꺼워집니다. 다음 장에서 우리가 쓰는 작은 버전을 봅니다.
