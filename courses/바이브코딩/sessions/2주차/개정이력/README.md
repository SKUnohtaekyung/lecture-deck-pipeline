2주차 덱이 **어떤 요청으로 어떻게 바뀌어 왔는지**의 기록이다. 사용자 원본 요청·실행 계획·중간 결정본을 시간순으로 모았다.

- 이 폴더는 **이력 보관소**다. 현재 상태를 알고 싶으면 여기가 아니라 `../조립_보고.md`(무엇을 왜 그렇게 만들었나)와 `../deck.contract.json`(구조 계약)을 본다.
- 여기 있는 계획서는 **그 시점의 스펙**이다. 나중에 뒤집힌 결정이 그대로 남아 있으니, 최신 판정은 언제나 `.agents/agent-memory/create-slides/MEMORY.md`의 「2주차 현재 상태」가 이긴다.
- 2026-08-04 신설. 그 전에는 전부 주차 폴더 최상위에 흩어져 있었다(아래 §대응표).
