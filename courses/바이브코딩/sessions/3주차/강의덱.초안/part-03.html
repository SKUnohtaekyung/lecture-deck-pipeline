HTML · CSS · JS · QA 담당

사람 이름이 아니라 파일 이름이 담당 경계가 됩니다.

index.html → HTML 담당구조를 봅니다
style.css → CSS 담당스타일을 봅니다
script.js → JS 담당동작을 봅니다
화면 → QA 담당파일이 아니라 화면을 검증합니다
경계가 파일이라 겹칠 수가 없습니다. 이게 오늘 사고를 막아 줍니다.

실습 ⑤ — 그대로 복사해 쓰세요

팀 구성 프롬프트

이렇게 말하세요

이 프로젝트에 AI 개발팀을 구성해 줘.

다음 네 개의 전문 서브에이전트를 만들어.

1. HTML 담당 — 화면 구조 · index.html

2. CSS 담당 — 스타일 · style.css

3. JS 담당 — 동작 · script.js

4. QA 담당 — 검증 · 화면 전체

각 담당은 자신의 이름과 역할을 인식해야 한다. 역할을 질문받으면 "나는 OO 담당이야."라고 답해야 한다.

각 담당은 자기 파일에만 집중하고, 메인은 요청에 따라 적절한 담당에게 작업을 위임한다.

이 구성이 이후 작업에도 유지되도록 필요한 Codex 설정 파일과 AGENTS.md를 생성해 줘.

초보자가 추가로 수정하지 않아도 바로 사용할 수 있도록 완성해 줘.

마지막에 생성한 파일과 각 담당의 호출 방법을 설명해 줘.
