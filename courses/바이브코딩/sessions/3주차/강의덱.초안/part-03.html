HTML · CSS · JS · QA 담당

사람 이름이 아니라 파일 이름이 담당 경계가 됩니다.

index.html → HTML 담당구조를 봅니다
style.css → CSS 담당스타일을 봅니다
script.js → JS 담당동작을 봅니다
화면 전체 → QA 담당파일이 아니라 화면 전체를 검증합니다
경계가 파일이라 겹칠 수가 없습니다. 이게 오늘 사고를 막아 줍니다.

이 프로젝트에 AI 개발팀을 구성해줘.

다음 네 명의 전문 서브에이전트를 만들어.

1. 짱구 — HTML 담당

2. 철수 — CSS 담당

3. 훈이 — JS 담당

각 에이전트는 자신의 이름과 역할을 인식해야 한다. 이름이나 역할을 질문받으면 “나는 [역할] [이름]이야.”라고 답해야 한다.

각 에이전트는 자신의 담당 영역에 집중하고, 메인 에이전트는 요청에 따라 적절한 에이전트에게 작업을 위임한다.

이 구성이 이후 작업에도 유지되도록 필요한 Codex 설정 파일과 AGENTS.md를 생성해줘.

초보자가 추가로 수정하지 않아도 바로 사용할 수 있도록 완성하고, 생성한 파일과 각 에이전트의 호출 방법을 마지막에 설명해줘.
