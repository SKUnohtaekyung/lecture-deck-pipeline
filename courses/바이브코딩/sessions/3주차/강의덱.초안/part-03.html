HTML · CSS · JS · QA 담당

사람 이름이 아니라 파일 이름이 담당 경계가 됩니다.

index.html → HTML 담당구조를 봅니다
style.css → CSS 담당스타일을 봅니다
script.js → JS 담당동작을 봅니다
화면 → QA 담당파일이 아니라 화면을 검증합니다
경계가 파일이라 겹칠 수가 없습니다. 이게 오늘 사고를 막아 줍니다.

실습 ④

내 프로젝트에 담당 배정하기

1내 프로젝트를 HTML · CSS · JS · QA 네 담당으로 나눕니다.
2각 담당이 어느 파일을 맡을지 한 줄씩 적습니다.
3파일이 3개뿐이어도 괜찮습니다 — QA 담당은 파일 대신 화면을 맡습니다.
이렇게 말하세요

"내 프로젝트를 HTML(구조) · CSS(스타일) · JS(동작) · QA(검증) 네 담당으로 나눈다면 각각 어떤 파일을 맡으면 좋을지 제안해 줘. 파일은 아직 고치지 마."

완성 기준 — 파일마다 담당이 하나씩 정해짐
