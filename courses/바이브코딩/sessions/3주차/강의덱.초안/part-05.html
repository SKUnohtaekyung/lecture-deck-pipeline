GitHub — 저장소와 커밋

GitHub — 내 프로젝트를 인터넷에 보관하고 변경 이력을 남기는 서비스

저장소(repository) — 내 프로젝트가 통째로 올라가는 자리

커밋(commit) — 무엇을 왜 바꿨는지 적어 남기는 기록 한 건

사진첩과 같습니다 — 저장소가 앨범이고, 커밋은 날짜와 설명이 붙은 사진 한 장입니다.

VIBECODING

저장소는 두 곳에 있습니다

같은 이름이지만 자리가 다릅니다.

커밋은 내 컴퓨터에서 만들어집니다 — 올려야 GitHub에 보입니다. 오늘은 혼자 쓰니 가져올 것이 없지만, 다른 곳에서도 고치거나 팀으로 쓰면 먼저 가져온 뒤에 시작해야 섞이지 않습니다.

VIBECODING

커밋은 「무엇을 올릴지 고르는 것」부터입니다

바뀐 것을 다 올리지 않습니다. 고를 수 있습니다.

장바구니에 다 쓸어 담고 계산하는 것과 하나씩 고르는 것의 차이입니다.

저장소 연결과 변경 파일 확인

2오늘 바뀐 파일 목록을 아직 올리지 말고 눈으로 봅니다.
