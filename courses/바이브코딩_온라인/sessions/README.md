# 회차별 작업 공간

저장소 도구와의 호환을 위해 폴더명은 `N주차`를 사용한다. 강의 화면·문서의 회차명은 **오전·오후**로 표시한다.

| 폴더 | 회차 | 핵심 실습 |
|---|---|---|
| `1주차/` | 오전 · 말로 바로 만들고 고치기(2시간) | 내 단어로 타자 게임 만들기 · 한 번에 하나씩 고치기 |
| `2주차/` | 오후 · 기준을 먼저 세우고 만들기(4시간) | prd.md·design.md·AGENTS.md → 나를 소개하는 웹사이트 |

각 폴더는 공용 `sessions/_template/`을 복사한 독립 제작 공간이다.

- `N주차_초안.md`: 강의 콘텐츠 입력
- `강의덱.초안/`: 파트별 편집 조각
- `자료/`: 집필노트·캡처·이미지 에셋
- `실습예제/`: 슬라이드용 참고 결과물
- `강의덱.html`: 조립 미리보기
- `강의덱_배포.html`: 최종 단일 HTML

검사 스크립트는 과목이 여럿이라 `CREATE_SLIDES_COURSE=바이브코딩_온라인`으로 과목을 지정해 실행한다.
