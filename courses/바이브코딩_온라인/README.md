# 바이브코딩 온라인 · 원데이

기존 강의안(바이브코딩 1·2주차 · AI 코딩 에이전트 입문 1·2차시)을 **재배치하고 Codex 데스크톱 앱 기준으로 교체**해 만드는 하루 과정이다. 새 내용을 쓰는 과정이 아니다.

## 현재 확정 기준

| 항목 | 기준 |
|---|---|
| 형식 | 온라인 · 같은 날 같은 수강생 · 오전 2시간 + 오후 4시간 |
| 대상 | 코딩 경험 없는 입문자 · 연령대 높은 편 |
| 주 도구 | Codex 데스크톱 앱(Go/Plus 요금제) · 브라우저 · Markdown · HTML·CSS·JavaScript |
| 오전 | 말로 바로 만들고 고치기 — 내 단어로 타자 게임 |
| 오후 | 기준(md)을 먼저 세우고 만들기 — prd.md·design.md·AGENTS.md → 나를 소개하는 웹사이트 |
| 제외 | 배포 · 오프닝 라이브 시연 · Git·GitHub · 서버·DB·로그인 |

계획·원본 대응표·캡처 목록의 정본은 `../../plans/바이브코딩_온라인/PLAN.md`다.

## 폴더 구조

```text
바이브코딩_온라인/
├── README.md
├── profile.md          과목 프로필(운영 파라미터)
├── 커리큘럼_기준안.md    과정 상위 기준
├── 슬라이드지침.md       슬라이드 제작 시 구속력 있는 결론
└── sessions/
    ├── README.md
    ├── _verify/        렌더 증거 namespace(존재 자체가 선언 — 지우지 마라)
    ├── 1주차/          ← 화면·문서에서는 «오전»
    └── 2주차/          ← 화면·문서에서는 «오후»
```

## 원본 보존 규칙

- 원본 과목(`../바이브코딩/`·`../AI_코딩_에이전트_입문_3차시/`)의 파일은 **읽기만** 한다. 문장·캡처를 가져올 때는 이 과목 폴더에 새로 쓴다.
- 화면에 표시하는 회차명은 `1주차`·`2주차`가 아니라 **`오전`·`오후`**다.
