## 4. 표현 취향

| 항목 | 값 |
|---|---|
| 정보량 | **최대로 담는다** — 온라인·강의 중심이라 화면이 설명을 받쳐야 한다. 시간 부족을 이유로 개념을 빼지 않는다(시간 조절은 강사) |
| 실습 화면 | 요청 → 계획 확인 → 권한 승인 → 실행 → 직접 검증. 온라인 따라하기를 위해 **요청 문장을 화면에 그대로 제시**하는 방식을 우선 검토(G1 확인) |
| 화면 조작 안내 | 누를 위치를 번호 배지로 크게 표시한 주석 스크린샷을 우선 |
| 용어 | 전문용어는 한 번 정확히 정의하고, 이후 쉬운 말로 풀어 쓴다(예: 하네스) |
| 레이아웃 동점 시 우선순위 | 차트·과정도·비교도 → 글과 여백 → 카드 |
| 기준 슬라이드 | 첫 완성 덱 검토 후 기록 |
