## 3차시 · 데이터에서 다양한 결과물까지

### 개념

- Coding Agent의 파일 활용 범위
- 확인 → 계획 → 승인 → 실행
- 원본과 파생 결과물의 분리
- 중복 · 결측 · 이상값
- 데이터로 답할 수 있는 질문과 답할 수 없는 질문
- 제작자와 검토자 역할 분리
- 하나의 근거를 여러 결과물에 재사용

### 실습

1. `mock_ecommerce_orders.csv` 구조 확인
2. 2,424행 · 20개 컬럼 · 데이터 유형 확인
3. 중복·결측·이상값 진단
4. 정리·분석 계획 작성과 승인
5. 원본 CSV 보존
6. 매출·상품군·마진·배송·평점 지표 계산
7. 단일 HTML 데이터 대시보드 제작
8. 원본 CSV와 대시보드 숫자 대조
9. 검증된 결과로 분석 Markdown 작성
10. DOCX·PPTX·공유 페이지 확장 시연
11. 정적 HTML 배포 방식 소개

### 필수 대시보드 요소

- 원본 행과 분석 대상 행
- 핵심 주문·매출 지표
- 월별 매출
- 상품군별 매출과 마진
- 배송 기간과 평점
- 데이터 정제 기준
- 확인이 필요한 데이터
- 분석의 한계

### 결과물

- 원본 CSV
- 데이터 품질 진단
- HTML 데이터 대시보드
- 분석 Markdown
