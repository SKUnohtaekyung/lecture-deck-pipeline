# 뉴스 결과 검증 기준

> 2차시 실습 ⑤ — Agent가 생성한 뉴스 결과와 실제 기사 출처를 비교한다.
> 근거: 교육계획서 원문 01 「6. 뉴스 결과 검증하기」 · 「2. AI 사용 시 반드시 알아야 할 주요 개념」의 결과 검증 ·
> 「7. 반복 실행하도록 설정하기」. 원문 02(목록형)와 교차 확인했다.

## 1. 확인 항목 — 뉴스마다 다섯 칸

| # | 확인 항목 | 확인 결과 |
|---:|---|---|
| 1 | 실제 존재하는 뉴스인가 | [ ] |
| 2 | 날짜가 맞는가 | [ ] |
| 3 | 제목이 과장되지 않았는가 | [ ] |
| 4 | 요약 내용이 원문과 일치하는가 | [ ] |
| 5 | 출처가 제대로 기록됐는가 | [ ] |

이를 통해 AI 결과를 직접 검증한다.

## 2. «완료했습니다»와 실제 완료

Agent가 «완료했습니다»라고 말하는 것과 실제 작업 완료는 다를 수 있다. 원문이 직접 확인하라고 한 항목은 다음과 같다.

- 파일이 실제 생성됐는가
- 브라우저에서 실행되는가 (웹 결과물일 때)
- 요구사항이 반영됐는가
- 데이터가 맞는가
- 출처가 실제 존재하는가

## 3. 반복 실행 흐름 (원문 예시)

매일 오전 9시 → 최신 AI 뉴스 탐색 → 뉴스 선정 → 요약 및 검증 → 날짜별 Markdown 저장

반복 실행 설정 방법은 원문에서 «소개»로 다루며, 수업에서는 강사 시연으로 본다(Google Antigravity의 실제 설정 화면 이름은 원문에 없다).
