AI Chat과 Coding Agent 역할표

두 도구는 묻는 질문이 다릅니다. AI Chat에는 "무엇을·왜"를 묻고, Coding Agent에는 "어떻게 저장할지"를 맡깁니다.

AI Chat
기획 · 질문 · 비판 무엇을·왜. 대화하며 아이디어를 정리하고 다듬는 상대입니다.
Coding Agent
(Google Antigravity)
구현 · 저장 어떻게. 정리된 결정을 코드와 문서 파일로 만들어 폴더에 저장합니다.
