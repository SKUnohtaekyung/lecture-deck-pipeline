prd.md는 시작 전과 끝난 뒤, 두 번 읽힙니다

앞 장의 다섯 항목만 빠짐없이 채우면 됩니다. 길이가 아니라 항목이 기준입니다. 프로젝트가 커지면 같은 다섯 항목이어도 길어집니다.

즉 prd.md는 에이전트가 시작하기 전과 끝난 뒤 두 번 참고하는 기준 문서입니다.

각 항목이 왜 AI 결과를 바꾸나

다섯 항목 가운데 하나라도 비워 두면, 그 자리를 AI가 추측으로 메웁니다.

  • 대상결과가 매번 흔들립니다
  • 핵심기능이 제멋대로 늘어납니다
  • 흐름화면 순서가 뒤죽박죽이 됩니다
  • 제외범위가 계속 커집니다
  • 완료끝을 아무도 모릅니다

빈칸은 AI의 추측이 됩니다. 결과가 흔들립니다.

소제목 다섯 개가 곧 다섯 항목입니다

prd.md집중 타이머 앱 · 실제 예시 파일
  1. # 집중 타이머
  2. ## 1. 누구에게 어떤 도움·결과·경험을 제공하는가
  3. 공부·일에 집중하려는 사람이 남은 시간을 보며 집중하고 끝을 알게 돕는다.
  4. ## 2. 핵심 기능 하나
  5. 입력한 분만큼 세어 남은 시간을 분:초로 보여 주고, 0이 되면 종료 안내
  6. ## 3. 대표 사용 흐름
  7. 집중 시간(분) 입력 → 시작 버튼 → 남은 시간 표시 → 0이 되면 종료 안내
  8. ## 4. 이번에 만들 것과 만들지 않을 것
  9. - 만들 것: 분 입력, 시작 버튼, 남은 시간 표시(분:초), 종료 안내 문구
  10. - 만들지 않을 것: 저장, 일시정지·재개, 알림 소리, 여러 타이머, 통계
  11. ## 5. 구현 완료 기준
  12. - 분을 입력하고 시작을 누르면 남은 시간이 1초마다 줄어든다.
  13. - 남은 시간이 0이 되면 카운트다운이 멈추고 종료 안내가 보인다.
  14. - 다른 분으로 다시 시작하면 새 시간으로 다시 센다.

이 제목이 맡는 항목

  1. 대상누구를 어떻게 돕나
  2. 핵심딱 하나의 기능
  3. 흐름화면을 쓰는 순서
  4. 제외이번엔 안 만들 것
  5. 완료끝났다고 볼 기준
