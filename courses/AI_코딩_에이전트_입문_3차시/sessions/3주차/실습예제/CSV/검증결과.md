# CSV 숫자 독립 검산 결과 (T53)

원본 CSV 하나만 읽어 **처음부터 다시 계산한** 값이다. 스크립트는 같은 폴더의 `독립검산.py`(표준 라이브러리만).

> **블라인드 원칙** — 이 검산은 작성자의 `계산.py`·`지표기준값.json`·`분석대상.csv`·`dashboard.html`·`분석결과.md`를 **열지 않고** 수행했다. 입력은 원본 `자료/데이터/mock_ecommerce_orders.csv` 하나뿐이며 읽기 전용으로만 열었다.
>
> **작성자 값과의 대조(일치/불일치 판정)는 오케스트레이터가 수행한다.** 이 문서는 대조 결과가 아니라 **대조에 쓰일 독립 기준값**이다. 검산자는 작성자 값을 모르므로 여기에 「일치」·「불일치」를 적지 않았다 — 이 문서 기준 **판정 0건 · 미판정(대조 대기) 전 지표**다.

## 1. 사용한 열·값

원본 헤더는 20열이다. 검산에 실제로 쓴 열과 그 열의 실제 값:

| 용도 | 열 이름 | 원본에서 확인한 값 |
|---|---|---|
| 주문 식별 | `order_id` | `ORD00001`~ (원본 2,424행 중 고유 2,400) |
| 월 집계 | `order_date` | `YYYY-MM-DD` · 2025-01~2025-12 (형식 이탈 0건) |
| 상태 필터 | `order_status` | `Completed` 2240 · `Cancelled` 112 · `Pending` 72 → **Cancelled·Pending 제외** |
| 상품군 | `category` | Beauty · Electronics · Fashion · Food · Home · Pet (6종) |
| 브랜드 | `brand` | 18종 |
| 수량 | `quantity` | 0(6) · 1 · 2 · 3 · 4 · 99(6) → **0과 99는 입력 오류로 제외** |
| 단가 | `unit_price_krw` | 정상값 + `999999`(4행) → **999999는 입력 오류로 제외** |
| 원가 | `cost_per_unit_krw` | 전 행 채워짐(공백 0) |
| 할인 | `discount_rate` | **비율** 0 / 0.05 / 0.1 / 0.15 / 0.2 / 0.25 → 할인액 = 단가 × 수량 × 비율 |
| 배송비 | `shipping_fee_krw` | 0 / 3000 등 — **매출에서 제외**(별도 합계로만 보고) |
| 배송 기간 | `delivery_days` | 공백(184) · `-1`(4) · 1~9 · `45`(4) → **-1 제외 · 45 보류(매출 포함, 배송 분모 제외)** |
| 평점 | `rating` | 공백(248, 미평가) · 2 · 3 · 4 · 5 |
| 반품 | `returned` | `Yes` 104 · `No` 2320 |
| 반품 사유 | `return_reason` | 반품 행에만 값(5종), 나머지 공백 |

쓰지 않은 열: `customer_id` · `customer_type` · `age_group` · `region` · `product_name` · `payment_method`(요구된 지표에 불필요).

적용 순서: ① 완전중복 제거 → ② 값 충돌 보류 → ③ 취소·대기 제외 → ④ 이상값 제외.

|---|---:|---|
| 원본 행 | **2,424** | 헤더 제외 |

## 6. 모호했던 정의와 병기 값

정의가 두 가지로 읽힐 수 있는 지점은 **둘 다 계산해** 병기한다. 굵은 쪽이 승인된 정의(A안)다.

| # | 모호한 지점 | A안(채택) | 대안 | 대안 값 |
|---|---|---|---|---|
| 1 | 「할인」 열의 성격 — 원본 열은 `discount_rate`(0~0.25 **비율**)이지 금액이 아니다 | **할인액 = 단가 × 수량 × 비율 → 총매출 205,274,700** | D안: 할인 미적용(총액) | 216,058,000 원 |
| 2 | 반품 처리 — 「반품 미차감」이 승인 정의 | **총매출 205,274,700 (반품 포함) · 반품 10,133,400 별도 보고** | B안: 반품 차감 | 매출 195,141,300 · 마진 103,843,300 · 평균 주문금액 88,579.80 |
| 3 | 배송일 45 (보류)의 배송 평균 취급 | **분모에서 제외 → 3.45 일 (분모 2,199)** | C안: 포함 | 3.52 일 (분모 2,203) |
| 4 | 배송비의 매출 포함 여부 — 승인 정의는 제외 | **배송비 제외 → 205,274,700** | E안: 배송비 포함 | 209,858,700 원 |
| 5 | 정제 순서(상태 필터 ↔ 이상값 필터) — 겹치는 행의 **버킷 귀속**이 달라진다 | **상태 → 이상값 순: 취소/대기 182 · 이상값 14** | 이상값 → 상태 순 | 이상값 15 · 취소/대기 181 |
| 6 | 평균 주문금액 표시 | **93,179.62 원**(평균은 소수 둘째) | 금액 규칙(원 단위 정수) 적용 시 | 93,180 원 |

- #5는 **분석 행 2,203과 모든 금액 지표가 순서와 무관하게 동일**하다(재계산으로 확인). 달라지는 것은 제외 사유별 계수뿐이다.
- 「배송일 45 보류」는 조정표의 **제외 항목이 아니다.** 분석 행 안에 남아 매출에 기여하므로, 조정표에 넣으면 2,424 등식이 깨진다. 부분 보류로 §2에 별도 표기했다.
