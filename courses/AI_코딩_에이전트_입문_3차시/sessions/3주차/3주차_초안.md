# 콘텐츠 초안 — AI 코딩 에이전트 입문 · 3차시

> 작성 주체: 스킬(create-slides) · 2026-09-11 사용자 지시 재구성
> 구성 정본: `plans/3차시-결과물중심-재설계/EXECUTION.md` §0·§1(v2) · 판단 기록 `자료/3주차_콘텐츠_집필노트.md` · G1 결정표 `조립_보고.md` · 계보 `제작관리/보존매트릭스_3차시.csv`

- 이 초안은 v1(75장 · 데이터 절차 중심)을 **결과물 중심**으로 다시 짠 것이다. 주인공은 «Coding Agent가 데이터 하나를 HTML 대시보드 · Markdown 근거 문서 · PPTX 발표자료 · DOCX 보고서로 바꾸는 경험»이다.
- `#` 칸은 `구간-슬라이드ID` + 백틱 계보 ID다. 기존 ID(`VC-W3-*` 원본 · `N-*` M6 신규)는 내용이 바뀌어도 유지하고, 이번 신규는 `M7-NN`이다(M-04). 병합한 장은 흡수한 ID를 함께 적는다.
- 아이콘: `💬` 강사 설명 / `👀` 시연·관찰 큐 / `🗣` 요청문. 셋 다 **발표자 노트로만** 간다(학생 덱에 힌트 UI 없음).
- 학생 작업공간은 `바이브코딩/3차시_실습/`이다(U-7). CSV가 이 폴더 안에 있고, 산출 파일(분석대상.csv · dashboard.html · 분석결과.md · 발표자료.pptx · 분석보고서.docx)도 모두 이 폴더 안에 생긴다.
- 숫자는 `실습예제/CSV/지표기준값.json`에서만 인용한다. 매출 라벨은 «총매출(취소·대기 제외, 반품 미차감)»이다.
- Antigravity에서 PPTX·DOCX 파일이 실제로 만들어지는지, 설치 요청의 모양, 걸리는 시간은 미확인이다. 화면에는 «계정·설정에 따라 다를 수 있음»으로만 쓴다.
- 부록 A·B는 THANK YOU 뒤에 붙고 시간표 밖이다(G 메뉴 점프).
