AI 업무 프롬프트 10개

막연한 요청을 바로 쓸 수 있는 결과물로 바꾸는 요청문입니다. 오늘 만든 결과물을 넘어, 내일의 실제 업무에도 같은 방식을 적용해 보세요.

회사 자료는 사내 AI 사용 기준에 맞게 제공하세요. 자동 복사가 되지 않는 환경에서는 프롬프트 본문을 선택한 뒤 Ctrl+C(Windows) 또는 Cmd+C(Mac)로 복사할 수 있습니다.

사용법

대괄호 안의 내용을 채우고, 관련 자료가 있다면 함께 첨부하세요. 파일 제작·검색·자동화는 사용하는 환경에서 지원되는 기능에 따라 달라집니다.

  1. 지금 처리할 업무와 가장 가까운 프롬프트 하나를 고릅니다.
  2. 대괄호 안의 내용을 내 업무에 맞게 채우고 필요한 자료를 붙입니다.
  3. 결과를 확인한 뒤, 빠진 조건이나 원하는 형식을 한 번 더 요청합니다.

각 카드의 프롬프트 복사를 누르면 그 요청문만 복사됩니다.

01

흩어진 회의 메모 → 실행 가능한 회의록

회의 중 적어둔 메모와 관련 자료를 전달할게.

[회의 메모·관련 자료 입력]

전체 내용을 읽고 **확정된 결정, 검토 중인 의견, 해결되지 않은 질문**을 구분해줘. 논의 과정과 최종 결론이 다르면 최종 결론을 중심으로 정리해줘.

후속 업무는 ‘할 일 / 담당자 / 기한 / 먼저 해결할 조건’ 표로 만들어줘. 자료에 없는 담당자나 날짜는 추측하지 말고 ‘확인 필요’로 표시해줘.

마지막에는 참석자에게 공유할 짧은 요약 메시지도 작성해줘. 회의에 참석하지 않은 사람도 무엇이 결정됐고 다음에 무엇을 해야 하는지 이해할 수 있어야 해.
02

막연한 궁금증 → 의사결정에 필요한 조사

내가 알아보고 싶은 주제와 이유는 다음과 같아.

[조사 주제 / 알아보는 이유 / 결정해야 할 일 입력]

바로 검색 결과를 요약하기 전에, 판단에 필요한 핵심 질문부터 나눠줘. 검색 기능을 사용할 수 있다면 공식 자료와 최신 데이터를 우선 확인하고, 주요 주장에 반대되는 근거도 찾아줘.

출처마다 발표 시점과 실제 데이터의 기준 시점을 구분해줘. 경험담은 참고 사례로 다루고, 일반화할 수 있는 근거와 분리해줘.

결과는 **확인된 사실 / 아직 불확실한 부분 / 내 상황에서의 선택지**로 정리해줘. 추천안을 제시할 때는 그 이유와 함께, 어떤 조건이 바뀌면 추천도 달라지는지 알려줘. 검색할 수 없는 환경이라면 확인하지 않은 내용을 최신 정보처럼 쓰지 말아줘.
03

반복 업무 목록 → 자동화 설계안

내가 반복해서 하는 업무를 적어줄게.

[업무 목록 / 빈도 / 소요 시간 / 사용하는 도구 입력]

각 업무를 **자동화하기 쉬운 일, AI가 초안을 만들고 사람이 검토할 일, 사람이 직접 판단해야 할 일**로 나눠줘.

반복 빈도, 예상 절약 시간, 오류가 났을 때의 영향을 기준으로 먼저 개선할 업무 3개를 골라줘. 절약 시간은 계산 근거와 가정을 함께 적어줘.

각 업무에 대해 ‘필요한 입력 → 처리 단계 → 결과물 → 사람의 확인 지점’을 설계하고, 바로 재사용할 수 있는 요청문도 만들어줘.

실제 도구 연결이나 자동 실행이 필요한 부분은 별도로 표시해줘. 우선 한 번 시험할 수 있는 작은 범위의 실행안부터 제안해줘.
04

길고 복잡한 메일 → 답장 초안과 할 일

아래는 업무 메일이나 메신저 대화 내용이야.

[대화 내용 / 상대방과의 관계 / 내가 원하는 대응 방향 입력]

대화를 시간순으로 읽고 상대방의 요청, 내가 답해야 할 질문, 약속된 일정, 아직 합의되지 않은 조건을 정리해줘.

그다음 바로 보낼 수 있는 답장 초안을 작성해줘. 결론을 먼저 말하고 필요한 설명만 덧붙여줘. 정중하되 지나치게 장황하거나 사과가 반복되지 않게 해줘.

내가 제공하지 않은 일정이나 조건을 임의로 약속하지 말고, 확인이 필요한 부분은 따로 알려줘. 답장 작성과 별개로 내가 실제로 처리해야 할 업무도 체크리스트로 정리해줘.
05

떠오르는 아이디어 → 설득력 있는 기획안

현재 생각한 아이디어는 다음과 같아.

[아이디어 / 대상 / 해결하려는 문제 / 예산·기간 등 제약 입력]

아이디어를 바로 멋있게 포장하기보다, 누구의 어떤 문제를 해결하는지부터 점검해줘. 근거가 부족하거나 논리가 뛰는 부분도 찾아줘.

이후 **문제 → 제안 → 기대 효과 → 실행 방법 → 필요한 자원 → 성과 측정 기준** 순서로 기획안을 작성해줘. 확인된 사실과 검증이 필요한 가설은 구분해줘.

의사결정자가 물을 법한 질문 5개와 답변 초안도 준비해줘. 마지막에는 전체 실행 전에 작은 비용으로 효과를 확인할 수 있는 실험을 제안해줘.
06

숫자만 가득한 실적 자료 → 한눈에 읽히는 보고서

분석할 실적 자료와 보고 목적을 전달할게.

[표·파일 / 지표의 의미 / 비교 기간 / 보고 대상 입력]

먼저 누락값, 중복, 단위 차이, 비교 기간 불일치가 있는지 확인해줘. 계산 기준이 불명확한 지표는 분석 전에 따로 표시해줘.

그다음 전체 흐름, 변화가 큰 항목, 목표 대비 차이를 찾아줘. 숫자로 확인되는 현상과 추가 검증이 필요한 원인 가설을 구분해줘.

결과는 **핵심 결론 3개 → 근거 수치 → 주의할 점 → 다음 행동** 순서로 작성해줘. 표나 그래프는 판단에 필요한 것만 선택하고, 증감률 계산 기준도 적어줘. 원본 자료로 주요 수치를 다시 대조한 뒤 마무리해줘.
07

쌓인 할 일 → 현실적인 주간 계획

이번 주 업무와 일정을 알려줄게.

[할 일 / 마감 / 예상 소요 시간 / 고정 일정 / 하루 가용 시간 입력]

마감, 중요도, 다른 사람의 업무에 미치는 영향, 선행 작업을 기준으로 우선순위를 정해줘. 시간이 부족하면 모든 일을 억지로 넣지 말고, 미루거나 범위를 줄일 후보를 알려줘.

집중이 필요한 업무와 짧게 처리할 업무를 구분하고, 예상치 못한 요청에 대응할 여유 시간도 포함해줘.

결과는 요일별 계획으로 정리하고, 각 날짜에 반드시 끝내야 할 핵심 결과물 하나를 지정해줘. 마지막에는 일정이 밀렸을 때 무엇부터 조정해야 할지도 적어줘.
08

여러 업체의 제안서 → 비교표와 선택 기준

같은 목적을 두고 받은 여러 업체의 제안 자료야.

[제안서·견적 / 필수 조건 / 예산 / 우선순위 입력]

먼저 모든 업체를 같은 기준으로 비교할 수 있도록 항목을 통일해줘. 가격뿐 아니라 포함 범위, 추가 비용, 일정, 유지보수, 제외 사항을 함께 비교해줘.

제안서에 없는 내용은 ‘미기재’로 표시하고, 업체별로 추가 확인할 질문을 작성해줘. 서로 다른 범위의 견적을 단순히 금액만으로 비교하지 않도록 해줘.

마지막에는 **비용 우선 / 품질 우선 / 일정 우선** 상황에서 각각 어떤 선택이 유리한지 설명해줘. 최종 추천이 있다면 어떤 조건을 전제로 한 판단인지 분명히 적어줘.
09

정리되지 않은 업무 경험 → 성과평가 초안

평가 기간 동안 내가 했던 업무를 전달할게.

[업무 기록 / 목표 / 결과 / 피드백 / 평가 기준 입력]

업무를 단순 나열하지 말고 **해결한 문제, 내가 맡은 역할, 실행한 행동, 만들어낸 변화**로 정리해줘. 팀 전체 성과와 내 기여를 구분해줘.

수치로 증명할 수 있는 성과는 근거를 붙이고, 수치가 없는 성과는 관찰 가능한 변화로 설명해줘. 제공하지 않은 실적이나 기여도를 만들어내지 말아줘.

그다음 평가 문서에 넣을 수 있는 문장으로 작성해줘. 잘한 점과 개선할 점을 균형 있게 담고, 다음 평가 기간의 목표까지 연결해줘. 추가로 확보하면 좋은 증빙도 알려줘.
10

머릿속에만 있는 업무 방식 → 인수인계 문서

내가 담당하는 업무와 처리 방법을 설명할게.

[업무 설명 / 관련 자료 / 처리 주기 / 자주 생기는 문제 입력]

처음 맡는 사람이 따라 할 수 있도록 **업무 목적 → 시작 조건 → 필요한 자료 → 처리 순서 → 완료 기준**으로 정리해줘.

각 단계에서 무엇을 확인하고 어떤 결과물을 남겨야 하는지 구체적으로 적어줘. 예외 상황과 자주 발생하는 실수는 해당 단계 바로 아래에 넣어줘.

문서만으로 따라 하기 어려운 부분은 추가 질문으로 모아줘. 마지막에는 새 담당자의 첫 실행 체크리스트와, 인수인계가 끝났다고 판단할 수 있는 확인 항목을 작성해줘.
