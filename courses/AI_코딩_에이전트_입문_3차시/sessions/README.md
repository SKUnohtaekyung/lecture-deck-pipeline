# 차시별 작업 공간

저장소 도구와의 호환을 위해 폴더명은 `N주차`를 사용한다. 강의 화면·문서의 회차명은 `N차시`로 표시한다.

| 폴더 | 강의명 | 핵심 실습 |
|---|---|---|
| `1주차/` | 1차시 · AI와 Coding Agent 첫걸음 | Antigravity 설치 · 웹 타자 게임 |
| `2주차/` | 2차시 · Coding Agent를 더 잘 사용하는 방법 | 뉴스 조사 Agent · Markdown · 반복 실행 |
| `3주차/` | 3차시 · 데이터에서 다양한 결과물까지 | CSV · HTML 대시보드 · 분석 문서 |

각 폴더는 공용 `sessions/_template/`을 복사한 독립 제작 공간이다.

- `N주차_초안.md`: 강의 콘텐츠 입력
- `강의덱.초안/`: 파트별 편집 조각
- `자료/`: 해당 차시 근거·이미지·검증 자료
- `실습예제/`: 실행 가능한 실습 프로젝트
- `강의덱.html`: 조립 미리보기
- `강의덱_배포.html`: 최종 단일 HTML
