## 4. effort 지원값과 지정 방법

- **지원값(순서 있음, 5개)**: `low` < `medium` < `high` < `xhigh` < `max` — Fable 5.1/5 · Opus 5 · Sonnet 5 · Opus 4.8/4.7 공통. 기본값 `high`(Opus 4.7만 xhigh). 근거: 공식 model-config 표 + 2.1.260 `--help` «--effort <level> (low, medium, high, xhigh, max)».
- **메인 세션 지정**: `--effort`, `/effort`, `CLAUDE_CODE_EFFORT_LEVEL`, 설정 `effortLevel`·`modelSettings`.
- **서브에이전트 지정**: 서브에이전트 정의 frontmatter의 `effort:` 필드만이 공식 경로(«set `effort` in a … subagent markdown file to override the effort level when that skill or subagent runs»). 정의 위치 우선순위: managed > `--agents` JSON(실행 시) > 프로젝트 `.claude/agents/`(재귀 스캔) > 사용자 `~/.claude/agents/`(현재 존재하지 않음) > 플러그인.
- **이 세션의 Agent 도구 스키마에는 effort 인자가 없다**(인자: description·isolation·model·prompt·run_in_background·subagent_type). `model` 인자는 **별칭 enum(sonnet/opus/haiku/fable)만** 받는다 — 풀 ID 불가.
- **frontmatter에 effort가 없으면 서브에이전트는 메인 세션 effort를 상속**한다 — 스모크 실측 `xhigh`(§5). 문서: «As of v2.1.198, subagents also inherit the main conversation's extended thinking configuration».
- 서브에이전트 모델 우선순위(공식): ① Agent 호출의 `model` 인자 → ② 정의 frontmatter `model`(inherit 포함) → ③ `CLAUDE_CODE_SUBAGENT_MODEL` → ④ 메인 모델.
- 중첩: «By default, a subagent can spawn subagents of its own, up to three layers below the main conversation.» (실측 미실시 — T04/G01)

## 6. Astra 배정 정책(E0~E4) → 지원값 대입 (G00 확정 대상)

지원 집합이 5개(순서 있음)이므로 §5.1 규칙을 적용할 수 있다. 두 칸은 규칙 문구가 두 가지로 읽혀 **사용자/Astra 확정**이 필요하다.

| 변수 | 규칙 원문 | 대입값(제안) | 판정 |
|---|---|---|---|
| E0 | 가장 낮은 추론 수준 | **`low`** | 확정 가능 |
| E1 | «지원값의 중앙 수준» | **`high`**(5값의 중앙 = 3번째) · 대안 `medium`(이름이 «중간») | ⚠️ 이중 해석 — 권고 `high`(계보 대조 오류가 하류로 전파되므로 기본값 이하로 내리지 않음) |

| E3 | «충분한 최상위 수준» | **`xhigh`** · 대안 `max` | ⚠️ 이중 해석 — 권고 `xhigh`(E4와 구분 유지; 문서가 `max`를 «diminishing returns·prone to overthinking»으로 경고) |

## 7. 확인하지 못한 것

- `--agents` JSON이 `effort` 필드를 받는지: 문서는 «CLI-defined subagents가 받는 필드 목록» 링크만 있고 인용 본문에 effort가 명시되지 않음 → 미확인(프로젝트 `.claude/agents/*.md` frontmatter `effort`는 공식 표에 명시됨).
- 중첩 서브에이전트(Opus 리드 → 워커) 실측과 그 로그 위치(`analyze_agent_usage.discover_worker_logs`는 `<세션>/subagents/agent-*.jsonl`과 `workflows/*/agent-*.jsonl`만 본다) → T02 분석·T04 실측.
- `analyze_agent_usage.py --tool-audit`가 세션 안의 **모든** `agent-*.jsonl`을 워커로 계수하는지(스모크 로그도 이미 이 세션 폴더에 있다) → T02.
- `claude-fable-5`(5.1 아님)를 풀 ID로 지정했을 때 실제 서비스되는지 → 미실측(정책이 5.1을 인정하면 불필요).
