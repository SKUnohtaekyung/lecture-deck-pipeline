# 검증명령 — AI 코딩 에이전트 입문 · 3차시 (T04-B 산출)

> 이 과정에서 **실제로 칠 명령**과 그 증거 경로를 한 곳에 모은다. 공통 명령의 정본은
> `references/검증-명령-지도.md`이고, 여기 있는 것은 **이 과정의 과목명·증거 namespace를
> 넣어 실행 가능한 형태로 고정한 것**이다. 값이 어긋나면 정본을 따른다.
>
> 근거·설계 정본: `경로스키마호환성.md` v3(§2 ⓐ · §6.1 A1~A10 · §6.2 해제 증거 5조건).
> 승인: G00 2026-09-09 「D1~D12 권고대로」(D8 = A1~A7·A9·A10 승인 · **A8 보류** · D10 = A9 worktree 보강).

## 0. 모든 명령의 전제 — 과목을 밝힌다

```powershell
$env:CREATE_SLIDES_COURSE = 'AI_코딩_에이전트_입문_3차시'
```

- 밝히지 않으면 러너·정적 게이트는 `AmbiguousCourseError`로 **시끄럽게 죽는다**(의도 · `MEMORY.md:320`).
- 수신기·비교도구만은 죽지 않고 **경고 1줄과 함께 구경로로 폴백**한다 — 그 경고가 보이면
  거기서 멈추고 환경변수를 지정하라. 구경로에는 바이브코딩의 **동결 증거**가 있다.
- bash에서는 `export CREATE_SLIDES_COURSE=AI_코딩_에이전트_입문_3차시`.

## 1. 증거 경로 (B03 격리 결과)

| 무엇 | 경로 |
|---|---|
| 렌더 증거 | `courses/AI_코딩_에이전트_입문_3차시/sessions/_verify/N주차/deck-audit.json` |
| 발표본 사이드카 | `courses/AI_코딩_에이전트_입문_3차시/sessions/_verify/N주차/강의덱_발표.meta.json` |
| namespace 선언(마커) | `courses/AI_코딩_에이전트_입문_3차시/sessions/_verify/README.md` |

라우팅 규칙: **그 과목이 `courses/<과목>/sessions/_verify/`를 만들어 두었으면 그것, 아니면
구경로 `sessions/_verify/`.** 마커를 지우면 이 과정의 증거가 조용히 구경로로 되돌아간다.

러너는 매 실행 `=== 렌더 증거 경로 ===` 줄로 실제 사용한 namespace를 찍는다. 그 줄이
`(과목 전용 namespace)`가 아니면 **거기서 멈춰라**.

## 2. 조립 → 정적 → 렌더 → 배포 (실행 순서 그대로)

```powershell
$env:CREATE_SLIDES_COURSE = 'AI_코딩_에이전트_입문_3차시'
$S = 'courses/AI_코딩_에이전트_입문_3차시/sessions/1주차'      # 주차만 바꿔 재사용

# ① 조립 — 정본은 shard(강의덱.초안/)다. 생성물 강의덱.html을 직접 고치지 마라.
python scripts/assemble_deck.py "$S/강의덱.초안"

# ② 정적 게이트 (N = 그 덱의 part-divider 수. 슬라이드 총수가 아니다)
python scripts/verify_deck.py "$S/강의덱.html" --parts N
python scripts/verify_deck_quality.py "$S/강의덱.html"
python scripts/verify_notes.py "$S/강의덱.html" "$S/강의덱_발표자노트.html"

# ③ 렌더 증거 — 브라우저에서 «만든다». 헤드리스는 도입돼 있지 않다(DEC-03).
python -m http.server 8799
python scripts/receive_audit.py 1주차            # 별도 콘솔. 요청 1건 받고 종료
#   브라우저(창 1280x720 이상)에서 덱을 열고 콘솔:
#     window.__audit = await (await fetch('/scripts/audit_all.js')).text().then(eval)
#     await fetch('http://localhost:8798/', {method:'POST', body: window.__audit})
#   수신기가 찍는 [저장] 경로가 위 §1의 경로인지 눈으로 확인한다.

# ④ 러너 — 정적 + 노트 + 렌더 증거 판정을 한 번에
python scripts/run_deck_checks.py 1주차
python scripts/compare_baseline_panel.py 1       # 참고값(FAIL 없음 · 언제나 exit 0)

# ⑤ 배포본
python scripts/build_release.py "$S/강의덱.초안"
python scripts/verify_distributable.py "$S/강의덱_배포.html"

# ⑥ 발표본(명시 요청 전용) — --meta 를 반드시 이 과정 namespace로
python scripts/inject_presenter.py "$S/강의덱_배포.html" `
  --notes "$S/강의덱_발표자노트.html" `
  --deck-id ai-agent-week-1 `
  --output "$S/강의덱_발표.html" `
  --meta "courses/AI_코딩_에이전트_입문_3차시/sessions/_verify/1주차/강의덱_발표.meta.json"
python scripts/verify_presenter_deck.py --source "$S/강의덱_배포.html" `
  --presenter "$S/강의덱_발표.html" `
  --meta "courses/AI_코딩_에이전트_입문_3차시/sessions/_verify/1주차/강의덱_발표.meta.json"
```

⚠️ **⑥의 `--meta`를 절차 문서에서 복사할 때 주차·과목을 함께 바꿔라.** 남의 사이드카를
가리키면 주입기가 `deckId` 불일치를 보고 **exit 1**로 거부한다(`--force`로도 열리지 않고,
발표본 HTML도 쓰이지 않는다). `deckId`는 **영구 식별자**이므로 `ai-agent-week-<N>`처럼
과목이 드러나는 값을 쓴다 — 두 과목이 같은 `deckId`를 쓰면 이 가드가 발화하지 않는다(§2.4-5).

⚠️ `verify_session_docs.py`는 **주차 인자 `1주차` 정규화 버그**(§4.2)가 남아 있다 —
A8이 **보류**됐으므로 이 과정에서는 **숫자만 넘긴다**(`python scripts/verify_session_docs.py 1 --target 자료`).

## 6. 되돌리는 법

```powershell
git checkout -- scripts/_course_paths.py scripts/run_deck_checks.py scripts/receive_audit.py `
  scripts/compare_baseline_panel.py scripts/inject_presenter.py `
  tests/test_course_paths.py tests/test_deck_pipeline.py .githooks/_gate.py
Remove-Item -Recurse -Force courses/AI_코딩_에이전트_입문_3차시/sessions/_verify
```
