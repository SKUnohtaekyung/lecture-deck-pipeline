# 슬라이드 지침 — AI 코딩 에이전트 입문

## 대상

- 코딩 경험이 없거나 적은 일반 참가자
- AI Chat 사용 경험은 있으나 Coding Agent는 처음인 참가자
- 온라인 환경 · 다양한 화면 크기

## 화면 원칙

- 한 장에 한 결론
- 긴 줄글 금지
- 목록 · 비교 · 단계 · 과정도 중심
- 정식 용어 + 쉬운 한 줄 풀이
- 차트·다이어그램·UI 흐름을 설명의 중심으로 사용
- 장식용 그래픽보다 기능을 설명하는 SVG·도식 우선
- 모바일에서도 읽히는 글자·표·여백
- 출처 표시는 화면이 아니라 강사 자료에서 관리

## 학습 리듬

- 개념
- 강사 시연
- 함께 따라 하기
- 참가자 수정
- 직접 확인
- 한 줄 정리

## 강제 메시지

- AI가 자신 있게 말해도 사실일 수는 없다.
- AI의 “완료”는 완료 증거가 아니다.
- 중요한 기준은 대화가 아니라 파일에 남긴다.
- 원본 데이터는 수정하지 않는다.
- 실행 전 계획과 권한을 확인한다.
- 결과물의 숫자는 원본에서 나온 근거 파일과 같아야 한다.

## 디자인

- 테마: `default`
- 브랜드: `VIBECODING`
- 구조 강조: 블루
- 행동·안전 강조: 민트
- 위험·주의 강조: 코랄
- 그라데이션 금지
- 차트에는 축·단위·범례·데이터 조건 표시

## 실습 자료 표기

- 파일명은 화면에 그대로 표시
- 복사할 프롬프트는 목적·입력·출력·검증 기준으로 분해
- Antigravity 화면은 실습에 필요한 최소 영역만 설명
- 계정·연동·권한에 따라 달라지는 기능은 선택 시연으로 표시
