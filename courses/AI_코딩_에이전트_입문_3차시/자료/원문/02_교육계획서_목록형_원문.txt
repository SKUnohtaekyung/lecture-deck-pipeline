-  이상값 
-  분석에 활용할 수 있는 항목 
예를 들어 이커머스 주문 데이터라면:
-  날짜 
-  상품 
-  판매 금액 
-  수량 
-  상품군 
-  마진 
-  배송 기간 
-  고객 평점 
등의 데이터를 확인할 수 있습니다.
Agent에게 바로 데이터를 수정하게 하지 않고,
이 데이터를 정리하고 대시보드로 만들기 위한 작업 계획을 먼저 작성해줘.
라고 요청합니다.
참가자는 Agent가 제시한 계획을 확인한 뒤 실행 여부를 판단합니다.
이를 통해
Agent가 계획을 세운다고 해서 무조건 실행시키는 것이 아니라 사용자가 중간에 검토하는 과정
을 경험합니다.
데이터 작업에서는 원본 파일을 직접 수정하지 않는 기본 원칙을 소개합니다.
예:
original.csv
원본 유지
↓
cleaned.csv
정리된 데이터 별도 생성
이를 통해 Agent를 사용할 때도 중요한 파일을 보존하는 습관을 익힙니다.
필요한 경우 Agent에게 다음 작업을 요청합니다.
-  중복 제거 
-  결측값 확인 
-  이상값 확인 
-  날짜 형식 통일 
-  숫자 데이터 정리 
-  필요 없는 컬럼 제외 
-  분석용 데이터 생성 
중요한 점은 Agent가 임의로 데이터를 삭제하지 않도록 어떤 변경을 했는지 확인하는 것입니다.
정리된 데이터를 바탕으로 Agent에게 주요 지표를 계산하도록 합니다.
예:
-  전체 매출 
-  월별 매출 
-  상품군별 매출 
-  상품군별 마진 
-  평균 배송 기간 
-  평균 평점 
전문적인 통계 교육보다 “어떤 질문을 Agent에게 할 수 있는가”를 중심으로 실습합니다.
계산한 데이터를 기반으로 HTML 대시보드를 제작합니다.
대시보드에는 예를 들어 다음 요소를 포함합니다.
-  주요 KPI 
-  월별 매출 
-  상품군별 매출 
-  상품군별 마진 
-  배송 기간 
-  고객 평점 
-  주요 차트 
-  핵심 요약 
참가자는 자연어로 디자인과 구성을 수정합니다.
예:
월별 매출을 막대그래프로 바꿔줘.
가장 중요한 KPI를 상단에 크게 보여줘.
상품군별 매출과 마진을 한눈에 비교할 수 있게 만들어줘.
대시보드가 보기 좋게 만들어졌다고 해서 바로 완료하지 않습니다.
Agent에게 다음과 같이 요청합니다.
원본 CSV와 대시보드에 표시된 숫자를 다시 비교해줘.
 잘못 계산된 값이 있는지 확인해줘.
필요한 경우 별도의 검토 역할을 지정합니다.
예:
지금부터는 기존 결과를 만든 Agent가 아니라 검토자의 관점에서 확인해줘.
이를 통해 생성 역할과 검증 역할을 분리하는 기본 개념도 함께 경험합니다.
검증된 데이터와 차트를 다시 활용합니다.
CSV 하나에서 다음과 같은 결과물을 만들 수 있다는 점을 보여줍니다.
데이터 대시보드
분석 보고서
발표 자료
핵심 요약
즉:
CSV
↓
데이터 정리
↓
분석
↓
검증
↓
HTML / DOCX / PPTX / Markdown
이라는 Agent 기반 업무 흐름을 경험합니다.
검증된 결과만 사용하여 다음 내용을 정리합니다.
-  핵심 요약 
-  주요 지표 
-  발견한 특징 
-  개선이 필요한 부분 
-  데이터의 한계 
AI가 근거 없이 의미를 부여하지 않도록 원본 데이터에서 확인 가능한 내용만 작성하게 합니다.
마지막에는 결과물을 다른 사람과 공유할 수 있는 기본적인 방법을 소개합니다.
-  HTML 파일 공유 
-  웹으로 공개 
-  DOCX 보고서 공유 
-  PPTX 발표자료 활용 
배포 자체를 깊게 다루지는 않고, 참가자가
“내가 만든 결과물을 실제로 다른 사람에게 보여줄 수 있다.”
는 수준까지 경험하도록 합니다.
CSV
↓
데이터 구조 확인
↓
작업 계획 작성
↓
원본 보존
↓
데이터 정리
↓
분석
↓
HTML 대시보드
↓
원본 데이터와 교차 검증
↓
분석 보고서
↓
DOCX / PPTX 등 결과물 확장
↓
공유 및 배포
교육 종료 후 참가자는 다음을 직접 수행하거나 이해할 수 있습니다.
-  LLM과 AI Agent의 차이를 설명할 수 있다. 
-  일반 AI Chat과 Coding Agent의 차이를 이해한다. 
-  다양한 AI Agent 중 Coding Agent의 역할을 이해한다. 
-  대표적인 AI 서비스의 기본적인 특징을 구분할 수 있다. 
-  Google Antigravity를 설치하고 기본 환경을 구성할 수 있다. 
-  자연어로 Coding Agent에게 작업을 요청할 수 있다. 
-  Agent가 생성한 파일을 직접 확인할 수 있다. 
-  결과를 보고 추가 수정 요청을 할 수 있다. 
-  Prompt와 Context의 차이를 이해한다. 
-  AI가 참고할 정보를 Markdown으로 관리할 수 있다. 
-  Agent에게 역할, 조건, 완료 기준을 전달할 수 있다. 
-  Agent가 반복적으로 수행할 업무를 구성할 수 있다. 
-  Hallucination과 Sycophancy를 이해한다. 
-  Context 유실 가능성을 이해한다. 
-  개인정보와 실행 권한의 중요성을 이해한다. 
-  AI가 완료했다고 말한 결과를 직접 검증해야 한다는 점을 이해한다. 
-  원본 자료와 AI 결과를 비교할 수 있다. 
-  Coding Agent에게 웹 검색과 정보 정리를 요청할 수 있다. 
-  반복적으로 정보를 조사하는 Agent를 구성할 수 있다. 
-  CSV 파일을 Agent에게 전달하고 데이터를 파악할 수 있다. 
-  데이터를 정리하고 분석 결과를 만들 수 있다. 
-  데이터 기반 HTML 대시보드를 만들 수 있다. 
-  하나의 데이터를 DOCX, PPTX, Markdown 등 다양한 결과물로 확장할 수 있다.
