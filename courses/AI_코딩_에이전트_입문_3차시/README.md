# AI 코딩 에이전트 입문 · 3차시

두 개의 붙여넣기 원문과 이커머스 주문 CSV를 바탕으로 새 교육 자료를 제작하는 독립 작업 공간이다.

## 현재 확정 기준

| 항목 | 기준 |
|---|---|
| 전체 구성 | 3차시 · 차시별 2시간 · 총 6시간 |
| 차시 운영 | 50분 수업·실습 → 10분 휴식 → 50분 실습 → 10분 정리·질의 |
| 대상 | 코딩 경험이 없거나 AI Coding Agent를 처음 접하는 일반 참가자 |
| 주 도구 | Google Antigravity · 브라우저 · Markdown · HTML · CSV |
| 1차시 | AI·LLM·Agent 이해 → Antigravity 설치 → 웹 타자 게임 |
| 2차시 | Prompt·Context·Harness → AI 뉴스 조사 Agent → 반복 실행 |
| 3차시 | CSV 확인·정리·검증 → HTML 대시보드 → 분석 문서·공유 |
| 제외 | Git·GitHub · 복잡한 백엔드 · 데이터베이스 구축 · API 직접 연동 |
| 배포 | 3차시 마지막에 개념과 간단한 시연만 진행 |

## 폴더 구조

```text
AI_코딩_에이전트_입문_3차시/
├── README.md
├── profile.md
├── 커리큘럼_기준안.md
├── 슬라이드지침.md
├── 자료/
│   ├── 자료목록.md
│   ├── 원문/
│   │   ├── 01_교육계획서_구조형_원문.txt
│   │   └── 02_교육계획서_목록형_원문.txt
│   └── 데이터/
│       └── mock_ecommerce_orders.csv
└── sessions/
    ├── README.md
    ├── 1주차/  ← 화면·문서에서는 1차시
    ├── 2주차/  ← 화면·문서에서는 2차시
    └── 3주차/  ← 화면·문서에서는 3차시
```

## 원본 보존 규칙

- `자료/원문/`의 두 파일은 수정하지 않는다.
- `자료/데이터/mock_ecommerce_orders.csv`는 수정하지 않는다.
- 정리본·정제본·대시보드는 해당 차시의 `자료/` 또는 `실습예제/`에 새 파일로 만든다.
- 강의덱 제작 시 `N주차_초안.md`를 먼저 채우고 `강의덱.초안/` 조각을 수정한다.
- 화면에 표시하는 명칭은 `1주차`가 아니라 `1차시`로 통일한다.

## 자료 우선순위

1. `커리큘럼_기준안.md`
2. `자료/원문/01_교육계획서_구조형_원문.txt`
3. `자료/원문/02_교육계획서_목록형_원문.txt`
4. `자료/데이터/mock_ecommerce_orders.csv`

두 원문이 충돌하면 구조와 맥락이 보존된 1번 원문을 우선하고, 확정 기준과 충돌하면 `커리큘럼_기준안.md`를 따른다.
