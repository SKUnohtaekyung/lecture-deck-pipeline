# Codex 어댑터

1. 이 파일을 기준으로 `../../../skills/리서치/SKILL.md`를 열고 처음부터 끝까지 완전히 읽는다.
2. 저장소 루트 `skills/리서치/SKILL.md`를 이 Skill의 공통 정본으로 적용한다.
3. 정본 본문에 나온 모든 상대경로는 이 어댑터 폴더가 아니라 정본이 있는 저장소 루트를 기준으로 해석한다.
4. 이후 조사·검증·산출·자기검증 흐름은 정본의 §0 하드 게이트와 8단계 워크플로를 그대로 따른다. 이 어댑터는 게이트 조건이나 워크플로 단계를 추가·변경하지 않는다.
5. `../../../skills/리서치/SKILL.md`를 읽을 수 없으면 대체 규칙을 추측하지 말고 공통 정본을 찾을 수 없다고 보고한다.
