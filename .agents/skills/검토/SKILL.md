# Codex 어댑터

1. 이 파일을 기준으로 `../../../skills/검토/SKILL.md`를 열고 처음부터 끝까지 완전히 읽는다.
2. 그 정본을 이 Skill의 공통 정본으로 적용한다.
3. 정본 본문에 나온 모든 상대경로는 이 어댑터 폴더가 아니라 정본이 있는 저장소 루트를 기준으로 해석한다.
4. 이후 인자 해석·인벤토리·7단계 검토·보고서 산출 흐름은 정본의 지시를 그대로 따른다. 이 어댑터는 검토 규칙이나 §0 불변 규칙을 추가·변경하지 않는다.
5. `../../../skills/검토/SKILL.md`를 읽을 수 없으면 대체 규칙을 추측하지 말고 공통 정본을 찾을 수 없다고 보고한다.
