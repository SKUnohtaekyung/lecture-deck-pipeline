# Codex 어댑터

1. 이 파일을 기준으로 `../../../SKILL.md`를 열고 처음부터 끝까지 완전히 읽는다.
2. 루트 `SKILL.md`를 이 Skill의 공통 정본으로 적용한다.
3. 루트 `SKILL.md` 본문에 나온 모든 상대경로는 이 어댑터 폴더가 아니라 루트 `SKILL.md`가 있는 저장소 루트를 기준으로 해석한다.
4. 이후 제작·참조·스크립트 실행·검증 흐름은 루트 `SKILL.md`의 지시를 그대로 따른다.
5. 루트가 `IMAGE_MODE=generate_now`로 확정한 경우에만 `$imagegen`을 호출하며, 에셋별 생성·투명화·QA와 모델 전환 승인 규칙은 루트 정본을 그대로 따른다.
