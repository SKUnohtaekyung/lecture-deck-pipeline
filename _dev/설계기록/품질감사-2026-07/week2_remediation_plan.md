## A. 108장 전수 트리아지

### A.0 분류 기준 요약

- `유지` — 이대로 충분. 구조 슬라이드(표지·간지·로드맵·마무리)와 실습 지시 슬라이드는 밀도 기준 적용 제외(과업 C 참조). `유지(의도적 미니멀)`은 C2-8·C5-2처럼 개념KB의 PPT 소재를 이미 정확히 실현한 슬라이드 — 글자수만으로 오판하면 안 되는 케이스.
- `보강` — 화면에 설명/예시/비교/비유/주의점/시각구조/결론 중 빠진 요소를 추가. 출처는 초안 강사멘트 열 또는 개념KB 청크.
- `병합` — 인접 슬라이드나 부록 슬라이드와 합쳐 한 장으로.
- `본류복귀` — 부록(FLEX/REC)에 있지만 본류로 와야 하는 슬라이드. 대상 학기시(교시) 내 위치 지정.
- `시각화` — 개념KB가 `PPT 소재:`로 지정한 시각 구조가 전혀 실현되지 않음.
- `자료없음` — 근거 자료 없음(전수 조사 결과 0건 — 아래 참조).

> **수정 사유**: 최초안은 FLEX 9건까지 "본류복귀(신규 독립 슬라이드)"로 분류해 본류가 75→91장(+21%)까지 불었다. 코디네이터 검증대로 `2주차_최종수정계획.md:16`의 CORE≈73은 정상 예산이고 `:120`은 1·2·4·6교시(CORE13)를 "45분 상한 근처"로 이미 경고하며 완화 밸브로 **인접 개념 병합**을 명시(예시로 1-2+1-3·4-1+4-2를 직접 거명)한다. 이를 적용해 **FLEX 26건은 전부 신규 슬라이드를 만들지 않고 기존 CORE 슬라이드에 병합하거나 부록에 남긴다.** 신규로 본류에 추가되는 것은 **RECOVERY 6건뿐**이며, RECOVERY는 최종계획 §10 자체가 "사용 조건: 해당 오류 실제 발생 시"로 규정해 45분 선형 예산에 포함되지 않는 항목이다(과업 F.4에서 시간 영향 0에 가까움을 논증).

전체 부록 33장 처리 결과: **본류복귀 6(RECOVERY만) · 병합 18(부록→본류 슬라이드 흡수 17 + 중복삭제 1) · 부록 유지(심화) 9**.

산술:
```
현재 전체 108 = 본류 75(구조17+콘텐츠58) + 부록 33(FLEX 26 + REC 7)

부록 33의 행선지:
  본류복귀(RECOVERY 6건 — 신규 슬라이드지만 시간예산 무관, 과업F.4)   6장
  병합(FLEX 17건 — 기존 CORE 슬라이드에 흡수, 신규 슬라이드 없음)     17장
  중복 삭제(A5F5, C2-8/C2-9와 완전 중복)                              1장
  부록 유지(FLEX 8건 + REC 1건(A5R4 예비) = R-ANNEX-01 "심화"만 잔류)  9장

  6 + 17 + 1 + 9 = 33 ✓

결과 본류 = 75 + 6(RECOVERY 복귀) = 81   ← `:16`의 승인범위 "~80±6"(74~86) 안, 73(CORE 단독)보다 살짝 위
결과 부록 = 33 - 6(복귀) - 17(병합소멸) - 1(삭제) = 9
결과 전체 = 81 + 9 = 90
```

`deck.contract.json`의 `decks.강의덱.slides`를 **108 → 90**으로 갱신해야 한다(과업 F 참조). ~~100~~(최초안 수치, 폐기).

R-ANNEX-01 검증: 부록 유지 9장은 모두 아래 중 하나에 해당한다 — ① 채택 미정 사항(Skill/AGENTS 심화 실습, D6·D7 결정 대기) ② KB상 P2 인접 개념(브라우저저장) ③ 저자가 스스로 "예비 카드"로 표시한 것(A5R4) ④ 순수 예고성(6-F1·6-F2). 개념적으로 필수인 P0/P1 청크(`대화vs문서`·`문서우선변경`·`PlanFirst`·역할분담)는 부록에 방치하지 않되, **신규 슬라이드가 아니라 병합**으로 해소한다(A.2 우선순위 표의 "3교시 4개념" 항목은 본류복귀에서 병합으로 재분류됨 — 특히 PlanFirst는 3교시가 아니라 그 개념이 실제로 쓰이는 5교시 C5-1에 병합해 "참조는 있는데 정의가 없는" 결함을 예산 증가 없이 해소한다).

### F.4 RECOVERY 카드 결정 + 1주차 선례
