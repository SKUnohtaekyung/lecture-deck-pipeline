## §A. 의존성 위반 (실행 순서 vs 실제 필요 순서)
기존 확인 사례: **C5-1 PlanFirst** — 정의는 선택 슬라이드 3-F4에만 있는데 CORE 5-1이 "계획을 다시 확인"이라며 미정의 개념을 재참조.

신규 발견:
1. **3교시 실습⑥(세 파일+첫 작동)이 분리파일·상대경로·브라우저직접실행·기술제한 4개를 전제로 하는데, 이 넷은 전부 5교시(5-2~5-5)에서야 정의된다.** 3교시 학생은 "왜 세 파일인지, 왜 `./`인지, 왜 더블클릭이 되는지" 모른 채 파일을 만든다. `week2_module_plan.md`의 모듈3은 분리파일만 앞으로 옮겼을 뿐 나머지 셋은 여전히 모듈5 — 부분 수정에 그침.
2. **마지막작동상태보호(5-9)가 실습⑩·⑪ 뒤에 온다** — "수정 전 백업"을 이미 수정한 뒤 배운다. `week2_module_plan.md` 모듈5가 이를 실제로 교정했으므로 그 교정을 정본으로 채택할 것.
3. **1-3(페르소나 vs 사용자가설 비교)이 사용자가설의 독립 정의보다 먼저 온다** — 아는 개념과 아직 정의 안 된 개념을 비교시킨다. depth_map은 "정의 슬라이드 부재"만 지적했고 순서 문제는 미포착.
4. **AGENTS.md 워크드 예시(`개념KB:805`, "React·서버 금지, index.html 루트에")가 기술제한·분리파일 지식을 전제**하는데 AGENTS.md는 3교시, 근거 개념은 5교시.
5. 완료기준(2-10)은 2교시에 옳게 선행 배치 — 위반 아님, 대조군.

## §C. 세 안 (교육철학이 다르며 모듈 순서가 시각적으로 다르다)

**깊이우선안** — 모듈이 빌드 순서가 아니라 **개념 클러스터** 순서: M1 사용자가설만, M2 MVP만, M3 문서화, M4 화면, M5 구현, M6 점검. 각 모듈이 그 개념을 처음부터 끝까지 다루고 실습은 클러스터 끝에 1회. CORE 6~7개로 축소(사용자가설·MVP·대표사용흐름·prd·분리파일·대표시나리오점검), 나머지 EXPOSE. 실습 12→7회. **"할 말이 떨어짐" 해결법**: 개념당 3.9분→8~10분. **위험**: 실습예제 5종·이탈재현 5종이 검증한 12단계 실습체인의 절반을 버림.

**균형안** — 현행 빌드 순서(주제→MVP→문서→화면→구현→점검) 유지하되 **§A 위반을 전부 모듈 내부 재배치로 수정**: 분리파일·상대경로를 3교시로 승격, PlanFirst를 CORE로 승격해 3교시 배치, 마지막작동상태보호를 실습⑩ 앞으로. CORE 12개·실습 12개 유지. **해결법**: 시연 20분 + 개념 설명에 오해·비교 내장. 사용자가 겪은 시간 부족에 가장 직접 대응.

**범위우선안** — 앞에 **개념지도 선행 슬라이드**(60개념을 한 번에 노출, "오늘 다룰 것 vs 이름만 아는 것")를 두고, 각 모듈은 CORE 적용 후 EXPOSE 카드를 뒤에 몰아 배치. CORE 12는 균형안과 동일하되 EXPOSE 18을 "이런 것도 있다" 카드 세트로 명시 노출, EXTENSION은 모듈 끝 별도 블록 고정. 혼합군 대응에 유리. **위험**: 초반 인지부하.

**강함 판정: 균형안** — 실제 교실 경험에 가장 직접 대응하고, 이미 검증된 12단계 실습체인을 보존하면서 §A 위반만 고친다.

## §F. 사용자 프레이밍에 대한 이견
1. **"107장 보존 의무 없음"이 매크로 순서까지 흔들 필요는 없다.** §A 위반은 전부 모듈 **내부** 미세 순서이지 모듈 간 대주제 순서가 아니다. 대주제 순서는 실습체인의 산출물 의존성과 정확히 일치한다(prd 없이 파일 못 만들고, MVP 없이 흐름 못 그림).
2. **PM 레퍼런스(개념당 7~25분)를 산술 목표로 옮기면 실습이 사라진다.** PM_1~4는 각 국면이 독립 세션 하나를 쓴다(PM_2 43장 중 31장이 WHY+WHO). 2주차는 270분 안에 기획+실제 작동 결과물까지 끝내야 한다. 12개 CORE에 PM 수준을 곱하면 84~300분이 되어 실습 시간이 전부 사라진다. 정답은 PM 분량 복제가 아니라 원형별 6단계를 채우는 것.
3. **AGENTS.md를 CORE로 유지하며 분할까지 투자한 기존 작업은 사용자 자신의 D7 결정과 어긋난다.**
