파트별 초안 5종
골라서 시스템을 확정하세요

확정된 브랜드 3색(블루·민트·코랄) 위에, 색 교체가 연쇄로 부르는 결정들을 파트별 5개 안으로 시각화했습니다. 각 파트에서 하나씩 고르면 맨 아래에 조합이 요약됩니다. ui-ux-pro-max 데이터로 근거를 붙였고, 파일·토큰은 확정 전까지 수정하지 않습니다.

구조 · MAIN#1D4ED8
행동 · SUB#14B8A6
주의 · ACCENT#F97360
A 의미 색 매핑 B 깊이·보조색 C 소프트 틴트 D 데이터 시각화 E 형태(라운드·섀도우) F 표지·클로징 G 타이포·코드폰트
PART A · 최우선

의미 색 매핑 — "색은 문법"의 뼈대

민트(행동)·코랄(주의)이 들어오면서 성공·경고·오류 슬롯을 다시 배정해야 합니다. 동시에 코드에 흩어진 따뜻한 색(#F84818 오렌지·#F97316 focus-tag)이 새 코랄 #F97360과 겹치는 문제를 정리합니다.

ui-ux-pro-max: 개발도구 관례 = 초록 #22C55E(성공/실행)·레드 #EF4444(오류) · "색만으로 의미 전달 금지 → 아이콘·텍스트 병기"
PART B

깊이·보조 색 — #1D4ED8족으로 재파생

기존 --navy #233B66 · --periwinkle #92ADF1 · --ice #8EC3FF가 전부 코발트족입니다. 새 블루에 맞춰 깊이(다크 층)·비강조 막대·헤더 라인 색을 다시 뽑습니다. 순서: 네이비 / 페리윙클 / 아이스.

PART C

소프트 틴트 — 콜아웃 배경 스타일

파란/민트/코랄 콜아웃의 연한 배경 처리 방식입니다. 데모는 블루·민트·코랄 3종 콜아웃으로 보여줍니다.

ui-ux-pro-max: 접근성 = 색만으로 구분 금지 → 좌측 컬러 보더·아이콘·라벨 병기 권장
PART D

데이터 시각화 색 — 차트 21종 규칙

현재는 "강조 1개만 진한 색 + 나머지는 무채 램프(무지개 금지)" 모델입니다. 새 블루로 강조를 옮기고, 민트·코랄이 차트에서 의미를 가질지 결정합니다.

ui-ux-pro-max: 색맹 대응 = 색+모양/패턴 병기, 데이터 테이블 대안 제공
PART E

형태 언어 — 라운드 + 섀도우

지금 라운드(6~20px)·섀도우가 토큰 없이 난립하고, 그림자가 코발트 틴트라 새 블루로 바꿔야 합니다. 촉감(둥근 정도 + 떠 있는 정도)을 한 세트로 고릅니다.

ui-ux-pro-max(Bento/Apple): 라운드 16–24px + 소프트 섀도우 + hover scale 1.02가 "친근·현대·프로" 조합
PART F

표지·클로징 처리

현재 표지·클로징은 다크 배경(#1A1A1A) + electric(#2F6BF8)입니다. 다크를 유지할지, 새 블루로 갈지 고릅니다. (본문 슬라이드는 밝게 유지, 그라데이션은 표지에만.)

PART G

타이포 & 코드 폰트

본문은 Pretendard 유지(한글 최적·가독). 결정할 것은 강조 굵기 정책과 코드용 monospace 폰트입니다. 코드 시각화가 스킬 핵심이라 코드 폰트가 중요합니다. 데모의 제목·본문·코드로 비교하세요.

ui-ux-pro-max google-fonts: 검증된 monospace 계열에서 강의·코드 가독 우선으로 선별
내 선택 조합
파트 A–G는 색·형태·타이포 시스템(색 교체가 부르는 결정 전부)입니다. 아이콘·로고는 이 조합이 확정된 뒤 라운드 2로 별도 5종 초안을 만드는 게 자연스럽습니다.
