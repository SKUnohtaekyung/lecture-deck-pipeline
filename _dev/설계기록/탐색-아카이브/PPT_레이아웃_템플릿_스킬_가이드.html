OVERVIEW

이 스킬의 핵심은 ‘기본 레이아웃’을 두지 않는 것입니다.

“좌측 글·우측 시각” 같은 익숙한 구도를 먼저 고르지 않습니다. 한 장의 정보가 선언인지, 흐름인지, 비교인지부터 분류해 맞는 구도를 선택합니다.

정보 모양 판단

각 장을 12개 정보 모양 중 하나로 분류합니다. 이 판단이 레이아웃 선택보다 앞섭니다.

후보 찾기

레이아웃 역인덱스에서 후보를 찾고, 수치·흐름·구조 등은 element 후보도 함께 찾습니다.

별도 선택

레이아웃과 차트·다이어그램은 별개입니다. 필요한 element를 시각 슬롯에 얹습니다.

템플릿 조립

스타터의 표지·도입·아젠다·마무리, 네비게이션과 페이지 표기를 보존하며 콘텐츠를 채웁니다.

필요한 이미지 핸드오프

이미지 생성 대신 필요한 슬롯의 프롬프트 또는 주석 스크린샷을 준비합니다. 차트·도해를 우선합니다.

측정으로 검증

정적 검사 후 브라우저에서 오버플로, 콘솔 오류, 글자 크기와 폰트 로드를 확인합니다.

단일 파일 배포

필요하면 CSS와 이미지를 인라인해 이동·공유하기 쉬운 단일 HTML로 제공합니다.

NON-NEGOTIABLE RULES

템플릿에서 반드시 지킬 규칙

영역규칙
고정 구조표지·도입·아젠다·마무리는 스타터 구조를 유지합니다. 하단 네비게이션과 표지 전용 PDF 버튼도 보존합니다.
파트 구성모든 파트는 PART 1을 포함해 part-divider로 시작합니다. 본문에는 우측 파트 진행, 표지·마무리를 제외한 장에는 하단 페이지 표기를 자동 주입합니다.
색과 장식navy와 그라데이션은 사용하지 않습니다. 블루는 강조, 코랄은 주의, 레드는 오류, 민트는 확인·안전의 의미로만 사용합니다.
번호 배지민트 번호 배지는 .num-circle, .work-step .n, .pd-dot.is-active에만 씁니다. 도해·플로우 노드는 블루로 유지합니다.
가독성1280×720 고정 캔버스에서 본문은 22px 이상, 표는 17px 이상입니다. 본문이 5줄 이상이면 글자를 줄이기보다 장을 나눕니다.
시각화이미지보다 코드 차트·다이어그램을 먼저 고려합니다. element를 독립된 전체 슬라이드로 승격하지 않고 선택한 레이아웃의 시각 슬롯에 삽입합니다.
리듬직전 콘텐츠 장과 같은 구도 패밀리를 피합니다. split은 소수만 사용하고 연속으로 배치하지 않습니다.
QUALITY CHECK

내보내기 전 체크

구조

  • 고정 슬라이드와 파트 전환 수가 맞는가
  • 네비게이션·PDF·페이지 표기가 유지됐는가
  • 정보 모양과 레이아웃 선택 근거가 있는가

화면

  • 모든 슬라이드의 오버플로가 0인가
  • 제목이 의도치 않게 두 줄로 줄바꿈되지 않았는가
  • 콘솔 오류가 없고 Pretendard가 로드됐는가

표현

  • raw 색상값 대신 토큰을 썼는가
  • 민트·코랄 배경에 흰 글자가 없는가
  • 한 장에 하나의 메시지가 남아 있는가
