# vibecoding-deck

Claude Code가 채워진 슬라이드 계획서를 읽고, 정보의 모양에 맞는 레이아웃과 시각 요소를 골라 **1280×720 HTML 발표 웹덱**을 만들도록 돕는 프레젠테이션 스킬입니다.

## 핵심 기능

- 계획서의 슬라이드 순서·정보 묶음·전달 목적을 우선합니다. 수용량을 넘겨도 승인 없이 슬라이드를 나누지 않습니다.
- 12개 정보 모양을 먼저 판단한 뒤, 50개 레이아웃과 21개 차트·다이어그램 요소를 조합합니다.
- 큰 글자와 높은 대비를 기본으로 하며, 40~50대 초보자 대상의 강의·교육 발표에 맞춥니다.
- 표지의 3단 큐브, 메인 블루 색 체계, 민트 강조 규칙, 파트 진행 표시와 페이지 번호를 유지합니다.
- 방향키 발표, 전체화면, 홈·페이지 이동·슬라이드 목록·PDF 출력을 제공하는 Liquid Glass 발표 내비게이션을 포함합니다.
- 외부 이미지보다 코드 기반 차트·다이어그램을 우선하고, 필요한 화면 조작은 주석 스크린샷으로 안내합니다.

## Claude Code에서 사용하기

이 저장소 전체를 대상 프로젝트의 아래 위치로 복사합니다.

```text
<프로젝트>/.claude/skills/vibecoding-deck/
```

새 Claude Code 세션에서 `/vibecoding-deck`으로 호출하거나, “이 계획서로 강의덱 만들어줘”, “PPT를 HTML 웹덱으로 만들어줘”처럼 요청하면 스킬이 적용됩니다.

자세한 워크플로와 불변 요소는 [SKILL.md](SKILL.md)를, 작성 형식은 [슬라이드 계획서 템플릿](입력양식/슬라이드계획서템플릿.md)을 참고하세요.

## 빠른 시작

1. `입력양식/슬라이드계획서템플릿.md`를 채웁니다.
2. Claude Code에서 계획서와 함께 덱 제작을 요청합니다.
3. 생성된 HTML 덱을 검증합니다.

```bash
python scripts/verify_deck.py <덱 파일>.html --parts <파트 수>
```

## 구성

```text
SKILL.md                         스킬 진입점과 제작 워크플로
입력양식/                         슬라이드 계획서 템플릿
kit/starter/                     발표덱 스타터 템플릿
kit/styles/                      디자인 토큰·가독성·컴포넌트 CSS
kit/layouts/                     50개 레이아웃 카탈로그와 선택 규칙
kit/charts/                      21개 차트·다이어그램 요소와 선택 규칙
kit/guide/                       정보 모양·디자인 시스템·토큰 가이드
references/                      조립·리듬·배포 규칙
scripts/                         정적 검증과 단일 파일 배포 도구
outputs/                         레이아웃 아틀라스와 생성 도구
evals/                           회귀 평가 시나리오
```

## 레이아웃 아틀라스

[`outputs/vibecoding-deck-layout-atlas.html`](outputs/vibecoding-deck-layout-atlas.html)에서 50개 레이아웃과 21개 시각 요소를 실제 발표 화면처럼 넘겨볼 수 있습니다.

## 디자인 원칙

- 구조와 주 강조에는 `--blue`를 사용합니다.
- 민트는 행동·안전·강조에 사용하며, 글자색·밑줄·글자폭 배경·도형 중 문맥에 맞춰 선택합니다.
- 상단 헤더 선은 메인 블루를 사용합니다.
- 그라데이션과 `navy` 렌더 사용을 금지합니다.
- 하단 기본 바는 고투명 유리, 상세 메뉴는 옅은 쿨그레이 반투명 유리로 구성합니다.

## 검증 기준

정적 검증은 표지 3큐브, 파트 전환 수, 발표 내비게이션, PDF 출력, 색 토큰, 민트 강조, 코드 시각화 접근성 등을 확인합니다. 브라우저에서는 각 슬라이드의 오버플로와 콘솔 오류를 추가로 확인합니다.
