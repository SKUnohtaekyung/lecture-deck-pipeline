# 보조 문서(reference) 예시

이런 파일은 **필요할 때만** 읽히는 온디맨드 참조다. `SKILL.md` 는 짧게 유지하고,
길어지는 것들(스펙 표, 규격, 예시 모음, 체크리스트, 계산식 등)은 여기로 분리한다.

## 왜 분리하나
- `SKILL.md` 는 스킬이 켜질 때 항상 로드된다 → 짧을수록 좋다(트리거 판단·초기 컨텍스트).
- reference 는 SKILL.md 안에서 "필요하면 `references/xxx.md` 를 읽어라"로 가리킬 때만 로드된다.

## 쓰는 법
1. 이 폴더에 주제별 `.md` 를 둔다 (예: `spec.md`, `examples.md`, `checklist.md`).
2. `SKILL.md` 의 "참조" 섹션에서 각 파일이 **무엇을 담는지** 한 줄로 링크한다.
3. 코드·스크립트는 `../scripts/`, 템플릿·이미지는 `../assets/` 로.

> 이 예시 파일은 지우고 실제 참조 문서로 교체하면 된다.
