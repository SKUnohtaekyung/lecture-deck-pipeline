# 주석 스크린샷 element (Annotated Screenshot)

> 정보 모양 `screen-operation`(실습 화면 조작 안내)용 element. **캡처는 사람이, 번호·테두리 overlay는 킷이 코드로.**
> whole-slide가 아니라 host 레이아웃(`L-dc-annotated`·`L-vf-numbered-stack`·`L-dc-hero`)에 얹는 fragment.

## 무엇인가
실제 화면 캡처 이미지 위에 **번호 배지(①②③)** 와 **강조 테두리 박스**를 얹어 "이 버튼 → 저 메뉴 → 클릭"을 짚는다. "여기" 대신 실제 버튼명·위치.

## data_shape · capacity
- 한 화면에 짚을 지점 **3~5개**(6개↑면 리더선/배지 혼잡 → 화면을 나눔).
- 배지·캡션 텍스트 ≥22px(40~50대 하한). 배지는 대상이므로 `--blue`(색 문법: 강조/대상).
- 여러 화면 단계면 host를 `L-vf-numbered-stack`으로 세로 나열, 각 단계에 미니 캡처 + 캡션.

## element_vs_slide
- **fragment** = `.shot-annot`(프레임 + 캡처 `<img>` + 절대배치 `.shot-badge`/`.shot-hl` overlay + 캡션). whole-slide 아님.
- **host(별도)** = `L-dc-annotated`(한 화면 여러 지점)·`L-vf-numbered-stack`(여러 화면)·`L-dc-hero`(단일 화면 크게). host가 eyebrow·제목을 얹는다.

## 핸드오프
1. 계획서 `화면 캡처` 항목의 화면·단계·강조 위치(번호)를 읽는다.
2. **캡처는 사용자가** 실제 화면을 찍어 `img/`에 둔다(이 스킬은 캡처하지 않음).
3. 킷이 그 위에 배지·테두리 overlay를 코드로 얹는다(아래 CSS). 배지 `top/left`, 테두리 박스 `top/left/width/height`는 캡처의 강조 지점에 맞춰 인라인.

## CSS (토큰 기반 · 데모에서 브라우저 검증)
```css
.shot-annot{ position:relative; width:100%; max-width:560px; margin:0 auto; }
.shot-frame{ border:1px solid var(--line); border-radius:12px; overflow:hidden;
  box-shadow:0 16px 40px rgba(20,24,33,.16); background:var(--white); }
.shot-frame img{ display:block; width:100%; height:auto; }              /* 캡처 이미지 */
.shot-badge{ position:absolute; width:34px; height:34px; border-radius:50%;
  background:var(--blue); color:var(--white); font-weight:800; font-size:18px;
  display:grid; place-items:center; box-shadow:0 8px 18px rgba(29,78,216,.4); } /* top/left 인라인 */
.shot-hl{ position:absolute; border:3px solid var(--blue); border-radius:8px; } /* top/left/width/height 인라인 */
.shot-cap{ margin-top:10px; font-size:19px; color:var(--gray-700); }    /* 단계 캡션 */
```

## 캡처가 아직 없을 때 (목업 폴백)
실제 캡처 전이라면 데모(`데모_제작규칙.html`)의 **목업 창** 변형으로 자리를 잡는다 — `.shot-win`(타이틀바 + 메뉴 행) + `.shot-row.on`(강조 행) + `.shot-badge.b1/.b2/.b3`(행에 정렬된 번호). 실제 캡처가 오면 목업을 `<img>`로 교체.

## a11y
`role="img"` + `aria-label="화면 조작: ① <위치> 클릭 → ② <메뉴> → ③ <항목>"` — 단계를 순서대로 문장으로. 배지·캡션은 실제 텍스트로도 존재.
