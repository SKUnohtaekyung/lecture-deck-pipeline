# 이미지 · 주석 스크린샷 · 배포

> 워크플로우 6·8단계에서 참조. **이 스킬은 이미지를 생성하지 않는다** — 슬롯만 배치하고 핸드오프.

## 1. 이미지 핸드오프 (필요 슬롯만)
- 시각화 **기본은 코드 차트·다이어그램**([`../kit/charts/`](../kit/charts/)). 이미지는 계획서가 `이미지 필요?`에 적은 슬롯 + 배경에만.
- 일러스트가 필요한 곳엔 `<img class="asset hero" src="img/slides/sNN_<concept>.png" alt="">` **슬롯만** 배치(좌 ~40% 비워 본문 자리).
- 이미지 슬롯을 모아 **프롬프트 시트**를 산출하고, 각 항목의 그릴 대상(SUBJECT)을 채운다. **실제 생성은 사용자가** 이미지 생성 도구로. 이 스킬은 여기서 멈춘다.
- 두 특수 슬롯: **도입(s02) 이미지**는 주제별로 새로, **마무리 배경**(`concept-bg`)은 풀블리드 가로(왼쪽 ~45% 저대비 — 패널 텍스트가 얹힘). 없어도 밝은 배경으로 무방.

## 2. 주석 스크린샷 (화면 조작 안내)
- 정보 모양이 `screen-operation`이면 실제 화면 **캡처는 사용자가**, 번호·테두리 **overlay는 킷이 코드로**.
- element·CSS·배치법: [`../kit/screenshots/주석스크린샷.md`](../kit/screenshots/주석스크린샷.md). host 레이아웃은 `L-dc-annotated`(한 화면 여러 지점)·`L-vf-numbered-stack`(여러 화면 단계)·`L-dc-hero`(단일 화면).
- "여기" 대신 실제 버튼명·위치를 번호로. 캡처는 느리고 불안정하니 최소로.

## 3. 배포 — 단일 파일 (선택)
개발용은 `img/`·CSS 링크 참조(가벼움). 학생 배포·오프라인은 단일 HTML:
- `deck.css` + `legibility-40s.css` + kit-additions CSS를 `<style>`로 **인라인**.
- 이미지가 있으면 base64로 인라인(용량 크면 다운스케일). 목표 3~8MB(메일·USB).
- 유일한 외부 의존 = Pretendard 폰트 CDN. 완전 오프라인이 필요하면 폰트도 인라인하거나 시스템 폰트(맑은 고딕) 폴백 허용.
- 원본(dev)은 불변, `<덱>_배포.html`을 새로 생성.

## 왜 코드 우선인가 (재확인)
코드 차트·다이어그램은 — 수정 즉시 반영 · 배율·인쇄에 항상 선명 · 파일 용량 0 · 텍스트라 접근성/검색 가능. 이미지는 정서·배경·실물이 꼭 필요한 스팟에만.
