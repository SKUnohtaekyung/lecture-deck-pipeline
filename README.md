# vibecoding-deck

Claude Code와 Codex가 채워진 콘텐츠 초안(교시별 표·본문·강사 멘트)을 읽고, 정보의 모양에 맞는 레이아웃과 시각 요소를 골라 **1280×720 HTML 발표 웹덱**을 만들도록 돕는 프레젠테이션 스킬입니다.

## 핵심 기능

- 초안의 슬라이드 순서·제목·본문을 그대로 존중합니다(재작성하지 않음). 수용량을 넘겨도 승인 없이 슬라이드를 나누지 않습니다.
- `시각화 의도`를 사람이 지정하지 않아도, 12개 정보 모양을 스킬이 직접 판단한 뒤 50개 레이아웃과 23개 차트·다이어그램 요소를 조합합니다.
- 강사 멘트를 아이콘으로 라우팅합니다 — `💬` 농담·`👀` 시연 큐는 화면에 감추고, `🗣` 안전망 예시는 접힌 힌트로 넣습니다. 멘트가 있으면 강사용 **발표자 노트 HTML**도 함께 만듭니다.
- 큰 글자와 높은 대비를 기본으로 하며, 40~50대 초보자 대상의 강의·교육 발표에 맞춥니다.
- 표지의 3단 큐브, 메인 블루 색 체계, 민트 강조 규칙, 파트 진행 표시와 페이지 번호를 유지합니다.
- 방향키 발표, 전체화면, 홈·페이지 이동·슬라이드 목록·PDF 출력을 제공하는 Liquid Glass 발표 내비게이션을 포함합니다.
- 외부 이미지보다 코드 기반 차트·다이어그램을 우선하고, 필요한 화면 조작은 주석 스크린샷으로 안내합니다.

## Claude Code에서 사용하기

이 개발 저장소에서는 `.claude/skills/vibecoding-deck/SKILL.md` 어댑터가 루트 공통 정본을 로드하므로 바로 사용할 수 있습니다. 다른 프로젝트에 배포할 때는 루트 포터블 Skill 파일을 아래 위치에 복사합니다.

```text
<프로젝트>/.claude/skills/vibecoding-deck/
```

새 Claude Code 세션에서 `/vibecoding-deck`으로 호출하거나, “이 초안으로 강의덱 만들어줘”, “PPT를 HTML 웹덱으로 만들어줘”처럼 요청하면 스킬이 적용됩니다.

## Codex에서 사용하기

이 개발 저장소에서는 `.agents/skills/vibecoding-deck/SKILL.md` 어댑터가 루트 공통 정본을 로드하므로 바로 사용할 수 있습니다. 다른 프로젝트에 포터블 스킬로 설치할 때는 배포 대상 파일을 아래 위치에 둡니다.

```text
<프로젝트>/.agents/skills/vibecoding-deck/
```

새 Codex 작업에서 `$vibecoding-deck`을 명시하거나 “이 초안으로 강의덱 만들어줘”처럼 요청합니다. 이 개발 저장소의 `.agents/`는 프로젝트 설정 레이어이므로 포터블 스킬 안에 중첩해 복사하지 않습니다.

자세한 워크플로와 불변 요소는 [SKILL.md](SKILL.md)를, 작성 형식은 [콘텐츠 초안 템플릿](입력양식/콘텐츠초안템플릿.md)을 참고하세요.

## 빠른 시작

1. `입력양식/콘텐츠초안템플릿.md` 형식으로 슬라이드 내용을 채웁니다(교시별 표 + 강사 멘트 아이콘).
2. Claude Code 또는 Codex에서 초안과 함께 덱 제작을 요청합니다. 스킬이 교시→PART 묶음을 확인한 뒤 조립합니다.
3. 생성된 HTML 덱(+ 멘트가 있으면 발표자 노트 HTML)을 검증합니다.

```bash
python scripts/verify_deck.py <덱 파일>.html --parts <파트 수>
python scripts/verify_skill_setup.py
```

## 구성

```text
SKILL.md                         스킬 진입점과 제작 워크플로
입력양식/                         콘텐츠 초안 템플릿(공식 입력 형식)
kit/starter/                     발표덱 스타터 + 발표자 노트 스타터
kit/styles/                      디자인 토큰·가독성·컴포넌트 CSS
kit/layouts/                     50개 레이아웃 카탈로그와 선택 규칙
kit/charts/                      23개 차트·다이어그램 요소와 선택 규칙
kit/guide/                       정보 모양·디자인 시스템·토큰 가이드
references/                      조립·리듬·배포 규칙
scripts/                         정적 검증과 단일 파일 배포 도구
.agents/skills/vibecoding-deck/ Codex용 공통 정본 어댑터
.claude/skills/vibecoding-deck/ Claude Code용 공통 정본 어댑터
outputs/                         레이아웃 아틀라스와 생성 도구
evals/                           회귀 평가 시나리오
```

## 레이아웃 아틀라스

[`outputs/vibecoding-deck-layout-atlas.html`](outputs/vibecoding-deck-layout-atlas.html)에서 50개 레이아웃과 현재 아틀라스에 수록된 21개 시각 요소를 실제 발표 화면처럼 넘겨볼 수 있습니다. 전체 23개 element의 정본은 `kit/charts/`입니다.

## 디자인 원칙

- 구조와 주 강조에는 `--blue`를 사용합니다.
- 민트는 행동·안전·강조에 사용하며, 글자색·밑줄·글자폭 배경·도형 중 문맥에 맞춰 선택합니다.
- 상단 헤더 선은 메인 블루를 사용합니다.
- 그라데이션과 `navy` 렌더 사용을 금지합니다.
- 하단 기본 바는 고투명 유리, 상세 메뉴는 옅은 쿨그레이 반투명 유리로 구성합니다.

## 검증 기준

정적 검증은 표지 3큐브, 파트 전환 수, 발표 내비게이션, PDF 출력, 색 토큰, 민트 강조, 코드 시각화 접근성 등을 확인합니다. 브라우저에서는 각 슬라이드의 오버플로와 콘솔 오류를 추가로 확인합니다.
